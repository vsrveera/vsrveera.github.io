35  Convolutional Vision in Depth

NoteKey ideas
  • The receptive field of a unit is the input region that can affect it. It grows with kernel size, stride, and depth.
  • \(1\times1\) convolution is a per-pixel linear layer. Depthwise-separable convolution splits spatial and channel mixing and costs about \(1/k^2+1/C_{\text{out}}\) of a full one.
  • Residual connections make very deep CNNs trainable.
  • Batch normalisation standardises each channel over the batch and spatial positions.
  • Transposed convolution is the transpose of a convolution matrix. It upsamples.
  • Affine warps are \(3\times3\) matrices in homogeneous coordinates. They are the basis of image augmentation.

35.2 Receptive fields

A unit in layer \(l\) depends on a patch of the input. Its size is the receptive field \(r_l\). Let \(j_l\) be the jump: the distance in input pixels between adjacent units of layer \(l\). For a layer with kernel \(k\), stride \(s\), and dilation \(\delta\):

\[ r_l=r_{l-1}+(k-1)\,\delta\,j_{l-1},\qquad j_l=j_{l-1}\,s,\qquad r_0=1,\ j_0=1. \tag{35.1}\]

TipDerivation

A kernel of width \(k\) spans \(k\) units of the previous layer. Adjacent units of the previous layer are \(j_{l-1}\) input pixels apart. So the kernel spans \((k-1)\,\delta\,j_{l-1}\) input pixels between its first and last unit, which adds to the receptive field of the previous layer. A stride multiplies the spacing of all later units. \(\blacksquare\)

def receptive_field(layers):
    r, j, out = 1, 1, []
    for k, s, dil in layers:
        r += (k - 1) * dil * j
        j *= s
        out.append(r)
    return out

L = 12
plain = [(3, 1, 1)] * L
strided = [(3, 2 if i % 2 == 1 else 1, 1) for i in range(L)]
dilated = [(3, 1, 2 ** (i % 5)) for i in range(L)]
fig, ax = plt.subplots(figsize=(6, 3.5))
for layers, name, c in [(plain, "3×3, stride 1", PALETTE["data"]), (strided, "stride 2 every 2nd layer", PALETTE["model"]),
                        (dilated, "dilation 1, 2, 4, …", PALETTE["grad"])]:

ax.set_xlabel("layer"); ax.set_ylabel("receptive field (pixels)"); ax.legend(fontsize=8)
plt.show()

      " strided:", receptive_field(strided)[-1], " dilated:", receptive_field(dilated)[-1])

A \(224\times224\) image needs a receptive field of that order at the deepest layer, so that the final features can see the whole object. Plain stacking would need over 100 layers. Downsampling gets there with a few.

35.3 Cheaper convolutions

A full convolution mixes space and channels in one step, at a cost of \(k^2C_{\text{in}}C_{\text{out}}\) weights.

\(1\times1\) convolution. Kernel size 1. It does no spatial mixing. It applies the same linear layer (Chapter 9) to the channel vector at every pixel.

import torch, torch.nn as nn, torch.nn.functional as F
torch.manual_seed(0)
x = torch.randn(2, 8, 5, 5)                          # (B, C_in, H, W)
conv = nn.Conv2d(8, 4, kernel_size=1, bias=False)
W = conv.weight.squeeze(-1).squeeze(-1)              # (C_out, C_in)
manual = torch.einsum("oc,bchw->bohw", W, x)         # same linear map at every pixel
print("1×1 conv equals a per-pixel linear layer:", torch.allclose(conv(x), manual, atol=1e-6))
1×1 conv equals a per-pixel linear layer: True

Depthwise-separable convolution splits the work in two: a depthwise \(k\times k\) convolution (each channel on its own, groups=C_in) for spatial mixing, followed by a \(1\times1\) convolution for channel mixing.

\[ \text{params}:\quad k^2C_{\text{in}}C_{\text{out}}\;\longrightarrow\;k^2C_{\text{in}}+C_{\text{in}}C_{\text{out}},\qquad \text{ratio}=\frac1{C_{\text{out}}}+\frac1{k^2}. \tag{35.2}\]

Cin, Cout, k = 128, 128, 3
full = nn.Conv2d(Cin, Cout, k, padding=1, bias=False)
sep = nn.Sequential(nn.Conv2d(Cin, Cin, k, padding=1, groups=Cin, bias=False),
                    nn.Conv2d(Cin, Cout, 1, bias=False))
n_full = sum(p.numel() for p in full.parameters()); n_sep = sum(p.numel() for p in sep.parameters())
print(f"full 3×3: {n_full:,} weights;  separable: {n_sep:,} weights;  ratio {n_sep / n_full:.3f}"
      f"  (formula {1 / Cout + 1 / k ** 2:.3f})")
H = W_ = 56
print(f"FLOPs at {H}×{W_}: full {2 * n_full * H * W_ / 1e6:.0f} M, separable {2 * n_sep * H * W_ / 1e6:.0f} M")
full 3×3: 147,456 weights;  separable: 17,536 weights;  ratio 0.119  (formula 0.119)
FLOPs at 56×56: full 925 M, separable 110 M

Mobile-friendly architectures (MobileNet, EfficientNet) rely on this factorisation to cut cost by about an order of magnitude.

35.4 Residual networks

Stacking more convolutions ought not to hurt: extra layers could learn the identity. In practice, plain deep stacks are harder to train than shallow ones. Residual blocks fix this by computing a correction to the input:

\[ \mathbf{y}=\mathbf{x}+F(\mathbf{x}),\qquad F=\text{conv}\to\text{BN}\to\text{ReLU}\to\text{conv}\to\text{BN}. \tag{35.3}\]

The identity path gives the gradient a direct route (Chapters 18, 31). If \(\mathbf{x}\) and \(F(\mathbf{x})\) have different shapes (stride or more channels), the shortcut uses a \(1\times1\) convolution to match them.

We compare four designs on the digits (Chapter 11): plain and residual stacks of basic blocks (two \(3\times3\) convolutions each), with and without batch normalisation (next section). Same width, optimiser, and seed. We vary the depth.

from sklearn.datasets import load_digits
from sklearn.model_selection import train_test_split
D = load_digits()
Xtr, Xte, ytr, yte = train_test_split(D.data / 16.0, D.target, test_size=0.25,
                                      random_state=0, stratify=D.target)
Xt = torch.tensor(Xtr, dtype=torch.float32).view(-1, 1, 8, 8)
Xv = torch.tensor(Xte, dtype=torch.float32).view(-1, 1, 8, 8)
yt, yv = torch.tensor(ytr), torch.tensor(yte)

class Unit(nn.Module):
    """Basic block: conv-(BN)-ReLU-conv-(BN), with or without a skip around both convs."""
    def __init__(self, w, residual, bn):
        super().__init__()
        self.residual = residual
        self.c1, self.c2 = nn.Conv2d(w, w, 3, padding=1), nn.Conv2d(w, w, 3, padding=1)
        self.b1 = nn.BatchNorm2d(w) if bn else nn.Identity()
        self.b2 = nn.BatchNorm2d(w) if bn else nn.Identity()
    def forward(self, x):
        h = self.b2(self.c2(F.relu(self.b1(self.c1(x)))))
        return F.relu(x + h) if self.residual else F.relu(h)

class Net(nn.Module):
    def __init__(self, blocks, residual, bn, width=16):
        super().__init__()
        self.inp = nn.Conv2d(1, width, 3, padding=1)
        self.blocks = nn.Sequential(*[Unit(width, residual, bn) for _ in range(blocks)])
        self.fc = nn.Linear(width, 10)
    def forward(self, x):
        return self.fc(self.blocks(F.relu(self.inp(x))).mean((2, 3)))      # global average pooling

def fit(model, steps=300, lr=0.05, bs=128):
    g = torch.Generator().manual_seed(0)
    opt = torch.optim.SGD(model.parameters(), lr=lr, momentum=0.9)
    for _ in range(steps):
        idx = torch.randint(0, len(Xt), (bs,), generator=g)
        opt.zero_grad(); F.cross_entropy(model(Xt[idx]), yt[idx]).backward(); opt.step()
    model.eval()
    with torch.no_grad():
        return F.cross_entropy(model(Xt), yt).item(), (model(Xv).argmax(1) == yv).float().mean().item()

designs = {"plain": (False, False), "residual": (True, False),
           "plain + BN": (False, True), "residual + BN": (True, True)}
print(f"{'convolutions':>12s} | " + " | ".join(f"{n:>22s}" for n in designs))
results = {}
for blocks in (1, 4, 8):
    row = []
    for name, (res, bn) in designs.items():
        torch.manual_seed(0)
        loss, acc = fit(Net(blocks, res, bn)); results[(blocks, name)] = (loss, acc)
        row.append(f"loss {loss:5.3f}, acc {acc:5.3f}")
    print(f"{2 * blocks:12d} | " + " | ".join(f"{r:>22s}" for r in row))
convolutions |                  plain |               residual |             plain + BN |          residual + BN
           2 |  loss 1.692, acc 0.342 |  loss 0.861, acc 0.736 |  loss 0.034, acc 0.982 |  loss 0.051, acc 0.973
           8 |  loss 2.304, acc 0.100 |  loss 2.304, acc 0.100 |  loss 0.001, acc 0.993 |  loss 0.001, acc 0.998
          16 |  loss 2.304, acc 0.100 |  loss 2.303, acc 0.100 |  loss 0.086, acc 0.951 |  loss 0.000, acc 0.991

Read the table carefully, because it is not what the legend of a textbook ResNet figure suggests.

  • Without normalisation, every design fails (loss stays at \(\ln10=2.30\), chance accuracy) once the stack is 8 convolutions deep, residual or not. With default initialisation and plain SGD, the signal does not survive. The skip alone does not rescue it.
  • With batch normalisation, both trainable. At depth 16, the residual network is clearly better than the plain one.
  • The benefit of the skip appears at depth, and is one ingredient of a recipe. It works together with normalisation and sensible initialisation (Chapter 20).

35.5 Batch normalisation

Batch normalisation (BN) standardises each channel using statistics computed over the batch and over all spatial positions:

\[ \hat{x}_{nchw}=\frac{x_{nchw}-\mu_c}{\sqrt{\sigma_c^2+\epsilon}},\qquad y_{nchw}=\gamma_{c}\hat{x}_{nchw}+\beta_c, \tag{35.4}\]

with \(\mu_c,\sigma_c^2\) the mean and variance of channel \(c\) over \((n,h,w)\). During training the batch statistics are used (and a running average is stored). During evaluation the stored averages are used, so that one example gives the same output whatever the batch.

torch.manual_seed(0)
x = torch.randn(16, 4, 6, 6) * 3 + 2
bn = nn.BatchNorm2d(4, eps=1e-5)
bn.train(); y = bn(x)
mu = x.mean((0, 2, 3), keepdim=True); var = x.var((0, 2, 3), keepdim=True, unbiased=False)
manual = (x - mu) / torch.sqrt(var + 1e-5)
print("train mode equals the formula:", torch.allclose(y, manual, atol=1e-5))
print("per-channel mean and std of the output:", y.mean((0, 2, 3)).abs().max().item() < 1e-5,
      y.std((0, 2, 3), unbiased=False).round(decimals=3).tolist())
bn.eval()
single = bn(x[:1])
print("eval mode uses the running averages (output for one example differs from batch-stat output):",
      not torch.allclose(single, manual[:1], atol=1e-3))
train mode equals the formula: True
per-channel mean and std of the output: True [1.0, 1.0, 1.0, 1.0]
eval mode uses the running averages (output for one example differs from batch-stat output): True

35.6 Upsampling: transposed convolution

Many vision models must go up in resolution: segmentation, image generation (Chapters 40–42). Transposed convolution does this. If a convolution is a matrix \(\mathbf{M}\) (Chapter 12), the transposed convolution multiplies by \(\mathbf{M}^{\intercal}\). It is also the operation that appears in the backward pass of a convolution (Chapter 18).

For input size \(n\), kernel \(k\), stride \(s\), padding \(p\):

\[ n_{\text{out}}=(n-1)\,s-2p+k. \tag{35.5}\]

n, k, s = 8, 3, 1
kern = torch.randn(1, 1, k)                                  # (C_out, C_in, k)
# matrix of the convolution: (n - k + 1) × n
M = torch.zeros(n - k + 1, n)
for i in range(n - k + 1):
    M[i, i:i + k] = kern[0, 0]
v = torch.randn(1, 1, n - k + 1)
via_matrix = (M.T @ v[0, 0]).view(1, 1, n)
via_transposed = F.conv_transpose1d(v, kern)                 # kernel is applied in the same orientation
print("conv_transpose1d equals multiplication by Mᵀ:", torch.allclose(via_matrix, via_transposed, atol=1e-6))
up = nn.ConvTranspose2d(4, 4, kernel_size=4, stride=2, padding=1)
print("ConvTranspose2d(k=4, s=2, p=1): 16×16 ->", tuple(up(torch.randn(1, 4, 16, 16)).shape[2:]),
      "  formula:", (16 - 1) * 2 - 2 * 1 + 4)
conv_transpose1d equals multiplication by Mᵀ: True
ConvTranspose2d(k=4, s=2, p=1): 16×16 -> (32, 32)   formula: 32

A well-known artefact: with a kernel size not divisible by the stride, transposed convolutions produce a checkerboard pattern. Many models upsample by interpolation followed by an ordinary convolution instead.

35.7 Spatial transformations as matrices

A rotation, scale, shear, or translation of an image is an affine map of pixel coordinates. In homogeneous coordinates, with a point \((x,y)\) written as \((x,y,1)\), all of them are one \(3\times3\) matrix, and they compose by matrix product (Chapter 5):

\[ \begin{pmatrix}x'\\y'\\1\end{pmatrix}= \begin{pmatrix}a&b&t_x\\c&d&t_y\\0&0&1\end{pmatrix} \begin{pmatrix}x\\y\\1\end{pmatrix}. \tag{35.6}\]

To warp an image we use the inverse map. For each output pixel we compute where it comes from in the input (using \(\mathbf{A}^{-1}\)) and read the value there, interpolating between the four nearest pixels (bilinear interpolation). Using the forward map would leave holes.

def bilinear(img, rr, cc):
    """Sample img at float coordinates (rr, cc); zero outside."""
    H, W = img.shape
    r0, c0 = np.floor(rr).astype(int), np.floor(cc).astype(int)
    fr, fc = rr - r0, cc - c0
    def px(r, c):
        ok = (r >= 0) & (r < H) & (c >= 0) & (c < W)
        return np.where(ok, img[np.clip(r, 0, H - 1), np.clip(c, 0, W - 1)], 0.0)
    return ((1 - fr) * (1 - fc) * px(r0, c0) + (1 - fr) * fc * px(r0, c0 + 1)
            + fr * (1 - fc) * px(r0 + 1, c0) + fr * fc * px(r0 + 1, c0 + 1))

def warp(img, A):
    """Warp img by the 3×3 affine matrix A (acts on (row, col, 1))."""
    H, W = img.shape
    rr, cc = np.meshgrid(np.arange(H), np.arange(W), indexing="ij")
    src = np.linalg.inv(A) @ np.stack([rr.ravel(), cc.ravel(), np.ones(H * W)])
    return bilinear(img, src[0].reshape(H, W), src[1].reshape(H, W))

def rot_scale_about_centre(theta, scale, shape, shift=(0.0, 0.0)):
    H, W = shape; c = np.array([(H - 1) / 2, (W - 1) / 2])
    R = scale * np.array([[np.cos(theta), -np.sin(theta)], [np.sin(theta), np.cos(theta)]])
    A = np.eye(3); A[:2, :2] = R
    A[:2, 2] = c - R @ c + np.array(shift)           # rotate/scale about the centre, then shift
    return A

from sklearn.datasets import load_sample_image
photo = load_sample_image("china.jpg").astype(float).mean(axis=2)[50:210, 150:390]     # (160, 240)
A = rot_scale_about_centre(np.deg2rad(20), 0.8, photo.shape, shift=(10, 20))
warped = warp(photo, A)

from scipy.ndimage import affine_transform
Ainv = np.linalg.inv(A)
ref = affine_transform(photo, Ainv[:2, :2], offset=Ainv[:2, 2], order=1, mode="grid-constant", cval=0.0)
print("matches scipy.ndimage.affine_transform:", np.allclose(warped, ref, atol=1e-6))
print(f"largest difference: {np.abs(warped - ref).max():.1e}")
matches scipy.ndimage.affine_transform: True
largest difference: 6.8e-12
shear = np.eye(3); shear[0, 1] = 0.4

35.7.1 Augmentation fixes what architecture does not

In Chapter 12, a model trained on centred digits lost much of its accuracy when the test images were shifted by one pixel. Convolution is equivariant to shifts, but the classifier is not invariant. Data augmentation addresses this by training on randomly transformed copies. We close the loop on that experiment.

class SmallCNN(nn.Module):
    def __init__(self):
        super().__init__()
        self.c, self.l = nn.Conv2d(1, 8, 3), nn.Linear(72, 10)
    def forward(self, x):
        return self.l(F.max_pool2d(F.relu(self.c(x)), 2).flatten(1))

def train_cnn(augment, steps=800, seed=0):
    torch.manual_seed(seed); rng = np.random.default_rng(seed)
    m = SmallCNN(); opt = torch.optim.SGD(m.parameters(), lr=0.5)
    for _ in range(steps):
        x = Xt
        if augment:
            dy, dx = rng.integers(-1, 2, 2)
            x = torch.roll(Xt, (int(dy), int(dx)), (2, 3))          # random shift by up to 1 pixel
        opt.zero_grad(); F.cross_entropy(m(x), yt).backward(); opt.step()
    return m

acc = lambda m, X: (m(X).argmax(1) == yv).float().mean().item()
print(f"{'training':12s} {'original':>9s} {'shifted +1 col':>15s} {'shifted (−1, +1)':>17s}")
for aug in (False, True):
    m = train_cnn(aug)
    print(f"{'augmented' if aug else 'plain':12s} {acc(m, Xv):9.3f} "
          f"{acc(m, torch.roll(Xv, (0, 1), (2, 3))):15.3f} {acc(m, torch.roll(Xv, (-1, 1), (2, 3))):17.3f}")
training      original  shifted +1 col  shifted (−1, +1)
plain            0.973           0.498             0.293

35.8 Failure modes

Aliasing. Strided convolution and pooling subsample without low-pass filtering, so small input shifts can change the output unpredictably (Chapter 12). Blur-pool and anti-aliased downsampling reduce it.

Border effects. Padding adds artificial context at the image border. Zero padding can leak absolute position information into the features.

Shortcut mismatch. A residual add needs equal shapes. A stride or channel change without a projection shortcut is a shape error.

Batch-norm and small batches. Statistics from a batch of 2 are noisy. In evaluation mode, the running statistics may not match the test distribution. Group or layer normalisation avoids this.

Train/eval mode. Forgetting model.eval() changes BN (and dropout) behaviour and silently changes results.

Large receptive field is not large effective receptive field. The theoretical field is a bound. In trained networks, the units that matter lie mostly near the centre.

Interpolation artefacts. Repeated resampling blurs images. Augmentation composed from many warps should compose the matrices first, and warp once.

35.10 System connection

NoteWhat the system gained in this chapter

System A can now be built deep and efficient: the receptive field is under control, convolutions can be made cheap, residual paths make depth trainable, and spatial transformations are matrices that augment the data. It also has the upsampling operator that generative models need.

All of the spatial reasoning here is built into the convolution. The next chapter replaces it with attention: instead of a sliding kernel, an image becomes a sequence of patches, and the Transformer of Chapter 31 reads it (Chapter 36).

Chapter summary

  • Receptive field: \(r_l=r_{l-1}+(k-1)\delta j_{l-1}\), \(j_l=j_{l-1}s\). Stride and dilation make it grow exponentially.
  • \(1\times1\) convolution is a per-pixel linear layer. Separable convolution costs \(\frac1{C_{\text{out}}}+\frac1{k^2}\) of a full one.
  • \(\mathbf{y}=\mathbf{x}+F(\mathbf{x})\) makes deep CNNs trainable.
  • BN uses batch statistics in training and running averages in evaluation.
  • Transposed convolution is multiplication by \(\mathbf{M}^{\intercal}\). \(n_{\text{out}}=(n-1)s-2p+k\).
  • An affine transformation is a \(3\times3\) matrix. Warps use the inverse map and interpolation.
  • Augmentation supplies the invariance that convolution alone does not.
