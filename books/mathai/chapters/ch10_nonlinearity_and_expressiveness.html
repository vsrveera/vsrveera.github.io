10  Nonlinearity and Expressiveness

NoteKey ideas
  • Linear layers alone collapse into one linear layer. A nonlinear activation between them removes this limit.
  • Common activations: ReLU, sigmoid, tanh, GELU, SiLU. They differ in range, smoothness, and gradient.
  • A ReLU network is piecewise linear: it cuts space into regions and is linear inside each one.
  • Width adds pieces side by side. Depth multiplies them by composition.
  • The wrong activation can saturate or die, and the gradient then vanishes.

10.1 The system problem

Chapter 9 ended with a problem. A stack of linear layers is equal to one linear layer. XOR cannot be learned. Curved boundaries cannot be learned.

Why does a stack of linear layers equal one linear layer, and what is the smallest change that fixes it?

The change is small: apply a simple fixed nonlinear function to each number between the layers.

10.2 The collapse, once more

Chapter 9 showed \(\mathbf{W}_2(\mathbf{W}_{1}\mathbf{x})=(\mathbf{W}_{2}\mathbf{W}_1)\mathbf{x}\). By induction, any depth reduces to a single matrix. The reason is that the product of matrices is a matrix.

The fix: insert a function \(\sigma\) that is not linear, applied element by element:

\[ \mathbf{h}=\sigma(\mathbf{W}_{1}\mathbf{x}+\mathbf{b}_1),\qquad \mathbf{y}=\mathbf{W}_{2}\mathbf{h}+\mathbf{b}_2. \tag{10.1}\]

Now \(\mathbf{y}\) is not a matrix times \(\mathbf{x}\), because \(\sigma\) sits between the two matrices.

10.3 A gallery of activations

Five activations appear in almost all models.

Name Formula Range Where used
ReLU \(\max(0,z)\) \([0,\infty)\) CNNs, many MLPs
Sigmoid \(\dfrac{1}{1+e^{-z}}\) \((0,1)\) gates, binary outputs
Tanh \(\dfrac{e^z-e^{-z}}{e^z+e^{-z}}\) \((-1,1)\) RNNs, small networks
GELU \(z\,\Phi(z)\) \(\approx[-0.17,\infty)\) Transformers (BERT, GPT)
SiLU (swish) \(z\,\sigma(z)\) \(\approx[-0.28,\infty)\) modern LLM MLPs (SwiGLU)

Here \(\Phi\) is the cumulative distribution function of the standard normal distribution. GELU weights its input by the probability that a standard normal variable is smaller than it.

We define them and their derivatives. Then we check each derivative against a finite difference, as in Chapter 1.

from scipy.special import erf

def Phi(z):                                   # normal CDF
    return 0.5 * (1.0 + erf(z / np.sqrt(2.0)))

def phi(z):                                   # normal density
    return np.exp(-0.5 * z ** 2) / np.sqrt(2.0 * np.pi)

sig = lambda z: 1.0 / (1.0 + np.exp(-z))

ACTS = {   # name: (function, derivative)
    "ReLU":    (lambda z: np.maximum(0, z),   lambda z: (z > 0) * 1.0),
    "sigmoid": (sig,                          lambda z: sig(z) * (1 - sig(z))),
    "tanh":    (np.tanh,                      lambda z: 1 - np.tanh(z) ** 2),
    "GELU":    (lambda z: z * Phi(z),         lambda z: Phi(z) + z * phi(z)),
    "SiLU":    (lambda z: z * sig(z),         lambda z: sig(z) + z * sig(z) * (1 - sig(z))),
}

z = np.linspace(-4, 4, 801)
eps = 1e-6

    print(f"{name:8s} max |derivative - finite difference| = "

10.4 Solving XOR by hand

We now solve the problem that a linear model cannot. With two ReLU units we can set the weights by hand.

\[ h_1=\text{ReLU}(x_1+x_2),\qquad h_2=\text{ReLU}(x_1+x_2-1),\qquad y=h_1-2h_2. \tag{10.2}\]

relu = lambda z: np.maximum(0, z)
pts = np.array([[0, 0], [1, 0], [0, 1], [1, 1]], dtype=float)

W1 = np.array([[1.0, 1.0], [1.0, 1.0]]); b1 = np.array([0.0, -1.0])
W2 = np.array([1.0, -2.0])
h = relu(pts @ W1.T + b1)                  # (4, 2)
y = h @ W2                                 # (4,)
for p, hh, yy in zip(pts, h, y):
    print(f"x = {p}   h = {hh}   y = {yy:+.0f}")
x = [0. 0.]   h = [0. 0.]   y = +0
x = [1. 0.]   h = [1. 0.]   y = +1
x = [0. 1.]   h = [1. 0.]   y = +1
x = [1. 1.]   h = [2. 1.]   y = +0

The four points give \(0,1,1,0\). XOR is solved. The hidden layer bends the plane: it maps \((1,1)\) to a point where a line can separate it from \((0,1)\) and \((1,0)\).

10.5 How a ReLU network represents a function

A network with ReLU units is a piecewise linear function. Each unit is linear on each side of its hyperplane, and the sum of such functions is linear on each region.

10.5.1 Width: pieces side by side

In one dimension, a sum of shifted ReLUs makes a polyline:

\[ f(x)=y_0+\sum_{i=1}^{k}c_i\,\text{ReLU}(x-t_i). \tag{10.3}\]

The knots \(t_i\) are where the slope changes, and \(c_i\) is the change in slope. We can choose them to match any target function at the knots. With \(k\) units, the function has \(k+1\) linear pieces. Here we approximate \(\sin\).

def relu_interpolant(target, a, b, k):
    """k ReLU units at equal spacing that interpolate `target` at k+1 points."""
    knots = np.linspace(a, b, k + 1)
    vals = target(knots)
    slopes = np.diff(vals) / np.diff(knots)              # slope on each piece
    c = np.diff(slopes, prepend=0.0)                     # slope changes
    def f(x):
        out = vals[0] + 0.0 * x
        for ci, ti in zip(c, knots[:-1]):
            out = out + ci * np.maximum(0, x - ti)
        return out
    return f

xs = np.linspace(0, 2 * np.pi, 1000)
ks = [2, 4, 8, 16, 32, 64]
errs = [np.max(np.abs(relu_interpolant(np.sin, 0, 2 * np.pi, k)(xs) - np.sin(xs)))
        for k in ks]

fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(10, 3.4))
ax1.plot(xs, np.sin(xs), color="black", lw=2, label="sin x")
for k, col in zip([2, 4, 8], [PALETTE["loss"], PALETTE["model"], PALETTE["grad"]]):
    ax1.plot(xs, relu_interpolant(np.sin, 0, 2 * np.pi, k)(xs), color=col, label=f"k = {k}")
ax1.legend(fontsize=8); ax1.set_xlabel("x")
ax2.loglog(ks, errs, "o-", color=PALETTE["data"], label="max error")
ax2.loglog(ks, [errs[0] * (ks[0] / k) ** 2 for k in ks], "--",
           color=PALETTE["neutral"], label="∝ 1/k²")
ax2.set_xlabel("number of ReLU units k"); ax2.set_ylabel("max |error|"); ax2.legend()
plt.tight_layout(); plt.show()
print("errors:", [f"{e:.4f}" for e in errs])
errors: ['1.0000', '0.2105', '0.0704', '0.0188', '0.0048', '0.0012']

This construction is the core of the universal approximation idea: a network with one hidden layer of enough units can approximate any continuous function on a bounded interval to any accuracy. The theorem says that such a network exists. It does not say how to find it, how large it must be, or that training will find it.

10.5.2 Regions in higher dimension

In 2D, each hidden unit has a boundary line \(\mathbf{w}\cdot\mathbf{x}+b=0\). Together, \(n\) lines cut the plane into regions. In each region the on/off pattern of the units is fixed, so the network is affine there.

\(n\) lines in general position make at most \(1+n+\binom{n}{2}\) regions. We count the regions of random networks by the number of distinct activation patterns.

def count_regions(n, rng, grid=500, lim=3.0):
    W = rng.normal(size=(n, 2)); b = rng.normal(scale=0.6, size=n)
    g = np.linspace(-lim, lim, grid)
    P = np.stack(np.meshgrid(g, g), -1).reshape(-1, 2)
    codes = (P @ W.T + b > 0)                         # (G, n) on/off pattern
    keys = codes.dot(1 << np.arange(n))               # pattern as one integer
    uniq, inv = np.unique(keys, return_inverse=True)
    return len(uniq), inv.reshape(grid, grid)

rng = np.random.default_rng(1)
fig, axes = plt.subplots(1, 2, figsize=(8, 3.8))
for ax, n in zip(axes, [3, 8]):
    n_reg, labels = count_regions(n, rng)
    ax.imshow(labels, extent=(-3, 3, -3, 3), origin="lower", cmap="tab20")
    ax.set_title(f"{n} units: {n_reg} regions (max {1 + n + n * (n - 1) // 2})")
    ax.set_xticks([]); ax.set_yticks([]); ax.grid(False)
plt.tight_layout(); plt.show()

10.5.3 Depth: pieces multiply

Width adds pieces. Composition multiplies them. Take the tent map on \([0,1]\), built from two ReLUs:

\[ \text{tent}(x)=2\,\text{ReLU}(x)-4\,\text{ReLU}\!\left(x-\tfrac12\right). \tag{10.4}\]

It rises from 0 to 1 on \([0,\frac12]\) and falls back on \([\frac12,1]\). Composing it with itself \(k\) times gives a sawtooth with \(2^k\) teeth, using only \(2k\) ReLU units.

tent = lambda x: 2 * np.maximum(0, x) - 4 * np.maximum(0, x - 0.5)
x = np.linspace(0, 1, 2001)
fig, axes = plt.subplots(1, 4, figsize=(11, 2.6))
y = x.copy()
for k, ax in enumerate(axes, start=1):
    y = tent(y)                                       # one more composition
    ax.plot(x, y, color=PALETTE["model"], lw=1.4)
    slopes = np.sign(np.diff(y))
    pieces = 1 + int(np.sum(slopes[1:] != slopes[:-1]))
    ax.set_title(f"depth {k}:  {pieces} pieces,  {2 * k} units", fontsize=9)
    ax.set_xticks([0, 1]); ax.set_yticks([0, 1])
plt.tight_layout(); plt.show()

Real networks do not build sawtooths. The lesson is general: depth gives a number of regions that grows exponentially with the number of layers, while width grows it only polynomially.

10.6 Choosing an activation

ReLU sigmoid / tanh GELU / SiLU
Cost very cheap exponential exponential or erf
Gradient for large \(|z|\) 1 (positive) / 0 → 0 (saturates) ≈ 1 / ≈ 0
Smooth at 0 no yes yes
Risk dead units vanishing gradient small cost
Typical use CNNs, plain MLPs gates, probabilities Transformers, LLMs

Smoothness. ReLU has a kink at 0, where the derivative is undefined. Libraries use 0 or 1 there, and this almost never matters. GELU and SiLU are smooth, which can help optimisation of very deep Transformers.

Why not use sigmoid everywhere? Its maximum derivative is \(0.25\), so the backward signal shrinks by at least \(4\times\) per layer (Chapter 18).

10.7 From first principles to production

PyTorch implements these functions and their derivatives. We check that they agree with ours.

10.8 Failure modes

10.8.1 Saturation

For sigmoid and tanh, large \(|z|\) gives a nearly flat curve. The derivative is almost zero. The backward signal dies, and the weights below that unit hardly change.

for zv in [0.0, 2.0, 5.0, 10.0]:
    print(f"z = {zv:4.1f}   sigmoid'(z) = {ACTS['sigmoid'][1](np.array(zv)):.2e}")
z =  0.0   sigmoid'(z) = 2.50e-01
z =  2.0   sigmoid'(z) = 1.05e-01
z =  5.0   sigmoid'(z) = 6.65e-03
z = 10.0   sigmoid'(z) = 4.54e-05

10.8.2 Dead ReLUs

If a ReLU unit gets \(z\le0\) for every input, its output and its gradient are both zero. Its weights stop changing. The unit is dead for good.

rng = np.random.default_rng(0)
X = rng.uniform(-1, 1, size=(1000, 2))
w_dead, b_dead = np.array([1.0, 1.0]), -10.0         # bias far too negative
z_unit = X @ w_dead + b_dead
print("fraction of inputs with the unit active:", np.mean(z_unit > 0))
print("gradient of the unit w.r.t. its weights: ",
      np.mean((z_unit > 0)[:, None] * X, axis=0))
fraction of inputs with the unit active: 0.0
gradient of the unit w.r.t. its weights:  [0. 0.]

Common causes are a too-large learning rate and a poor initialisation. Remedies: smaller learning rates, careful initialisation (Chapter 20), and “leaky” variants (\(\max(0.01z,z)\)).

10.8.3 Nonlinearity at the output

The last layer usually has no activation, or one matched to the loss: a sigmoid for binary outputs, a softmax for classes (Chapter 24). A ReLU at the output would forbid negative predictions.

10.8.4 Too little or too much

A network with too few nonlinear units underfits. One with too many can fit noise. This trade-off is the subject of Part VII.

10.10 System connection

NoteWhat the system gained in this chapter

The system can now represent curved boundaries and nonlinear functions. The key is one fixed nonlinear function between linear layers. Width adds linear pieces side by side, and depth multiplies them.

We have the two ingredients, \(\mathbf{W}\mathbf{x}+\mathbf{b}\) and \(\sigma\). Chapter 11 assembles them into a complete network and trains it.

Chapter summary

  • Linear layers collapse. A nonlinearity between them prevents this.
  • ReLU, sigmoid, tanh, GELU, and SiLU differ in range, smoothness, and gradient.
  • Two ReLU units solve XOR by hand.
  • A ReLU network is piecewise linear. \(k\) units in 1D make \(k+1\) pieces. \(n\) units in 2D make up to \(1+n+\binom n2\) regions.
  • Depth multiplies pieces. A \(k\)-fold composition of the tent map has \(2^k\) pieces.
  • Universal approximation says a good network exists. It does not say that training finds it.
  • Sigmoid and tanh saturate. ReLU units can die.
