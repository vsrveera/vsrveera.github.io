8  Functions as Machines

NoteKey ideas
  • A function is a rule that gives one output for each input. Think of it as a machine.
  • Machines can be composed: the output of one is the input of the next. A neural network is a composition.
  • A function has an inverse only if it loses no information. Many useful machines lose information on purpose.
  • A parameterized family \(f_\theta\) is a set of functions indexed by numbers. Learning is a search in this family.
  • The loss is a function of the parameters, with the data held fixed.

8.2 Intuition: a function is a machine

A function is a machine with one input slot and one output slot. You put an input in. One output comes out. The same input always gives the same output.

A machine may be simple (add one) or large (a language model). From outside, both have the same form. This is why the language of functions is the right language for AI systems.

8.3 The mathematical object

A function \(f:\mathcal{X}\to\mathcal{Y}\) assigns to every \(x\in\mathcal{X}\) exactly one \(f(x)\in\mathcal{Y}\).

Term Meaning Example: \(f(x)=x^2\) on \(\mathbb{R}\)
Domain \(\mathcal{X}\) allowed inputs all real numbers
Codomain \(\mathcal{Y}\) where outputs are declared to live all real numbers
Range (image) outputs that actually occur \([0,\infty)\)
Graph the set of pairs \((x,f(x))\) a parabola

In AI the inputs and outputs are vectors, so most functions have the form \(f:\mathbb{R}^{n}\to\mathbb{R}^m\). A function of this kind is just \(m\) scalar functions that share the same input. Chapter 17 studies how to differentiate such functions.

8.4 Operations on functions

8.4.1 Composition

Given \(f:\mathcal{X}\to\mathcal{Y}\) and \(g:\mathcal{Y}\to\mathcal{Z}\), the composition \(g\circ f\) applies \(f\) first:

\[ (g\circ f)(x)=g\bigl(f(x)\bigr). \tag{8.1}\]

The codomain of \(f\) must match the domain of \(g\). For vector functions this is the shape rule of Chapter 2: the output size of \(f\) must equal the input size of \(g\).

Composition is associative: \(h\circ(g\circ f)=(h\circ g)\circ f\). So we may write \(h\circ g\circ f\) with no brackets.

TipProof of associativity

Apply both sides to any \(x\): \[ \bigl(h\circ(g\circ f)\bigr)(x)=h\bigl((g\circ f)(x)\bigr)=h\bigl(g(f(x))\bigr)=(h\circ g)\bigl(f(x)\bigr)=\bigl((h\circ g)\circ f\bigr)(x).\ \blacksquare \]

Composition is not commutative: \(g\circ f\neq f\circ g\) in general.

A neural network is a composition of layer functions:

\[ f_\theta=f_{L}\circ f_{L-1}\circ\dots\circ f_1. \tag{8.2}\]

We now build composition in code and test associativity.

def compose(*fs):
    """compose(h, g, f)(x) == h(g(f(x)))  -- the rightmost function runs first."""
    def composed(x):
        for f in reversed(fs):
            x = f(x)
        return x
    return composed

f = lambda x: 0.5 * x ** 2 - 1.0
g = np.tanh
h = lambda x: 3.0 * x + 2.0

xs = np.linspace(-3, 3, 7)
left  = compose(h, compose(g, f))(xs)
right = compose(compose(h, g), f)(xs)
print("associative:", np.allclose(left, right))
print("commutative:", np.allclose(compose(g, f)(xs), compose(f, g)(xs)))
associative: True
commutative: False
x = np.linspace(-3, 3, 400)
fig, ax = plt.subplots()
ax.plot(x, f(x), color=PALETTE["data"], label="f(x) = x²/2 − 1")
ax.plot(x, g(x), color=PALETTE["prob"], label="g(x) = tanh x")
ax.plot(x, compose(g, f)(x), color=PALETTE["model"], lw=2.5, label="g∘f")
ax.set_ylim(-1.5, 3.5); ax.legend(fontsize=9); ax.set_xlabel("x")
plt.show()

8.4.2 Identity and inverse

The identity \(\text{id}(x)=x\) does nothing. An inverse \(f^{-1}\) undoes \(f\):

\[ f^{-1}\circ f=\text{id}. \tag{8.3}\]

Not every function has one. Two properties decide it.

Property Definition Meaning
Injective (one-to-one) \(f(a)=f(b)\Rightarrow a=b\) different inputs give different outputs
Surjective (onto) every \(y\in\mathcal{Y}\) is some \(f(x)\) every output is reached
Bijective both an inverse exists
TipWhy a non-injective function has no inverse

Suppose \(f(a)=f(b)=y\) with \(a\ne b\). A left inverse \(g\) would need \(g(y)=g(f(a))=a\) and also \(g(y)=g(f(b))=b\). But \(a\ne b\). No single value \(g(y)\) can do both. \(\blacksquare\)

For compositions, inverses undo in reverse order: \((g\circ f)^{-1}=f^{-1}\circ g^{-1}\). You take off your shoes before your socks only if you put on socks before shoes. This is the same pattern as \((\mathbf{AB})^{\intercal}=\mathbf{B}^{\intercal}\mathbf{A}^{\intercal}\) in Chapter 5.

8.4.3 Linear and nonlinear

A function is linear if \(f(a\mathbf{x}+b\mathbf{y})=af(\mathbf{x})+bf(\mathbf{y})\). Matrices are exactly the linear functions on vectors (Chapter 5). All other functions are nonlinear. We study the simplest linear case in Chapter 9 and the nonlinear case in Chapter 10.

8.5 Parameterized families

A model is not one function. It is a family of functions, selected by parameters \(\theta\):

\[ \mathcal{F}=\{f_\theta:\theta\in\Theta\}. \tag{8.4}\]

In code, a parameterized function is a closure: a function that returns a function.

def make_f(a, b, c):
    """Return the function f_theta with theta = (a, b, c)."""
    return lambda x: a * np.tanh(b * x) + c

x = np.linspace(-3, 3, 300)
fig, ax = plt.subplots()
for theta in [(1.0, 1.0, 0.0), (2.0, 0.5, 0.0), (1.0, 4.0, 0.0),
              (1.0, 1.0, 1.5), (-1.5, 1.0, 0.0)]:
    ax.plot(x, make_f(*theta)(x), label=f"θ = {theta}")
ax.legend(fontsize=8); ax.set_xlabel("x")
plt.show()

8.5.1 The loss is a function of the parameters

There are two ways to look at \(f_\theta(x)\).

  • Fix \(\theta\) and vary \(x\): a function of the input. This is inference.
  • Fix the data \(x\) and vary \(\theta\): a function of the parameters. This is what training optimises.

The loss \(L(\theta)=\frac1N\sum_{i}\ell(f_\theta(x_i),y_i)\) is of the second kind. The data is held fixed. The parameters are the argument. This switch of viewpoint is the core of learning.

rng = np.random.default_rng(0)
xd = rng.uniform(-2, 2, 30)
yd = 2.0 * xd + 1.0 + rng.normal(0, 0.5, 30)

def loss(a, b):                      # data (xd, yd) is fixed inside
    pred = a * xd[:, None, None] + b           # (30, 200, 200)
    return np.mean((pred - yd[:, None, None]) ** 2, axis=0)

A_, B_ = np.meshgrid(np.linspace(-1, 5, 200), np.linspace(-3, 5, 200))
Lz = loss(A_, B_)
fig, ax = plt.subplots(figsize=(5.4, 4.2))
cs = ax.contour(A_, B_, Lz, levels=15, cmap="viridis")
ax.plot([2], [1], "*", color=PALETTE["loss"], ms=14)
ax.set_xlabel("slope a"); ax.set_ylabel("offset b")
plt.show()

8.6 Geometry: what maps do to space

For maps of the plane, we can see the function by watching what it does to a grid. Linear maps keep grid lines straight (Chapter 5). Nonlinear maps bend them. Maps that lose information fold or flatten them.

We compare four maps \(\mathbb{R}^{2}\to\mathbb{R}^2\).

Map Rule Invertible?
Bend \((x,y)\mapsto(x,\ y+0.4x^2)\) yes: \(v\mapsto v-0.4u^2\)
Squash \((x,y)\mapsto(\tanh x,\ \tanh y)\) yes, onto \((-1,1)^2\)
Fold \((x,y)\mapsto(|x|,\ y)\) no: \(x\) and \(-x\) collide
ReLU \((x,y)\mapsto(\max(0,x),\max(0,y))\) no: a whole quadrant collapses 
maps = {
    "bend":   lambda x, y: (x, y + 0.4 * x ** 2),
    "squash": lambda x, y: (np.tanh(x), np.tanh(y)),
    "fold":   lambda x, y: (np.abs(x), y),
    "ReLU":   lambda x, y: (np.maximum(0, x), np.maximum(0, y)),
}
fig, axes = plt.subplots(1, 4, figsize=(11, 3.0))
for ax, (name, fn) in zip(axes, maps.items()):
    ok = name in ("bend", "squash")              # invertible maps in green
    warp_fn(ax, fn, extent=2.0, title=name,
            color=PALETTE["grad"] if ok else PALETTE["loss"])
plt.tight_layout(); plt.show()

We confirm in code that the first two can be undone and the last two cannot.

rng = np.random.default_rng(0)
P = rng.uniform(-2, 2, size=(1000, 2))                      # random points

bend_inv   = lambda u, v: (u, v - 0.4 * u ** 2)
squash_inv = lambda u, v: (np.arctanh(u), np.arctanh(v))

for name, fwd, inv in [("bend", maps["bend"], bend_inv),
                       ("squash", maps["squash"], squash_inv)]:
    u, v = fwd(P[:, 0], P[:, 1]); xr, yr = inv(u, v)
    print(f"{name:7s} round-trip error: {np.max(np.abs(xr - P[:, 0])):.1e}")

# fold: both x and -x give the same output, so no inverse can recover the sign
u1, _ = maps["fold"](np.array([1.5]), np.array([0.0]))
u2, _ = maps["fold"](np.array([-1.5]), np.array([0.0]))
print("fold:   f(1.5, 0) and f(-1.5, 0) first coordinates:", u1[0], u2[0])
bend    round-trip error: 0.0e+00
squash  round-trip error: 1.1e-15
fold:   f(1.5, 0) and f(-1.5, 0) first coordinates: 1.5 1.5

8.7 Computation: models are callables

A model is a function in the programming sense, too. In PyTorch, nn.Sequential is literally composition:

import torch
import torch.nn as nn

torch.manual_seed(0)
f1, f2, f3 = nn.Linear(4, 8), nn.Tanh(), nn.Linear(8, 2)

seq = nn.Sequential(f1, f2, f3)                           # f3 ∘ f2 ∘ f1
x_in = torch.randn(5, 4)

by_hand = f3(f2(f1(x_in)))
print("Sequential == f3(f2(f1(x)))  :", torch.allclose(seq(x_in), by_hand))
print("shape rule: 4 -> 8 -> 8 -> 2, output:", tuple(seq(x_in).shape))
Sequential == f3(f2(f1(x)))  : True
shape rule: 4 -> 8 -> 8 -> 2, output: (5, 2)

Shape mismatches are composition errors: the output size of one layer must equal the input size of the next.

try:
    nn.Sequential(nn.Linear(4, 8), nn.Linear(6, 2))(x_in)    # 8 != 6
except RuntimeError as e:
    print("RuntimeError:", str(e)[:70], "...")
RuntimeError: mat1 and mat2 shapes cannot be multiplied (5x8 and 6x2) ...

8.8 Information loss on purpose

A classifier maps 64 pixel values to one of 10 labels. This map is many-to-one by design. Millions of different images get the same label. The classifier is not invertible, and it should not be: it throws away everything except class evidence.

from sklearn.datasets import load_digits
digits = load_digits()
X, y = digits.data, digits.target

means = np.array([X[y == c].mean(axis=0) for c in range(10)])           # (10, 64)
Xn = X / np.linalg.norm(X, axis=1, keepdims=True)
Mn = means / np.linalg.norm(means, axis=1, keepdims=True)
pred = (Xn @ Mn.T).argmax(axis=1)           # f: R^64 -> {0..9}

print(f"accuracy of this simple classifier: {np.mean(pred == y):.3f}")
same = np.where(pred == 3)[0]
print(f"images mapped to class 3: {len(same)}; distinct pixel vectors: "
      f"{len({tuple(r) for r in X[same]})}")
accuracy of this simple classifier: 0.906
images mapped to class 3: 167; distinct pixel vectors: 167

The consequence is general: a trained classifier cannot recover its input from its output. Information has been discarded. Each layer in a network may add information-losing steps such as ReLU or pooling.

8.9 Failure modes

Outside the domain. Some functions are defined only on part of \(\mathbb{R}\). log(0), sqrt(-1), and 1/0 give -inf, nan, or inf. These values spread through a whole computation.

with np.errstate(all="ignore"):
    print("log(0)    =", np.log(0.0))
    print("sqrt(-1)  =", np.sqrt(-1.0))
    print("1/0       =", np.float64(1.0) / 0.0)
    print("0 * log(0) =", 0.0 * np.log(0.0), "  (needs a convention, Ch. 15)")
log(0)    = -inf
sqrt(-1)  = nan
1/0       = inf
0 * log(0) = nan   (needs a convention, Ch. 15)

Discontinuous functions. floor, argmax, and thresholds jump. Small input changes can give large output changes. Their derivative is zero almost everywhere, so gradients cannot flow through them. This is why classifiers output probabilities (via softmax, Chapter 24) and not the argmax during training.

Loss of invertibility. Do not assume that a hidden representation can be mapped back to the input. Some architectures (normalising flows, Chapter 43) are built to stay invertible. Most are not.

Hidden dependence on parameters. A function that looks like it only depends on \(x\) may depend on global state (random seeds, dropout, batch statistics). Then equal inputs give different outputs. Mathematical functions have no such hidden state. Code must be careful to match them.

8.11 System connection

NoteWhat the system gained in this chapter

The system now has the vocabulary of transformation: a model is a function, a network is a composition, a family is selected by parameters, and training views the loss as a function of the parameters. We know that a map may lose information and when it may be undone.

We have not yet chosen which functions to compose. The simplest building block is the linear function. Chapter 9 studies it.

Chapter summary

  • A function \(f:\mathcal{X}\to\mathcal{Y}\) gives one output for each input. Domain, codomain, and range describe it.
  • Composition \(g\circ f\) applies \(f\) first. It is associative and not commutative.
  • An inverse exists only for bijections. Inverses of compositions reverse the order.
  • A model is a parameterized family \(f_\theta\). In code it is a closure.
  • Training treats the loss as a function of \(\theta\) with the data fixed.
  • Maps of the plane can be pictured by their effect on a grid: bend, squash, fold, collapse.
  • A network is \(f_{L}\circ\dots\circ f_1\), and shape mismatches are composition errors.
  • Invalid domains (log 0) and jumps (argmax) break computation and gradients.

Exercises

  1. Compose. For \(f(x)=2x+1\) and \(g(x)=x^2\), compute \(g\circ f\) and \(f\circ g\). Show they are different.
  2. Invert. Find the inverse of \(f(x)=\frac{x-3}{2}\). Verify \(f^{-1}\circ f=\text{id}\).
  3. Classify. Is \(f(x)=x^3\) injective? Surjective on \(\mathbb{R}\)? Is \(f(x)=e^x\) surjective onto \(\mathbb{R}\)?
  4. Prove. If \(f\) and \(g\) are injective, then \(g\circ f\) is injective.
  5. Prove. Show that ReLU applied element-wise on \(\mathbb{R}^n\) is not injective for any \(n\ge1\).
  6. Code. Write make_layer(W, b, act) that returns the function \(\mathbf{x}\mapsto\text{act}(\mathbf{W}\mathbf{x}+\mathbf{b})\). Compose three layers and check the shapes.
  7. Code. Add the “swirl” map \((x,y)\mapsto(x\cos r-y\sin r,\ x\sin r+y\cos r)\) with \(r=\sqrt{x^2+y^2}\) to the grid figure. Is it invertible?
  8. Code. Plot \(L(a)\) for a one-parameter model \(f_a(x)=a\,x\) on the data of this chapter. Where is its minimum?
  9. Diagnose. A function f(x) returns different values for the same x on two calls. List three possible causes in a deep learning program.
  10. Explain. Why is it acceptable that a classifier is not invertible? Give one example in which an invertible model is required.
