44  One AI System, All the Mathematics

NoteKey ideas
  • Every system in this book is the same chain: data → representation → model → loss → gradient → update → deployment.
  • A small model written from first principles contains every step. A Transformer language model repeats the same few operations at larger scale.
  • For any model we can count: parameters, floating-point operations (FLOPs), and memory. These counts follow from shapes.
  • A new architecture can be read by decomposition: name each operation, its shapes, and the chapter that explains it.

44.1 The system problem

This is the last chapter of the mathematics. It does not introduce a new tool. It asks whether the tools fit together. Part IX then turns to the question of how to know that a system built from these tools meets its requirement.

Can we take any AI system, name every mathematical operation inside it, and say where each one comes from?

We answer in three steps. First, a very small model, with every step written out and checked. Second, a tiny GPT, written with explicit operations and trained on characters. Third, tools that count what a model costs and a method that reads any architecture.

44.2 The smallest complete system

A classifier for two-dimensional points. The chain is

\[ \mathbf{x}\ \xrightarrow{\ \mathbf{W}_{1}\mathbf{x}+\mathbf{b}_1\ }\ \mathbf{z}\ \xrightarrow{\ \sigma\ }\ \mathbf{h}\ \xrightarrow{\ \mathbf{w}_2^{\intercal}\mathbf{h}+b_2\ }\ s\ \xrightarrow{\ \text{sigmoid}\ }\ \hat y\ \xrightarrow{\ \text{cross-entropy}\ }\ L\ \xrightarrow{\ \nabla\ }\ \nabla_\theta L\ \xrightarrow{\ -\eta\nabla\ }\ \theta'. \tag{44.1}\]

Each arrow is a chapter: matrix-vector product (Chapter 5), a nonlinearity (Chapters 10 and 11), a probability (Chapter 24), a loss (Chapters 14 and 25), the chain rule (Chapters 16 and 18), and the update (Chapter 19). We write the backward pass by hand and check it against finite differences.

from sklearn.datasets import make_moons
rng = np.random.default_rng(0)
X, y = make_moons(400, noise=0.15, random_state=0)
H = 16
params = {"W1": rng.normal(0, 0.7, (H, 2)), "b1": np.zeros(H),
          "w2": rng.normal(0, 0.7, H), "b2": np.array(0.0)}

def forward(p, X):
    z = X @ p["W1"].T + p["b1"]          # (n, H)   affine
    h = np.tanh(z)                       # (n, H)   nonlinearity
    s = h @ p["w2"] + p["b2"]            # (n,)     score
    yhat = 1 / (1 + np.exp(-s))          # (n,)     probability
    return z, h, s, yhat

def loss_fn(p, X, y):
    yhat = forward(p, X)[3]
    return -np.mean(y * np.log(yhat + 1e-12) + (1 - y) * np.log(1 - yhat + 1e-12))

def backward(p, X, y):
    z, h, s, yhat = forward(p, X); n = len(y)
    ds = (yhat - y) / n                                  # d loss / d score (sigmoid + cross-entropy)
    g = {"w2": h.T @ ds, "b2": ds.sum()}
    dh = np.outer(ds, p["w2"])                           # (n, H)
    dz = dh * (1 - h ** 2)                               # tanh'
    g["W1"] = dz.T @ X; g["b1"] = dz.sum(0)
    return g

# gradient check against central finite differences
g = backward(params, X, y); worst = 0.0
for name, arr in params.items():
    a = np.atleast_1d(arr)
    for idx in np.ndindex(a.shape):
        old = a[idx]
        a[idx] = old + 1e-5; lp = loss_fn(params, X, y)
        a[idx] = old - 1e-5; lm_ = loss_fn(params, X, y)
        a[idx] = old
        num = (lp - lm_) / 2e-5
        ana = np.atleast_1d(g[name])[idx]
        worst = max(worst, abs(num - ana) / (abs(num) + abs(ana) + 1e-12))
print(f"gradient check: worst relative error over all {sum(np.size(v) for v in params.values())} parameters = {worst:.1e}")

eta = 0.5
for step in range(2001):
    g = backward(params, X, y)
    for k in params: params[k] = params[k] - eta * g[k]
    if step in (0, 100, 500, 2000):
        acc = ((forward(params, X)[3] > 0.5) == y).mean()
        print(f"step {step:5d}  loss {loss_fn(params, X, y):.3f}  accuracy {acc:.3f}")
gradient check: worst relative error over all 65 parameters = 4.2e-09
step     0  loss 0.848  accuracy 0.285
step   100  loss 0.231  accuracy 0.905
step   500  loss 0.079  accuracy 0.973

44.3 A tiny GPT, from explicit operations

The language model of Chapters 31–33, written without nn.Module for attention. Every operation is a line. The parameters are one flat dictionary of tensors.

\[ \begin{aligned} \mathbf{X}_0&=\mathbf{E}[\text{ids}]+\mathbf{P}\\ \mathbf{X}_{\ell+1}&=\mathbf{X}_\ell'+\text{MLP}\bigl(\text{LN}(\mathbf{X}_\ell')\bigr),\quad \mathbf{X}_\ell'=\mathbf{X}_\ell+\text{MHA}\bigl(\text{LN}(\mathbf{X}_\ell)\bigr)\\ \text{logits}&=\text{LN}(\mathbf{X}_L)\,\mathbf{E}^{\intercal} \end{aligned} \tag{44.2}\]

import torch, torch.nn.functional as F
from pydoc_data import topics

raw = " ".join(topics.topics[k] for k in sorted(topics.topics)).lower()
keep = set("abcdefghijklmnopqrstuvwxyz .,\n")
text = " ".join("".join(c if c in keep else " " for c in raw).split())[:200_000]
chars = sorted(set(text)); V = len(chars); ix = {c: i for i, c in enumerate(chars)}
data = torch.tensor([ix[c] for c in text]); n_tr = int(0.9 * len(data))
train_data, val_data = data[:n_tr], data[n_tr:]

def init_params(V, T, d, L, dtype=torch.float32, seed=0):
    g = torch.Generator().manual_seed(seed)
    rn = lambda *s: (torch.randn(*s, generator=g) * 0.02).to(dtype).requires_grad_()
    z = lambda *s: torch.zeros(*s, dtype=dtype).requires_grad_()
    o = lambda *s: torch.ones(*s, dtype=dtype).requires_grad_()
    p = {"E": rn(V, d), "P": rn(T, d), "lnf_g": o(d), "lnf_b": z(d)}
    for l in range(L):
        p.update({f"{l}.ln1_g": o(d), f"{l}.ln1_b": z(d), f"{l}.Wqkv": rn(d, 3 * d), f"{l}.bqkv": z(3 * d),
                  f"{l}.Wo": rn(d, d), f"{l}.bo": z(d), f"{l}.ln2_g": o(d), f"{l}.ln2_b": z(d),
                  f"{l}.W1": rn(d, 4 * d), f"{l}.b1": z(4 * d), f"{l}.W2": rn(4 * d, d), f"{l}.b2": z(d)})
    return p

def layer_norm(x, g, b, eps=1e-5):
    mu = x.mean(-1, keepdim=True); var = ((x - mu) ** 2).mean(-1, keepdim=True)
    return (x - mu) / torch.sqrt(var + eps) * g + b

def gpt_forward(p, ids, L, n_heads):
    B, T = ids.shape; d = p["E"].shape[1]; dh = d // n_heads
    x = p["E"][ids] + p["P"][:T]                                    # (B, T, d)
    mask = torch.tril(torch.ones(T, T, dtype=torch.bool))
    for l in range(L):
        h = layer_norm(x, p[f"{l}.ln1_g"], p[f"{l}.ln1_b"])
        q, k, v = (h @ p[f"{l}.Wqkv"] + p[f"{l}.bqkv"]).chunk(3, dim=-1)
        sp = lambda t: t.reshape(B, T, n_heads, dh).transpose(1, 2)  # (B, H, T, dh)
        scores = (sp(q) @ sp(k).transpose(-1, -2)) / math.sqrt(dh)   # (B, H, T, T)
        att = torch.softmax(scores.masked_fill(~mask, float("-inf")), dim=-1)
        o = (att @ sp(v)).transpose(1, 2).reshape(B, T, d)
        x = x + o @ p[f"{l}.Wo"] + p[f"{l}.bo"]
        h = layer_norm(x, p[f"{l}.ln2_g"], p[f"{l}.ln2_b"])
        x = x + F.gelu(h @ p[f"{l}.W1"] + p[f"{l}.b1"]) @ p[f"{l}.W2"] + p[f"{l}.b2"]
    return layer_norm(x, p["lnf_g"], p["lnf_b"]) @ p["E"].T          # (B, T, V)

def lm_loss(p, batch, L, n_heads):
    logits = gpt_forward(p, batch[:, :-1], L, n_heads)
    return F.cross_entropy(logits.reshape(-1, logits.shape[-1]), batch[:, 1:].reshape(-1))

44.3.1 Check the gradient

Autograd computes the gradient of a very long chain. We check it against central differences, in 64-bit arithmetic, on a very small instance (so that finite differences are affordable). We test three random entries of every tensor.

Vt, Tt, dt_, Lt, ht = 7, 6, 8, 2, 2
pc = init_params(Vt, Tt, dt_, Lt, dtype=torch.float64, seed=1)
for t in pc.values():                      # larger random values so no gradient is trivially zero
    t.data += 0.3 * torch.randn_like(t)
batch = torch.randint(0, Vt, (3, Tt + 1))
loss0 = lm_loss(pc, batch, Lt, ht); loss0.backward()
gen = torch.Generator().manual_seed(5); worst = 0.0; checked = 0
for name, t in pc.items():
    flat = t.data.view(-1); gflat = t.grad.view(-1)
    for j in torch.randint(0, flat.numel(), (3,), generator=gen).tolist():
        old = flat[j].item(); e = 1e-6
        flat[j] = old + e; lp = lm_loss(pc, batch, Lt, ht).item()
        flat[j] = old - e; lm_v = lm_loss(pc, batch, Lt, ht).item()
        flat[j] = old
        num = (lp - lm_v) / (2 * e); ana = gflat[j].item()
        worst = max(worst, abs(num - ana) / (abs(num) + abs(ana) + 1e-12)); checked += 1
print(f"{len(pc)} tensors, {checked} entries checked; worst relative error {worst:.1e}")
28 tensors, 84 entries checked; worst relative error 5.2e-05

44.4 Counting: parameters, FLOPs, memory

Shapes alone tell us what a model costs. We derive the counts and then check them against the code.

Parameters. With vocabulary \(V\), context \(T\), width \(d\), \(L\) layers (the formula of Chapter 31):

\[ N=Vd+Td+L\,(12d^2+13d)+2d. \tag{44.3}\]

FLOPs of one forward pass over a sequence of \(T\) tokens, counting a multiply-add as 2 FLOPs and including only matrix products. Per layer: the QKV projection \(2T\cdot d\cdot3d\), the scores \(2T^2d\), the weighted values \(2T^2d\), the output projection \(2Td^2\), and the MLP \(2\cdot2T\cdot d\cdot4d\):

\[ F_{\text{layer}}=24\,Td^2+4\,T^2d,\qquad F=L\,F_{\text{layer}}+2TdV. \tag{44.4}\]

Memory. Training with Adam in 32-bit floats holds the parameters, the gradients, and two Adam moments: \(4N\) numbers, \(16N\) bytes. Activations come in addition and scale with batch size.

from torch.utils.flop_counter import FlopCounterMode
N_actual = sum(t.numel() for t in p.values())
N_formula = V * d + T_ctx * d + n_layers * (12 * d * d + 13 * d) + 2 * d
print(f"parameters: counted {N_actual:,}   formula {N_formula:,}")

T = T_ctx
F_formula = n_layers * (24 * T * d * d + 4 * T * T * d) + 2 * T * d * V
ids = torch.randint(0, V, (1, T))
with FlopCounterMode(display=False) as fc, torch.no_grad():

44.7 Decompose this architecture

Here is a description of a model the book has not discussed:

Model Z. An audio clip is turned into a spectrogram (a 2-D array, frequency × time). The spectrogram is cut into non-overlapping 16×16 patches, each flattened and projected linearly to a vector. A learned class vector is prepended, and learned position vectors are added. Twelve Transformer encoder blocks follow. The class vector’s final state goes through a linear layer to 527 sigmoid outputs, one per sound event type. Training minimises binary cross-entropy against multi-label annotations, with Adam and a warm-up and cosine learning-rate schedule.

Try to name each operation and chapter before you read on.

Spectrogram fixed linear map (a Fourier transform, not developed in this book); 2-D array 6, 9
16×16 patches + linear projection reshape; a strided convolution 6, 12, 36
Class vector + position vectors learned embeddings, as in a ViT 36
Twelve encoder blocks bidirectional self-attention, LayerNorm, MLP, residuals 30, 31
Linear layer + 527 sigmoids independent Bernoulli outputs (multi-label) 23, 24
Binary cross-entropy negative log-likelihood of Bernoullis 14, 25
Adam, warm-up, cosine optimiser and schedule 19, 20

It is a vision Transformer (Chapter 36) on a time–frequency image. It contains no operation the book has not treated.

44.8 What to do when it does not work

The same checklist works for the whole book.

Symptom Likely place Chapter
Loss is nan or explodes step too large; missing normalisation; low precision 19, 31, 34
Loss does not decrease wrong gradient; wrong labels; step too small 18, 19
Train loss low, validation high overfitting; leakage 27, 28
Both losses high model too small; features missing; under-training 27, 34
Outputs repeat decoding rule, not the model 33
Shapes mismatch broadcast rules; wrong axis in softmax or norm 5, 30
Result differs between runs seeds; non-deterministic kernels; float order 34

The first step is always the same: shrink the problem until it can be checked by hand, as in the gradient check above.

NoteWhat the system gained in this chapter

Nothing new. The chapter shows that the book’s system map is complete enough: a small model and a tiny GPT were written out in full, their gradients were checked, their costs were counted and compared with formulas, and an unfamiliar architecture was decomposed into parts the book already covers.
