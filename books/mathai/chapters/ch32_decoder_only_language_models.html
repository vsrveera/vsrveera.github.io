32  Decoder-only Language Models

NoteKey ideas
  • A modern decoder-only model (GPT, Llama) is the Chapter 31 block with four changes: RoPE for positions, RMSNorm, a gated SwiGLU MLP, and grouped-query attention.
  • RoPE rotates query and key vectors by an angle proportional to position, so the attention score depends only on the relative offset.
  • RMSNorm drops the mean subtraction of LayerNorm. SwiGLU multiplies a SiLU-gated branch with a linear branch.
  • The KV cache stores past keys and values, so each new token costs \(O(T)\) instead of \(O(T^2)\).
  • The output head can reuse the embedding matrix (weight tying): \(\text{logits}=\mathbf{h}\mathbf{E}^{\intercal}\).

32.3 Tokens: byte-pair encoding

A language model does not read characters or words, but tokens: frequent pieces of text. Byte-pair encoding (BPE) builds the vocabulary by repeatedly merging the most frequent adjacent pair of symbols in a training corpus.

from collections import Counter
corpus = {"low": 5, "lower": 2, "newest": 6, "widest": 3}
words = {tuple(w) + ("</w>",): f for w, f in corpus.items()}

def pair_counts(words):
    c = Counter()
    for w, f in words.items():
        for a, b in zip(w[:-1], w[1:]):
            c[(a, b)] += f
    return c

def merge(words, pair):
    out = {}
    for w, f in words.items():
        new, i = [], 0
        while i < len(w):
            if i < len(w) - 1 and (w[i], w[i + 1]) == pair:
                new.append(w[i] + w[i + 1]); i += 2
            else:
                new.append(w[i]); i += 1
        out[tuple(new)] = f
    return out

merges = []
for _ in range(10):
    pc = pair_counts(words)
    best = max(pc, key=pc.get)
    words = merge(words, best); merges.append(best)
print("merges learned:", [a + b for a, b in merges])
print("vocabulary of pieces now used:", sorted({p for w in words for p in w}))
merges learned: ['es', 'est', 'est</w>', 'lo', 'low', 'ne', 'new', 'newest</w>', 'low</w>', 'wi']
vocabulary of pieces now used: ['</w>', 'd', 'e', 'est</w>', 'low', 'low</w>', 'newest</w>', 'r', 'wi']

Frequent words become single tokens. Rare words split into pieces. The vocabulary \(V\) is typically 32,000–256,000 tokens. Each token id indexes a row of the embedding matrix \(\mathbf{E}\in\mathbb{R}^{V\times d}\) (Chapter 3).

32.4 RoPE: positions as rotations

Chapter 31 added a position vector to the input. Rotary position embedding (RoPE) instead rotates the query and key vectors inside each attention layer, by an angle that grows with position.

Split a vector into pairs of coordinates. Treat each pair as a point in a plane. For position \(m\), rotate the \(i\)-th pair by the angle \(m\theta_i\), with \(\theta_i=10000^{-2i/d_h}\):

\[ \mathbf{R}_{m}=\text{blockdiag}\Bigl(\begin{pmatrix}\cos m\theta_i&-\sin m\theta_i\\\sin m\theta_i&\cos m\theta_{i}\end{pmatrix}\Bigr)_{i=0}^{d_h/2-1}. \tag{32.1}\]

Queries and keys at position \(m\) and \(n\) become \(\mathbf{R}_{m}\mathbf{q}\) and \(\mathbf{R}_{n}\mathbf{k}\).

TipDerivation: the score depends only on the offset

Rotation matrices satisfy \(\mathbf{R}_m^{\intercal}=\mathbf{R}_{-m}\) and \(\mathbf{R}_{a}\mathbf{R}_b=\mathbf{R}_{a+b}\) (Chapter 5: a rotation by \(a\) then by \(b\) is a rotation by \(a+b\)). So \[ (\mathbf{R}_{m}\mathbf{q})\cdot(\mathbf{R}_{n}\mathbf{k})=\mathbf{q}^{\intercal}\mathbf{R}_m^{\intercal}\mathbf{R}_n\,\mathbf{k}=\mathbf{q}^{\intercal}\mathbf{R}_{n-m}\,\mathbf{k}. \] The attention score depends on the content \(\mathbf{q},\mathbf{k}\) and on the relative offset \(n-m\), and not on the absolute positions. \(\blacksquare\)

Rotations preserve length (Chapter 4), so RoPE changes no norms. It carries only angle information.

def rope(x, positions, base=10000.0):
    """x: (T, d) with d even; positions: (T,) -> rotated x."""
    T, d = x.shape
    theta = base ** (-np.arange(0, d, 2) / d)                   # (d/2,)
    ang = positions[:, None] * theta[None, :]                   # (T, d/2)
    c, s = np.cos(ang), np.sin(ang)
    x1, x2 = x[:, 0::2], x[:, 1::2]
    out = np.empty_like(x)
    out[:, 0::2] = x1 * c - x2 * s
    out[:, 1::2] = x1 * s + x2 * c
    return out

32.5 RMSNorm

LayerNorm (Chapter 20) subtracts the mean and divides by the standard deviation. RMSNorm divides only by the root mean square:

\[ \text{RMSNorm}(\mathbf{x})=\frac{\mathbf{x}}{\sqrt{\tfrac1d\sum_ix_i^2+\epsilon}}\odot\mathbf{g}. \tag{32.2}\]

It has no mean statistic and no bias, so it is cheaper, and it is as effective in practice. For a vector with zero mean it equals LayerNorm without its shift.

def layernorm(x, eps=1e-6):
    mu = x.mean(-1, keepdims=True); v = x.var(-1, keepdims=True)
    return (x - mu) / np.sqrt(v + eps)

def rmsnorm(x, eps=1e-6):
    return x / np.sqrt((x ** 2).mean(-1, keepdims=True) + eps)

x = rng.normal(size=(4, 64))
x0 = x - x.mean(-1, keepdims=True)                         # zero-mean rows
print("equal when the mean is zero  :", np.allclose(layernorm(x0), rmsnorm(x0), atol=1e-4))
xs = x + 5.0                                                # large common offset
print("differ when there is an offset:", not np.allclose(layernorm(xs), rmsnorm(xs), atol=1e-2))
print("RMS of the output is 1       :", np.round(np.sqrt((rmsnorm(xs) ** 2).mean(-1)), 3))

32.6 SwiGLU

A gated linear unit multiplies two projections of the input element-wise: one passes through an activation and acts as a gate for the other. With the SiLU activation (Chapter 10), the MLP becomes

\[ \text{SwiGLU}(\mathbf{x})=\mathbf{W}_{2}\Bigl(\text{SiLU}(\mathbf{W}_{1}\mathbf{x})\odot(\mathbf{W}_{3}\mathbf{x})\Bigr),\qquad\text{SiLU}(z)=z\,\sigma(z). \tag{32.3}\]

It has three matrices instead of two. To keep the parameter count of the standard MLP (\(2\cdot d\cdot4d=8d^2\)), the hidden size is reduced to \(\frac83d\):

\[ 3\cdot d\cdot\tfrac83d=8d^2. \]

The gate lets the network switch features on and off per token, a multiplicative interaction that a plain MLP only approximates. Empirically it gives a better loss at equal parameters.

d = 4096
hid_std = 4 * d

print("difference: {:.2%}".format(abs(3 * d * hid_glu - 2 * d * hid_std) / (2 * d * hid_std)))

32.7 Grouped-query attention and the KV cache

During generation, the keys and values of all past tokens are needed at every step. Recomputing them is wasteful. The KV cache stores them. Each new token only computes its own \(\mathbf{q},\mathbf{k},\mathbf{v}\), appends \(\mathbf{k},\mathbf{v}\) to the cache, and attends over the cache.

The cache holds \(2\cdot L\cdot T\cdot n_{\text{kv}}\cdot d_h\) numbers. It grows with the context length and can dominate memory. Grouped-query attention (GQA) uses fewer key/value heads \(n_{\text{kv}}\) than query heads \(h\). Several query heads share one key/value head. It shrinks the cache by \(h/n_{\text{kv}}\) with a small loss in quality.

def kv_bytes(L, T, n_kv, dh, bytes_per=2):
    return 2 * L * T * n_kv * dh * bytes_per

L_, h_, dh_, T_ = 32, 32, 128, 8192                       # a 7B-class shape, 8k context, fp16
for name, n_kv in [("multi-head (32 KV heads)", 32), ("GQA (8 KV heads)", 8), ("multi-query (1 KV head)", 1)]:
    print(f"{name:26s} KV cache per sequence: {kv_bytes(L_, T_, n_kv, dh_) / 2**30:6.2f} GiB")

32.8 A minimal Llama block

We assemble everything in PyTorch: RMSNorm, RoPE, grouped-query causal attention, SwiGLU, residual connections. It follows the structure of Figure 32.2.

import torch, torch.nn as nn, torch.nn.functional as F

class RMSNorm(nn.Module):
    def __init__(self, d, eps=1e-6):
        super().__init__(); self.g = nn.Parameter(torch.ones(d)); self.eps = eps
    def forward(self, x):
        return x * torch.rsqrt(x.pow(2).mean(-1, keepdim=True) + self.eps) * self.g

def rope_cache(dh, T, base=10000.0):
    theta = base ** (-torch.arange(0, dh, 2).float() / dh)
    ang = torch.arange(T).float()[:, None] * theta[None, :]          # (T, dh/2)
    return ang.cos(), ang.sin()

def apply_rope(x, cos, sin):                                         # x: (B, heads, T, dh)
    x1, x2 = x[..., 0::2], x[..., 1::2]
    return torch.stack([x1 * cos - x2 * sin, x1 * sin + x2 * cos], dim=-1).flatten(-2)

class LlamaBlock(nn.Module):
    def __init__(self, d, n_heads, n_kv, hidden):
        super().__init__()
        self.h, self.n_kv, self.dh = n_heads, n_kv, d // n_heads
        self.wq = nn.Linear(d, n_heads * self.dh, bias=False)
        self.wk = nn.Linear(d, n_kv * self.dh, bias=False)
        self.wv = nn.Linear(d, n_kv * self.dh, bias=False)
        self.wo = nn.Linear(n_heads * self.dh, d, bias=False)
        self.w1 = nn.Linear(d, hidden, bias=False)       # gate branch
        self.w3 = nn.Linear(d, hidden, bias=False)       # linear branch
        self.w2 = nn.Linear(hidden, d, bias=False)       # down projection
        self.n1, self.n2 = RMSNorm(d), RMSNorm(d)

    def _qkv(self, x, cos, sin):
        B, T, _ = x.shape
        q = self.wq(x).view(B, T, self.h, self.dh).transpose(1, 2)
        k = self.wk(x).view(B, T, self.n_kv, self.dh).transpose(1, 2)
        v = self.wv(x).view(B, T, self.n_kv, self.dh).transpose(1, 2)
        return apply_rope(q, cos, sin), apply_rope(k, cos, sin), v

    def _mlp(self, x):
        return self.w2(F.silu(self.w1(x)) * self.w3(x))

    def forward(self, x, cos, sin):
        B, T, d = x.shape
        q, k, v = self._qkv(self.n1(x), cos[:T], sin[:T])
        rep = self.h // self.n_kv                              # query heads per KV head
        k, v = k.repeat_interleave(rep, dim=1), v.repeat_interleave(rep, dim=1)
        a = F.scaled_dot_product_attention(q, k, v, is_causal=True)
        x = x + self.wo(a.transpose(1, 2).reshape(B, T, d))
        return x + self._mlp(self.n2(x))

    def step(self, x_t, pos, cache, cos, sin):
        """One-token forward with a KV cache. x_t: (B, 1, d)."""
        B, _, d = x_t.shape
        q, k, v = self._qkv(self.n1(x_t), cos[pos:pos + 1], sin[pos:pos + 1])
        cache["k"] = k if cache.get("k") is None else torch.cat([cache["k"], k], dim=2)
        cache["v"] = v if cache.get("v") is None else torch.cat([cache["v"], v], dim=2)
        rep = self.h // self.n_kv
        K, Vv = cache["k"].repeat_interleave(rep, 1), cache["v"].repeat_interleave(rep, 1)
        a = F.scaled_dot_product_attention(q, K, Vv)           # one query: no mask needed
        x_t = x_t + self.wo(a.transpose(1, 2).reshape(B, 1, d))
        return x_t + self._mlp(self.n2(x_t))

torch.manual_seed(0)
d, h, n_kv, hid = 64, 8, 2, 176                                # hidden ≈ 8d/3 rounded
blk = LlamaBlock(d, h, n_kv, hid)
cos, sin = rope_cache(d // h, 64)
X = torch.randn(2, 10, d)
Y = blk(X, cos, sin)
print("output shape:", tuple(Y.shape))

n_counted = sum(p.numel() for p in blk.parameters())
n_formula = (2 * d * d + 2 * d * n_kv * (d // h)) + 3 * d * hid + 2 * d
print(f"parameters: counted {n_counted:,}, formula {n_formula:,}, equal: {n_counted == n_formula}")

32.8.1 Checks

Causality. Changing a future token must not change earlier outputs.

KV cache. Decoding one token at a time with a cache must give exactly the same outputs as the full forward pass.

X2 = X.clone(); X2[:, 7:] += torch.randn(2, 3, d)              # change tokens 7..9
Y2 = blk(X2, cos, sin)

      torch.allclose(Y[:, :7], Y2[:, :7], atol=1e-6))

32.9 Weight tying and the output head

The output layer maps a hidden vector \(\mathbf{h}\in\mathbb{R}^d\) to \(V\) scores. If we reuse the embedding matrix, the logits are

\[ \mathbf{z}=\mathbf{h}\,\mathbf{E}^{\intercal}\in\mathbb{R}^V,\qquad z_t=\mathbf{h}\cdot\mathbf{e}_t. \tag{32.4}\]

The score of token \(t\) is the dot product of the final representation with that token’s embedding (Chapter 4). Embedding and output share one matrix and the model saves \(Vd\) parameters. After softmax this is the next-token distribution (Chapter 24).

32.10 Counting a full model

Putting the pieces together, for width \(d\), \(L\) blocks, \(h\) query heads of size \(d_h=d/h\), \(n_{\text{kv}}\) key/value heads, and hidden size \(f\):

\[ N\approx Vd+L\Bigl(\underbrace{2d^2+2\,d\,n_{\text{kv}}d_h}_{\text{attention}}+\underbrace{3\,d\,f}_{\text{SwiGLU}}+\underbrace{2d}_{\text{norms}}\Bigr)+d. \tag{32.5}\]

def llama_params(V, d, L, h, n_kv, f):
    dh = d // h
    per_block = 2 * d * d + 2 * d * n_kv * dh + 3 * d * f + 2 * d
    return V * d + L * per_block + d

32.12 Failure modes

RoPE beyond the training length. Rotation angles for positions never seen in training put queries and keys in configurations the model did not learn. Quality falls sharply past the trained context. Methods that rescale positions (position interpolation) exist for this reason.

Position precision. Position indices stored in 16-bit floats lose exactness:

pos = torch.arange(250, 270, dtype=torch.float32)
print("float32:", pos[:8].tolist())

Compute RoPE angles in float32.

Norm epsilon. In 16-bit arithmetic, \(\epsilon=10^{-6}\) can vanish in the sum, and the reciprocal square root may overflow for tiny inputs. Models normalise in float32.

GQA grouping. If \(h\) is not a multiple of \(n_{\text{kv}}\), heads cannot be grouped. If the repeat uses the wrong order (repeat instead of repeat_interleave), query heads read the wrong KV head and the model silently degrades.

Cache memory. The KV cache grows linearly with context and batch size and often limits the number of simultaneous requests.

32.14 System connection

NoteWhat the system gained in this chapter

System C is now a modern language-model architecture: tokens \(\to\) embeddings \(\to\) (RMSNorm, RoPE-attention, SwiGLU) \(\times\,N\to\) logits \(=\mathbf{h}\mathbf{E}^{\intercal}\) \(\to\) softmax. Every change from Chapter 31 was an application of earlier mathematics: rotations, norms, element-wise gating, and reuse of cached tensors.

The model gives a distribution over the next token. Chapter 33 shows how a distribution becomes a sentence, and how the whole model is trained by the chain rule of probability.

Chapter summary

  • RoPE rotates query/key pairs by \(m\theta_i\). The score depends on content and the offset \(n-m\).
  • RMSNorm: \(\mathbf{x}/\text{RMS}(\mathbf{x})\odot\mathbf{g}\), no mean subtraction.
  • SwiGLU: \(\mathbf{W}_2(\text{SiLU}(\mathbf{W}_{1}\mathbf{x})\odot\mathbf{W}_{3}\mathbf{x})\), hidden size \(\frac83d\) for equal parameters.
  • GQA shares KV heads and shrinks the cache by \(h/n_{\text{kv}}\). The cache has \(2LTn_{\text{kv}}d_h\) numbers.
  • Tied head: \(\mathbf{z}=\mathbf{h}\mathbf{E}^{\intercal}\).
  • A 7B-class model: about \(12d^2L\) block parameters, \(2N\) FLOPs per token.
