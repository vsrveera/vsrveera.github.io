42  Latent Diffusion and Diffusion Transformers

NoteKey ideas
  • Latent diffusion runs the diffusion process in the compact latent space of an autoencoder (Chapter 40), not in pixel space. The number of values to denoise falls by a large factor.
  • Conditioning (a class, a text embedding) enters the denoiser as an extra input, through concatenation, cross-attention, or adaptive normalisation.
  • Classifier-free guidance extrapolates from the unconditional to the conditional prediction: \(\tilde{\boldsymbol\epsilon}=\boldsymbol\epsilon_u+w(\boldsymbol\epsilon_c-\boldsymbol\epsilon_u)\). It trades diversity for fidelity to the condition.
  • A Diffusion Transformer (DiT) replaces the U-Net by Transformer blocks over latent patches, with adaLN-Zero conditioning.
  • The pipeline is: text encoder → denoiser (many steps) → decoder.

42.1 The system problem

Chapter 41’s diffusion model works, but two things stand in the way of images as we know them:

  1. Cost. Every denoising step runs a network on every pixel. A \(512\times512\) colour image has 786,432 numbers, and sampling needs tens of steps.
  2. Control. The model generates some sample. A user wants the image for a given prompt.

How do we make diffusion cheap enough for large images, and how do we steer it with text?

42.3 Why latents: the arithmetic

An autoencoder (Chapter 40) compresses an image to a small tensor. A typical design maps \(512\times512\times3\) to \(64\times64\times4\): a factor of 8 per side, with 4 latent channels.

def n_values(h, w, c): return h * w * c
pixel = n_values(512, 512, 3); latent = n_values(64, 64, 4)
print(f"pixel space : {pixel:,} values;  latent space: {latent:,} values;  ratio {pixel / latent:.0f}x")

patch = 2
tok_pixel = (512 // patch) ** 2; tok_latent = (64 // patch) ** 2
print(f"tokens for a Transformer denoiser with {patch}×{patch} patches: pixels {tok_pixel:,}, latents {tok_latent:,}")
print(f"attention score entries per layer: pixels {tok_pixel ** 2:,}, latents {tok_latent ** 2:,} "
      f"(ratio {tok_pixel ** 2 / tok_latent ** 2:,.0f}x)")

tokens for a Transformer denoiser with 2×2 patches: pixels 65,536, latents 1,024
attention score entries per layer: pixels 4,294,967,296, latents 1,048,576 (ratio 4,096x)

The attention cost grows with the square of the number of tokens (Chapter 30), so the latent space is thousands of times cheaper in that part, and tens of times cheaper elsewhere. The autoencoder is trained once, separately, and then frozen. Diffusion is trained on its latents.

42.3.1 A digit-scale demonstration

We repeat the idea at small scale. A VAE with an 8-dimensional latent space (Chapter 40) compresses the \(8\times8=64\)-value digits. We train the same class-conditional denoiser network twice: once on the 64 pixels, once on the 8 latent values (standardised).

import torch, torch.nn as nn, torch.nn.functional as F
from sklearn.datasets import load_digits
from sklearn.model_selection import train_test_split
from sklearn.linear_model import LogisticRegression

D = load_digits(); X, y = D.data / 16.0, D.target
Xtr, Xte, ytr, yte = train_test_split(X, y, test_size=0.25, random_state=0, stratify=y)
Xt, yt = torch.tensor(Xtr, dtype=torch.float32), torch.tensor(ytr)
judge = LogisticRegression(max_iter=3000).fit(Xtr, ytr)                 # independent classifier as a judge
print(f"judge classifier accuracy on real test digits: {judge.score(Xte, yte):.3f}")

class VAE(nn.Module):
    def __init__(self, k=8, h=128):
        super().__init__()
        self.enc = nn.Sequential(nn.Linear(64, h), nn.ReLU())
        self.mu, self.lv = nn.Linear(h, k), nn.Linear(h, k)
        self.dec = nn.Sequential(nn.Linear(k, h), nn.ReLU(), nn.Linear(h, 64), nn.Sigmoid())
    def forward(self, x):
        h = self.enc(x); mu, lv = self.mu(h), self.lv(h)
        return self.dec(mu + torch.exp(0.5 * lv) * torch.randn_like(mu)), mu, lv

torch.manual_seed(0)
vae = VAE(); opt = torch.optim.Adam(vae.parameters(), lr=2e-3)
for _ in range(3000):
    i = torch.randint(0, len(Xt), (128,)); xh, mu, lv = vae(Xt[i])
    loss = ((Xt[i] - xh) ** 2).sum(1).div(2 * 0.25 ** 2).mean() + 0.5 * (mu ** 2 + lv.exp() - 1 - lv).sum(1).mean()
    opt.zero_grad(); loss.backward(); opt.step()
with torch.no_grad():
    Z = vae.mu(vae.enc(Xt)); z_mean, z_std = Z.mean(0), Z.std(0)
    recon_err = F.mse_loss(vae.dec(Z), Xt).item()
Zs = (Z - z_mean) / z_std

T = 100
betas = torch.linspace(1e-3, 0.12, T); alphas = 1 - betas; abar = torch.cumprod(alphas, 0)

class CondNet(nn.Module):
    """Denoiser for data of dimension k, conditioned on a class (label 10 = 'no condition')."""
    def __init__(self, k, h=256, temb=16):
        super().__init__()
        self.temb = temb; self.cls = nn.Embedding(11, 16)
        self.net = nn.Sequential(nn.Linear(k + temb + 16, h), nn.SiLU(), nn.Linear(h, h), nn.SiLU(),
                                 nn.Linear(h, h), nn.SiLU(), nn.Linear(h, k))
    def forward(self, x, t, c):
        f = torch.exp(-math.log(1000) * torch.arange(self.temb // 2) / (self.temb // 2))
        a = t[:, None].float() * f[None]
        return self.net(torch.cat([x, a.sin(), a.cos(), self.cls(c)], dim=1))

def train_denoiser(data, k, steps=15000, p_uncond=0.15, seed=0):
    torch.manual_seed(seed)
    net = CondNet(k); opt = torch.optim.Adam(net.parameters(), lr=2e-3)
    for _ in range(steps):
        i = torch.randint(0, len(data), (256,)); x0 = data[i]; c = yt[i].clone()
        c[torch.rand(256) < p_uncond] = 10                       # condition dropout (for guidance)
        t = torch.randint(0, T, (256,)); eps = torch.randn_like(x0)
        xt = abar[t].sqrt()[:, None] * x0 + (1 - abar[t]).sqrt()[:, None] * eps
        loss = F.mse_loss(net(xt, t, c), eps)
        opt.zero_grad(); loss.backward(); opt.step()
    return net

@torch.no_grad()
def ddim(net, n, k, cls, w=1.0, steps=25, seed=0):
    g = torch.Generator().manual_seed(seed)
    x = torch.randn(n, k, generator=g); ts = np.linspace(T - 1, 0, steps).round().astype(int)
    c, u = torch.full((n,), cls), torch.full((n,), 10)
    for j, t in enumerate(ts):
        tt = torch.full((n,), int(t))
        e_c, e_u = net(x, tt, c), net(x, tt, u)
        e = e_u + w * (e_c - e_u)                                # classifier-free guidance
        x0 = (x - (1 - abar[t]).sqrt() * e) / abar[t].sqrt()
        if j + 1 < len(ts):
            an = abar[ts[j + 1]]; x = an.sqrt() * x0 + (1 - an).sqrt() * e
        else:
            x = x0
    return x

42.4 Conditioning and classifier-free guidance

We want samples from \(p(\mathbf{x}\mid c)\). By Bayes’ rule (Chapter 22),

\[ \nabla_{\mathbf{x}}\ln p(\mathbf{x}\mid c)=\nabla_{\mathbf{x}}\ln p(\mathbf{x})+\nabla_{\mathbf{x}}\ln p(c\mid\mathbf{x}). \tag{42.1}\]

The first term is the unconditional score. The second says: move in the direction that makes the condition more likely. We can amplify that second term with a weight \(w\):

\[ \nabla_{\mathbf{x}}\ln p(\mathbf{x})+w\,\nabla_{\mathbf{x}}\ln p(c\mid\mathbf{x}) =(1-w)\,\nabla\ln p(\mathbf{x})+w\,\nabla\ln p(\mathbf{x}\mid c). \tag{42.2}\]

Since the noise prediction is proportional to the (negative) score (Chapter 41), the same combination applies to \(\boldsymbol\epsilon\):

\[ \tilde{\boldsymbol\epsilon}=\boldsymbol\epsilon_\theta(\mathbf{x}_t,t,\varnothing)+w\bigl(\boldsymbol\epsilon_\theta(\mathbf{x}_t,t,c)-\boldsymbol\epsilon_\theta(\mathbf{x}_t,t,\varnothing)\bigr). \tag{42.3}\]

This is classifier-free guidance: one network is trained with the condition randomly replaced by a null token (here, 15% of the time), so that it can produce both \(\boldsymbol\epsilon_c\) and \(\boldsymbol\epsilon_u\). At \(w=0\) the sample ignores the condition. At \(w=1\) it is the plain conditional model. For \(w>1\) it is pushed further along the direction that distinguishes the condition.

ws = [0.0, 0.5, 1.0, 1.5, 2.0, 3.0, 5.0, 8.0]

For text-to-image models, the same recipe holds with \(c\) a text embedding: a sequence of vectors from a text encoder (Chapter 39). The null condition is the embedding of the empty prompt. Typical guidance weights are 5–10.

42.5 Where the condition enters the network

Three mechanisms are common.

Mechanism How Typical use
Concatenation / addition embed \(c\) and add or concatenate to the input or time embedding class labels, as above
Cross-attention queries from image tokens, keys/values from text tokens (Chapter 30) text-to-image U-Nets
Adaptive normalisation the condition produces a per-channel scale and shift DiT

42.6 Diffusion Transformers

The denoiser of Chapter 41 was an MLP. For images, early latent diffusion models used a U-Net: a convolutional encoder–decoder with skip connections and attention (Chapter 35). A Diffusion Transformer (DiT) replaces it with the Transformer of Chapter 31, applied to the sequence of patch tokens of the latent (Chapter 36).

The condition (time step and class or pooled text) is injected by adaptive layer norm with zero initialisation (adaLN-Zero). A small network maps the condition \(c\) to six vectors: a scale \(\boldsymbol\gamma\), shift \(\boldsymbol\beta\), and gate \(\boldsymbol\alpha\) for each of the attention and MLP sub-layers:

\[ \mathbf{h}\leftarrow\mathbf{h}+\boldsymbol\alpha_1(c)\odot\text{Attn}\bigl(\boldsymbol\gamma_1(c)\odot\text{LN}(\mathbf{h})+\boldsymbol\beta_1(c)\bigr), \] \[ \mathbf{h}\leftarrow\mathbf{h}+\boldsymbol\alpha_2(c)\odot\text{MLP}\bigl(\boldsymbol\gamma_2(c)\odot\text{LN}(\mathbf{h})+\boldsymbol\beta_2(c)\bigr). \tag{42.4}\]

The gates \(\boldsymbol\alpha\) are initialised to zero. At the start of training every block is the identity map (Chapter 31, residual path), which makes training of a deep stack stable.

import math
class DiTBlock(nn.Module):
    def __init__(self, d, heads=4):
        super().__init__()
        self.h = heads
        self.ln1, self.ln2 = nn.LayerNorm(d, elementwise_affine=False), nn.LayerNorm(d, elementwise_affine=False)
        self.qkv, self.o = nn.Linear(d, 3 * d), nn.Linear(d, d)
        self.mlp = nn.Sequential(nn.Linear(d, 4 * d), nn.GELU(), nn.Linear(4 * d, d))
        self.ada = nn.Linear(d, 6 * d)                             # condition -> γ1, β1, α1, γ2, β2, α2
        nn.init.zeros_(self.ada.weight); nn.init.zeros_(self.ada.bias)      # adaLN-Zero
    def forward(self, x, c):                                       # x: (B, N, d) tokens; c: (B, d)
        g1, b1, a1, g2, b2, a2 = self.ada(c)[:, None].chunk(6, dim=-1)
        B, N, d = x.shape
        h = (1 + g1) * self.ln1(x) + b1
        q, k, v = self.qkv(h).chunk(3, dim=-1)
        sp = lambda t: t.view(B, N, self.h, d // self.h).transpose(1, 2)
        att = F.scaled_dot_product_attention(sp(q), sp(k), sp(v)).transpose(1, 2).reshape(B, N, d)
        x = x + a1 * self.o(att)
        h = (1 + g2) * self.ln2(x) + b2
        return x + a2 * self.mlp(h)

torch.manual_seed(0)
blk = DiTBlock(d=64)
tokens = torch.randn(2, 16, 64); cond = torch.randn(2, 64)           # 16 latent patches, one condition vector
print("output shape:", tuple(blk(tokens, cond).shape))
print("at initialisation the block is the identity map:", torch.allclose(blk(tokens, cond), tokens))
with torch.no_grad():
    blk.ada.weight.add_(0.05 * torch.randn_like(blk.ada.weight))
print("after perturbing the adaLN weights the block changes the tokens:",
      not torch.allclose(blk(tokens, cond), tokens, atol=1e-4))
print(f"parameters in one DiT block of width 64: {sum(p.numel() for p in blk.parameters()):,} "
      f"(a plain block has 12·64²+… ≈ {12 * 64 ** 2:,}; adaLN adds {6 * 64 * 64 + 6 * 64:,})")

The condition modulates every layer: scale, shift, and gate vary with the time step and the class or text. That gives the network a strong way to change its behaviour with the noise level, which is crucial in diffusion, where the right operation at \(t=90\) (mostly noise) differs from that at \(t=5\) (fine detail).

42.8 Failure modes

Autoencoder limits. The decoder bounds quality: fine detail lost in compression cannot be restored by diffusion. Text and small faces suffer first.

Latent scale. The latent should be standardised (we did) or multiplied by a fixed factor, so that its variance matches the noise schedule’s assumptions. A mismatch changes the effective signal-to-noise ratio.

Over-guidance. Large \(w\) gives over-saturated, high-contrast, repetitive images and mode collapse. In our digits, the accuracy saturates while diversity continues to fall.

Missing condition dropout. Without null-condition training, classifier-free guidance has no \(\boldsymbol\epsilon_u\).

Prompt encoding. The image model sees only what the text encoder encodes: bag-of-words behaviour (Chapter 39) shows up as errors in counting and relations.

Sampling cost. Tens of denoiser evaluations per image, each on thousands of tokens. Distillation methods reduce the step count.

The generative pipeline is complete: text → condition → denoiser over a compressed latent → decoder → image. Every box is an object from earlier chapters: a text encoder (Chapters 31, 39), a VAE (Chapter 40), a denoising network trained by squared error (Chapter 41), attention and normalisation (Chapters 30, 20), and guidance from Bayes’ rule (Chapter 22).

The sampling procedure has one more view. The deterministic DDIM steps trace trajectories from noise to data. Chapter 43 shows that these are solutions of an ordinary differential equation, and trains such a vector field directly.

Chapter summary

  • Latent diffusion: encode with a VAE, diffuse in the latent space, decode. \(512^{2}\times3\to64^{2}\times4\) is a \(48\times\) reduction.
  • Guidance: \(\tilde{\boldsymbol\epsilon}=\boldsymbol\epsilon_u+w(\boldsymbol\epsilon_c-\boldsymbol\epsilon_u)\) corresponds to the score \(\nabla\ln p(\mathbf{x})+w\nabla\ln p(c\mid\mathbf{x})\).
  • Train with condition dropout. Raising \(w\) trades diversity for fidelity.
  • DiT: Transformer on latent patches with adaLN-Zero conditioning: scale, shift, and a zero-initialised gate per sub-layer.
  • Compute is dominated by token count squared. Latents cut it by orders of magnitude.
