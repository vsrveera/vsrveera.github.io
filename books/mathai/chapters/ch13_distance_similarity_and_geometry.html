13  Distance, Similarity and Geometry

NoteKey ideas
  • A distance must satisfy the metric axioms. Cosine distance does not satisfy the triangle inequality.
  • Mahalanobis distance is Euclidean distance after whitening: it accounts for the shape of the data cloud.
  • Nearest-neighbour search is the base of retrieval, classification, and clustering.
  • TF-IDF weights words by how rare they are, so common words stop dominating.
  • \(k\)-means groups points by repeatedly assigning to the nearest centre and moving the centre.

13.1 The system problem

Part IV is about measurement. A system needs to know two things: how similar two items are, and how wrong a prediction is. This chapter does the first.

How does a system decide that two items are close, and how does it find the closest ones among millions?

This is System B in full: text \(\to\) vector \(\to\) similarity \(\to\) retrieval.

13.2 What makes a distance

A function \(d(\mathbf{a},\mathbf{b})\) is a metric if it satisfies four rules:

Axiom Statement Meaning
Non-negative \(d(\mathbf{a},\mathbf{b})\ge0\) no negative distance
Identity \(d(\mathbf{a},\mathbf{b})=0\iff\mathbf{a}=\mathbf{b}\) only identical items are at 0
Symmetric \(d(\mathbf{a},\mathbf{b})=d(\mathbf{b},\mathbf{a})\) no direction
Triangle \(d(\mathbf{a},\mathbf{c})\le d(\mathbf{a},\mathbf{b})+d(\mathbf{b},\mathbf{c})\) no shortcut through a third point

The triangle inequality is what makes search structures possible: if \(\mathbf{b}\) is far from \(\mathbf{a}\) and close to \(\mathbf{c}\), then \(\mathbf{c}\) is far from \(\mathbf{a}\), and we can skip it.

13.2.1 The common distances

Name Formula Metric? Note
Euclidean \(\lVert\mathbf{a}-\mathbf{b}\rVert_2\) yes default
Manhattan \(\lVert\mathbf{a}-\mathbf{b}\rVert_1\) yes robust to one large coordinate
Chebyshev \(\lVert\mathbf{a}-\mathbf{b}\rVert_\infty\) yes worst coordinate
Cosine distance \(1-\cos(\mathbf{a},\mathbf{b})\) no triangle fails
Angular distance \(\arccos(\cos(\mathbf{a},\mathbf{b}))\) yes the angle itself
Mahalanobis \(\sqrt{(\mathbf{a}-\mathbf{b})^{\intercal}\mathbf{S}^{-1}(\mathbf{a}-\mathbf{b})}\) yes uses covariance

We show that cosine distance breaks the triangle inequality with three vectors.

def cos_dist(a, b):
    return 1 - a @ b / (np.linalg.norm(a) * np.linalg.norm(b))

a = np.array([1.0, 0.0])
c = np.array([np.cos(np.pi / 2), np.sin(np.pi / 2)])          # 90 degrees from a
b = np.array([np.cos(np.pi / 4), np.sin(np.pi / 4)])          # halfway: 45 degrees
d_ac, d_ab, d_bc = cos_dist(a, c), cos_dist(a, b), cos_dist(b, c)
print(f"d(a,c) = {d_ac:.3f}")
print(f"d(a,b) + d(b,c) = {d_ab + d_bc:.3f}")
print("triangle inequality holds:", d_ac <= d_ab + d_bc)
d(a,c) = 1.000
d(a,b) + d(b,c) = 0.586
triangle inequality holds: False

The direct distance is larger than the path through \(\mathbf{b}\). Cosine distance is useful for ranking, but it is not a metric. The angle is.

13.3 Euclidean distance from a dot product

For search, we need all distances between a query set and a database. The identity

\[ \lVert\mathbf{a}-\mathbf{b}\rVert^2=\lVert\mathbf{a}\rVert^2+\lVert\mathbf{b}\rVert^2-2\,\mathbf{a}\cdot\mathbf{b} \tag{13.1}\]

turns all pairwise distances into one matrix product plus two vectors of norms. This is why retrieval runs fast on matrix hardware.

def pairwise_sqdist(A, B):
    """Squared Euclidean distances between rows of A (m, d) and B (n, d)."""
    sa = (A ** 2).sum(axis=1)[:, None]            # (m, 1)
    sb = (B ** 2).sum(axis=1)[None, :]            # (1, n)
    return np.maximum(sa + sb - 2 * A @ B.T, 0)   # (m, n); clip rounding noise

rng = np.random.default_rng(0)
A, B = rng.normal(size=(5, 16)), rng.normal(size=(7, 16))
brute = np.array([[np.sum((a - b) ** 2) for b in B] for a in A])
print("matrix form == double loop:", np.allclose(pairwise_sqdist(A, B), brute))
matrix form == double loop: True

13.4 Mahalanobis distance: respect the shape of the data

Euclidean distance treats every direction alike. Real data is rarely round. Take two correlated features. A step along the long axis of the cloud is normal. A step across it is unusual.

The Mahalanobis distance measures a step in units of the cloud’s spread:

\[ d_M(\mathbf{x},\boldsymbol{\mu})=\sqrt{(\mathbf{x}-\boldsymbol{\mu})^{\intercal}\mathbf{S}^{-1}(\mathbf{x}-\boldsymbol{\mu})}. \tag{13.2}\]

TipDerivation: Mahalanobis is Euclidean after whitening

The covariance \(\mathbf{S}\) is symmetric. By the spectral theorem (Chapter 7), \(\mathbf{S}=\mathbf{V}\boldsymbol{\Lambda}\mathbf{V}^{\intercal}\). Define the whitening map \[ \mathbf{z}=\boldsymbol{\Lambda}^{-1/2}\mathbf{V}^{\intercal}(\mathbf{x}-\boldsymbol{\mu}). \] Then \[ \lVert\mathbf{z}\rVert^2=(\mathbf{x}-\boldsymbol{\mu})^{\intercal}\mathbf{V}\boldsymbol{\Lambda}^{-1}\mathbf{V}^{\intercal}(\mathbf{x}-\boldsymbol{\mu})=(\mathbf{x}-\boldsymbol{\mu})^{\intercal}\mathbf{S}^{-1}(\mathbf{x}-\boldsymbol{\mu}).\ \blacksquare \] Whitening rotates the cloud onto its principal axes and rescales each axis to unit spread. The cloud becomes a round ball with identity covariance.

rng = np.random.default_rng(1)
M = np.array([[2.0, 0.0], [1.5, 0.5]])
X = rng.normal(size=(500, 2)) @ M.T + np.array([2.0, 1.0])
mu = X.mean(axis=0)
S = np.cov(X.T, bias=True)
lam, V = np.linalg.eigh(S)
Z = (X - mu) @ V / np.sqrt(lam)                     # whitened, (500, 2)

# Mahalanobis via the formula and via Euclidean distance in whitened space
q = np.array([4.0, 3.0])
d_form = np.sqrt((q - mu) @ np.linalg.inv(S) @ (q - mu))
d_white = np.linalg.norm((q - mu) @ V / np.sqrt(lam))
print(f"Mahalanobis (formula) {d_form:.4f}   Euclidean after whitening {d_white:.4f}")
print("covariance of whitened data:\n", np.round(np.cov(Z.T, bias=True), 3))

Mahalanobis distance can change which neighbour is nearest. Take a point and two candidates: one on the cloud’s long axis, one across it.

major = V[:, 1]; minor = V[:, 0]                        # eigenvectors, long and short
origin = mu
p_long = origin + 2.5 * major                           # far, but along the cloud
p_short = origin + 1.2 * minor                          # near, but across the cloud
for name, p in [("long axis", p_long), ("across", p_short)]:
    de = np.linalg.norm(p - origin)
    dm = np.sqrt((p - origin) @ np.linalg.inv(S) @ (p - origin))
    print(f"{name:10s} Euclidean {de:.2f}   Mahalanobis {dm:.2f}")
long axis  Euclidean 2.50   Mahalanobis 1.03
across     Euclidean 1.20   Mahalanobis 3.00

The point across the cloud is closer in Euclidean terms and farther in Mahalanobis terms. The second is the right answer if we ask “how typical is this point for the data?”

13.5 Nearest neighbours

The \(k\)-nearest-neighbour (\(k\)-NN) rule classifies a point by a vote among its \(k\) closest training points. It has no training phase. It is the data and a distance.

from sklearn.datasets import load_digits
from sklearn.model_selection import train_test_split

D = load_digits()
Xtr, Xte, ytr, yte = train_test_split(D.data / 16.0, D.target, test_size=0.25,
                                      random_state=0, stratify=D.target)

def knn_predict(Xtr, ytr, Xq, k=3):
    d2 = pairwise_sqdist(Xq, Xtr)                       # (m, n)
    idx = np.argsort(d2, axis=1)[:, :k]                 # k nearest per query
    votes = ytr[idx]                                    # (m, k)
    return np.array([np.bincount(v, minlength=10).argmax() for v in votes])

for k in [1, 3, 5, 9]:
    acc = np.mean(knn_predict(Xtr, ytr, Xte, k) == yte)
    print(f"k = {k}: test accuracy {acc:.3f}")
k = 1: test accuracy 0.982
k = 3: test accuracy 0.987
k = 5: test accuracy 0.980
k = 9: test accuracy 0.973

The decision regions of 1-NN are the cells of a Voronoi diagram: each training point owns the region of space that is closer to it than to any other.

13.6 Clustering: \(k\)-means

\(k\)-means has no labels. It looks for \(K\) centres \(\boldsymbol{\mu}_1,\dots,\boldsymbol{\mu}_K\) that minimise

\[ J=\sum_{i=1}^{N}\lVert\mathbf{x}_i-\boldsymbol{\mu}_{c(i)}\rVert^2, \tag{13.3}\]

where \(c(i)\) is the centre assigned to point \(i\). It alternates two steps.

  1. Assign each point to its nearest centre.
  2. Update each centre to the mean of its points.

Each step cannot increase \(J\). The assignment step gives every point its best centre. The update step uses the fact that the mean minimises the sum of squared distances (Chapter 14). Since \(J\ge0\) and the number of assignments is finite, the procedure stops.

def kmeans(X, K, iters=20, seed=0):
    rng = np.random.default_rng(seed)
    centres = X[rng.choice(len(X), K, replace=False)].copy()     # random start
    history = []
    for _ in range(iters):
        d2 = pairwise_sqdist(X, centres)                          # (N, K)
        assign = d2.argmin(axis=1)                                # assign step
        history.append(d2[np.arange(len(X)), assign].sum())       # objective J
        for k in range(K):                                        # update step
            if np.any(assign == k):
                centres[k] = X[assign == k].mean(axis=0)
    return centres, assign, history

from sklearn.datasets import make_blobs
Xb, _ = make_blobs(n_samples=300, centers=3, cluster_std=1.1, random_state=2)
cen, assign, J = kmeans(Xb, 3)
print("objective by iteration:", np.round(J[:6], 1))
print("never increases:", all(J[i + 1] <= J[i] + 1e-9 for i in range(len(J) - 1)))
objective by iteration: [1610.5  758.4  751.5  750.9  750.7  750.6]
never increases: True

13.7 Retrieval for text: TF-IDF

In Chapter 4, a bag-of-words vector let common words dominate the dot product. TF-IDF weights words by how informative they are.

\[ \text{tfidf}(t,d)=\text{tf}(t,d)\cdot\ln\frac{N}{\text{df}(t)}. \tag{13.4}\]

  • \(\text{tf}(t,d)\) is the count of word \(t\) in document \(d\).
  • \(\text{df}(t)\) is the number of documents that contain \(t\). A word in every document has \(\ln(N/N)=0\) and carries no weight.

We build a small corpus of 24 sentences on four topics.

corpus = {
 "pets": ["the dog barked at the mailman and chased the cat",
          "my cat sleeps on the sofa all day",
          "feed the puppy twice a day with dog food",
          "the vet checked the kitten and the puppy",
          "a parrot is a pet bird that can learn words",
          "walk your dog every morning to keep it healthy"],
 "cooking": ["boil the pasta then add tomato sauce and cheese",
          "bake the bread in a hot oven for forty minutes",
          "chop the onion and fry it with garlic in olive oil",
          "mix flour sugar and eggs to make the cake batter",
          "simmer the soup with carrot celery and onion",
          "season the chicken with salt pepper and herbs before roasting"],
 "finance": ["the bank raised interest rates to fight inflation",
          "stock prices fell as investors sold shares",
          "she opened a savings account at the bank",
          "the company reported higher profit and revenue this quarter",
          "bond yields rose after the central bank meeting",
          "investors buy shares when profit forecasts improve"],
 "space": ["the rocket launched the satellite into orbit around earth",
          "astronauts aboard the station orbit the earth every ninety minutes",
          "the telescope observed a distant galaxy and a bright star",
          "the probe landed on mars and sent photos back to earth",
          "a comet passed near the sun and glowed in the sky",
          "the moon orbits the earth and the earth orbits the sun"],
}
docs = [s for topic in corpus for s in corpus[topic]]
topic_of = np.repeat(list(corpus), 6)
vocab = sorted({w for d in docs for w in d.split()})
index = {w: i for i, w in enumerate(vocab)}
print(f"{len(docs)} documents, {len(vocab)} distinct words")

def count_matrix(texts):
    C = np.zeros((len(texts), len(vocab)))
    for i, t in enumerate(texts):
        for w in t.split():
            if w in index:
                C[i, index[w]] += 1
    return C

C = count_matrix(docs)                                   # (24, V) term counts
df = (C > 0).sum(axis=0)                                 # document frequency
idf = np.log(len(docs) / df)
T = C * idf                                              # TF-IDF, (24, V)
print("words with idf = 0 (in every document):", [w for w, v in zip(vocab, idf) if v == 0])
print("highest idf (rarest) examples:", [vocab[i] for i in np.argsort(-idf)[:5]])

words with idf = 0 (in every document): []
highest idf (rarest) examples: ['mailman', 'raised', 'quarter', 'probe', 'prices']

We test three representations. Each document is a query, and we retrieve its 3 nearest other documents. We measure precision@3: the fraction of retrieved documents that have the same topic.

def precision_at_k(Vec, metric, k=3):
    n = len(Vec)
    if metric == "cosine":
        Vn = Vec / np.maximum(np.linalg.norm(Vec, axis=1, keepdims=True), 1e-12)
        score = Vn @ Vn.T                                # similarity: larger = closer
        np.fill_diagonal(score, -np.inf)
        top = np.argsort(-score, axis=1)[:, :k]
    else:                                                # euclidean
        d2 = pairwise_sqdist(Vec, Vec)
        np.fill_diagonal(d2, np.inf)
        top = np.argsort(d2, axis=1)[:, :k]
    return np.mean(topic_of[top] == topic_of[:, None])

print(f"{'representation':28s} {'precision@3':>11s}")
for name, Vec, metric in [("counts + Euclidean", C, "euclid"),
                          ("counts + cosine", C, "cosine"),
                          ("TF-IDF + cosine", T, "cosine")]:
    print(f"{name:28s} {precision_at_k(Vec, metric):11.3f}")
representation               precision@3
counts + Euclidean                 0.417
counts + cosine                    0.306
TF-IDF + cosine                    0.528

Three things stand out. TF-IDF is the best of the three. Cosine on raw counts is worse than Euclidean distance here, because the word “the” appears in most sentences and dominates the angle. And the absolute precision is modest, because each sentence is short and shares few words with its topic-mates. The ranking of the methods is the point, not the value.

Now a free-text query:

def search(query, k=3):
    q = count_matrix([query])[0] * idf
    Tn = T / np.maximum(np.linalg.norm(T, axis=1, keepdims=True), 1e-12)
    scores = Tn @ (q / np.linalg.norm(q))
    for r in np.argsort(-scores)[:k]:
        print(f"  {scores[r]:.2f}  [{topic_of[r]}]  {docs[r]}")

13.8 Random projections preserve distances

Searching 10 million vectors of 768 dimensions is expensive. A surprising fact helps: a random linear map to far fewer dimensions approximately preserves all pairwise distances.

For \(\mathbf{R}\in\mathbb{R}^{k\times d}\) with entries \(\mathcal{N}(0,1/k)\), the projected distance \(\lVert\mathbf{R}(\mathbf{a}-\mathbf{b})\rVert\) is close to \(\lVert\mathbf{a}-\mathbf{b}\rVert\) with high probability. This is the Johnson–Lindenstrauss lemma, which we state without proof.

rng = np.random.default_rng(0)
Xs = D.data / 16.0
i, j = rng.integers(0, len(Xs), (2, 3000))
keep = i != j
orig = np.linalg.norm(Xs[i[keep]] - Xs[j[keep]], axis=1)
fig, ax = plt.subplots(figsize=(6.4, 3.4))
for k, col in zip([4, 16, 32], [PALETTE["loss"], PALETTE["model"], PALETTE["grad"]]):
    R = rng.normal(0, 1 / np.sqrt(k), size=(64, k))
    ratio = np.linalg.norm((Xs[i[keep]] - Xs[j[keep]]) @ R, axis=1) / orig
    ax.hist(ratio, bins=60, range=(0, 2), alpha=0.55, color=col, density=True,
            label=f"k = {k}   (std {ratio.std():.2f})")
ax.set_xlabel("projected distance / original distance"); ax.legend()
plt.show()

from sklearn.neighbors import NearestNeighbors, KNeighborsClassifier
import torch

knn = KNeighborsClassifier(n_neighbors=3).fit(Xtr, ytr)

      "  ours:", round(np.mean(knn_predict(Xtr, ytr, Xte, 3) == yte), 3))

Large systems use approximate nearest-neighbour indexes (such as graph-based or quantisation-based methods). They trade a small loss of recall for a large gain in speed.

13.10 Failure modes

Distance concentration. In high dimension, nearest and farthest neighbours become almost equally far (Chapter 3). Distances lose contrast.

Hubness. In high dimension, a few points become the nearest neighbour of many queries. We count how often each point appears among the 5 nearest neighbours of others.

def max_in_degree(d, n=1000, k=5, seed=0):
    X = np.random.default_rng(seed).normal(size=(n, d))
    d2 = pairwise_sqdist(X, X); np.fill_diagonal(d2, np.inf)
    nn = np.argsort(d2, axis=1)[:, :k]
    counts = np.bincount(nn.ravel(), minlength=n)
    return counts.max(), counts.std()

13.12 System connection

NoteWhat the system gained in this chapter

The system can now measure similarity: choose a distance, find nearest neighbours, group points without labels, and search a text collection. System B runs end to end with TF-IDF vectors.

Similarity compares two items. The system also needs to compare a prediction with the truth. That measure of error is the loss. Chapter 14 builds it.

Chapter summary

  • A metric is non-negative, zero only for identical items, symmetric, and obeys the triangle inequality. Cosine distance fails the last rule.
  • All pairwise squared distances come from one matrix product.
  • Mahalanobis distance is Euclidean distance after whitening.
  • \(k\)-NN classifies by the nearest points. 1-NN regions are Voronoi cells.
  • \(k\)-means alternates assign and update steps. \(J\) never increases.
  • TF-IDF down-weights words that occur in many documents.
  • Random projections keep distances approximately.
  • Distances lose contrast in high dimension, and hubs appear.
