17  Gradients and Multivariable Calculus

NoteKey ideas
  • The gradient \(\nabla f\) collects all partial derivatives. It points in the direction of steepest increase.
  • The directional derivative along a unit vector \(\mathbf{u}\) is \(\nabla f\cdot\mathbf{u}\).
  • The gradient is perpendicular to level sets.
  • The Jacobian is the derivative of a vector function. The Hessian is the matrix of second derivatives and measures curvature.
  • A loss surface can have steep walls, flat valleys, and saddle points. The Hessian describes them.

17.1 The system problem

A model has millions of parameters. The loss is a function on a space with millions of axes. At each point we must decide in which direction to step.

With many parameters, which direction in parameter space lowers the loss fastest, and how does the surface bend around us?

17.2 The gradient

For \(f:\mathbb{R}^{n}\to\mathbb{R}\), the gradient is the vector of partial derivatives:

\[ \nabla f(\mathbf{x})=\begin{pmatrix}\partial f/\partial x_1\\ \vdots\\ \partial f/\partial x_{n}\end{pmatrix}. \tag{17.1}\]

The first-order approximation of Chapter 16 becomes a dot product:

\[ f(\mathbf{x}+\mathbf{h})\approx f(\mathbf{x})+\nabla f(\mathbf{x})\cdot\mathbf{h}. \tag{17.2}\]

17.2.1 Directional derivative

How fast does \(f\) change if we move along a unit vector \(\mathbf{u}\)? The directional derivative is

\[ D_{\mathbf{u}}f(\mathbf{x})=\lim_{t\to0}\frac{f(\mathbf{x}+t\mathbf{u})-f(\mathbf{x})}{t}=\nabla f(\mathbf{x})\cdot\mathbf{u}. \tag{17.3}\]

(Apply Equation 17.2 with \(\mathbf{h}=t\mathbf{u}\).)

TipDerivation: the gradient is the direction of steepest ascent

By the geometry of the dot product (Chapter 4), \[ D_{\mathbf{u}}f=\nabla f\cdot\mathbf{u}=\lVert\nabla f\rVert\,\lVert\mathbf{u}\rVert\cos\theta=\lVert\nabla f\rVert\cos\theta, \] where \(\theta\) is the angle between \(\mathbf{u}\) and \(\nabla f\). This is largest when \(\cos\theta=1\), that is, when \(\mathbf{u}\) points along \(\nabla f\). The largest rate of increase is \(\lVert\nabla f\rVert\). The steepest descent is \(-\nabla f\), with rate \(-\lVert\nabla f\rVert\). \(\blacksquare\)

This is the justification for the update rule \(\theta\leftarrow\theta-\eta\nabla_\theta L\) of Chapter 1.

f = lambda x, y: x ** 2 + 3 * y ** 2 + x * y
grad = lambda x, y: np.array([2 * x + y, 6 * y + x])

p = np.array([1.5, 0.8]); g = grad(*p)
gx, gy = np.meshgrid(np.linspace(-3, 3, 200), np.linspace(-2.5, 2.5, 200))
angles = np.linspace(0, 2 * np.pi, 360)
Dphi = np.array([g @ np.array([np.cos(t), np.sin(t)]) for t in angles])
t_best = angles[np.argmax(Dphi)]

fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(10, 3.8))
ax1.contour(gx, gy, f(gx, gy), levels=10, cmap="viridis")
ax1.plot(*p, "ko"); draw_arrow(ax1, g / np.linalg.norm(g) * 1.2, origin=p, color=PALETTE["loss"], lw=2.5)
ax1.set_aspect("equal"); ax1.set_title("contours and ∇f")
ax2.plot(np.degrees(angles), Dphi, color=PALETTE["model"], lw=2)
ax2.axvline(np.degrees(t_best), ls="--", color=PALETTE["loss"])
ax2.axhline(0, color="#9CA3AF", lw=0.8)
ax2.set_xlabel("direction angle (degrees)"); ax2.set_ylabel("directional derivative")
plt.tight_layout(); plt.show()
print(f"max directional derivative {Dphi.max():.3f}  = ‖∇f‖ = {np.linalg.norm(g):.3f}")
print(f"best direction angle {np.degrees(t_best):.0f}°; gradient angle "
      f"{np.degrees(np.arctan2(g[1], g[0])):.0f}°")
max directional derivative 7.357  = ‖∇f‖ = 7.357
best direction angle 59°; gradient angle 59°

17.2.2 Level sets

A level set is the set where \(f\) is constant. Moving along a level set changes nothing, so the directional derivative along it is zero: \(\nabla f\cdot\mathbf{u}=0\). The gradient is perpendicular to the level set. Contour maps show this: gradients cross the contours at right angles.

17.3 The Jacobian

For a vector function \(\mathbf{f}:\mathbb{R}^{n}\to\mathbb{R}^m\), each output has a gradient. Stacking them as rows gives the Jacobian:

\[ \mathbf{J}_{ij}=\frac{\partial f_i}{\partial x_j},\qquad \mathbf{J}\in\mathbb{R}^{m\times n}. \tag{17.4}\]

It is the best linear approximation of \(\mathbf{f}\):

\[ \mathbf{f}(\mathbf{x}+\mathbf{h})\approx\mathbf{f}(\mathbf{x})+\mathbf{J}(\mathbf{x})\,\mathbf{h}. \tag{17.5}\]

For a composition, Jacobians multiply: \(\mathbf{J}_{g\circ f}=\mathbf{J}_g\,\mathbf{J}_f\). This is the chain rule in matrix form. Chapter 18 uses it.

Take a layer \(\mathbf{a}=\tanh(\mathbf{W}\mathbf{x}+\mathbf{b})\). Its Jacobian is \(\text{diag}(1-\mathbf{a}^2)\,\mathbf{W}\): the activation derivative scales each row of \(\mathbf{W}\).

rng = np.random.default_rng(0)
W = rng.normal(size=(3, 4)); b = rng.normal(size=3); x = rng.normal(size=4)
layer = lambda x: np.tanh(W @ x + b)

a = layer(x)
J_analytic = (1 - a ** 2)[:, None] * W                  # diag(1 - a²) W

eps = 1e-6
J_numeric = np.stack([(layer(x + eps * e) - layer(x - eps * e)) / (2 * eps)
                      for e in np.eye(4)], axis=1)      # column j = ∂f/∂x_j
print("Jacobian shape:", J_analytic.shape, "(m = 3 outputs, n = 4 inputs)")
print("max |analytic − numeric|:", np.abs(J_analytic - J_numeric).max())
Jacobian shape: (3, 4) (m = 3 outputs, n = 4 inputs)
max |analytic − numeric|: 5.866773733487207e-11

17.4 The Hessian and curvature

The Hessian collects all second partial derivatives:

\[ \mathbf{H}_{ij}=\frac{\partial^2f}{\partial x_i\,\partial x_j}. \tag{17.6}\]

It is symmetric (for smooth \(f\)). The second-order Taylor expansion adds a curvature term:

\[ f(\mathbf{x}+\mathbf{h})\approx f(\mathbf{x})+\nabla f\cdot\mathbf{h}+\tfrac12\,\mathbf{h}^{\intercal}\mathbf{H}\,\mathbf{h}. \tag{17.7}\]

Along a unit direction \(\mathbf{u}\), the curvature is \(\mathbf{u}^{\intercal}\mathbf{H}\mathbf{u}\). Since \(\mathbf{H}\) is symmetric, the spectral theorem (Chapter 7) says its eigenvectors are orthogonal. The curvature is largest along the eigenvector with the largest eigenvalue, and smallest along the one with the smallest eigenvalue.

17.4.1 Critical points

At a point where \(\nabla f=\mathbf{0}\), the eigenvalues of \(\mathbf{H}\) classify the point:

Eigenvalues of \(\mathbf{H}\) Type Picture
all positive local minimum a bowl
all negative local maximum a dome
mixed signs saddle point a pass: up one way, down another
some zero flat direction a valley floor 
cases = {
    "round bowl":      np.array([[2.0, 0.0], [0.0, 2.0]]),
    "elongated bowl":  np.array([[10.0, 3.0], [3.0, 1.0]]),
    "saddle":          np.array([[2.0, 0.0], [0.0, -2.0]]),
}
gx, gy = np.meshgrid(np.linspace(-2, 2, 200), np.linspace(-2, 2, 200))
fig, axes = plt.subplots(1, 3, figsize=(11, 3.6))
for ax, (name, H) in zip(axes, cases.items()):
    Z = 0.5 * (H[0, 0] * gx ** 2 + 2 * H[0, 1] * gx * gy + H[1, 1] * gy ** 2)
    ax.contour(gx, gy, Z, levels=12, cmap="viridis")
    lam, V = np.linalg.eigh(H)
    for k in range(2):
        draw_arrow(ax, 1.2 * V[:, k], color=PALETTE["loss"] if lam[k] < 0 else PALETTE["model"], lw=2.5)
    ax.set_title(f"{name}\nλ = {np.round(lam, 2)}", fontsize=10); ax.set_aspect("equal")
    ax.set_xticks([]); ax.set_yticks([])
plt.tight_layout(); plt.show()

The ratio of the largest to the smallest eigenvalue is the condition number, \(\kappa=\lambda_{\max}/\lambda_{\min}\). A large \(\kappa\) means a long, narrow valley. It makes gradient descent slow (Chapters 19 and 20).

17.4.2 Hessian of the line-fit loss

For the mean squared error of a line, \(L(a,b)=\frac1N\sum_i(ax_i+b-y_i)^2\), the Hessian is constant:

\[ \mathbf{H}=2\begin{pmatrix}\overline{x^2}&\bar{x}\\ \bar{x}&1\end{pmatrix}. \tag{17.8}\]

rng = np.random.default_rng(0)
x = rng.uniform(-2, 2, 30); y = 2 * x + 1 + rng.normal(0, 0.5, 30)

def grad_L(t):
    a, b = t
    e = a * x + b - y
    return np.array([2 * np.mean(e * x), 2 * np.mean(e)])

H_analytic = 2 * np.array([[np.mean(x ** 2), np.mean(x)], [np.mean(x), 1.0]])
t0, eps = np.array([0.3, -0.5]), 1e-5
H_numeric = np.stack([(grad_L(t0 + eps * e) - grad_L(t0 - eps * e)) / (2 * eps)
                      for e in np.eye(2)], axis=1)    # differentiate the gradient
lam = np.linalg.eigvalsh(H_analytic)
print("Hessian (analytic):\n", np.round(H_analytic, 3))
print("max |analytic − numeric|:", np.abs(H_analytic - H_numeric).max())
print(f"eigenvalues: {np.round(lam, 3)}   condition number {lam[1] / lam[0]:.2f}")
Hessian (analytic):
 [[3.25  0.275]
 [0.275 2.   ]]
max |analytic − numeric|: 1.878991406911723e-10
eigenvalues: [1.942 3.308]   condition number 1.70

Both eigenvalues are positive: the line-fit loss is a bowl, and its single minimum is the least-squares solution.

17.5 A hard landscape: the Rosenbrock valley

Real loss surfaces are not bowls. The Rosenbrock function is a standard test:

\[ f(x,y)=(1-x)^2+100\,(y-x^2)^2. \tag{17.9}\]

Its minimum is at \((1,1)\), at the bottom of a long curved valley. The walls are steep and the floor is nearly flat. Plain gradient descent shows the difficulty.

rosen = lambda x, y: (1 - x) ** 2 + 100 * (y - x ** 2) ** 2
def rosen_grad(p):
    x, y = p
    return np.array([-2 * (1 - x) - 400 * x * (y - x ** 2), 200 * (y - x ** 2)])

p = np.array([-1.5, 2.0]); path = [p.copy()]
for _ in range(5000):
    p = p - 0.001 * rosen_grad(p)
    path.append(p.copy())
path = np.array(path)

gx, gy = np.meshgrid(np.linspace(-2, 2, 300), np.linspace(-1, 3, 300))
fig, ax = plt.subplots(figsize=(5.6, 4.4))
ax.contour(gx, gy, np.log1p(rosen(gx, gy)), levels=18, cmap="viridis")
ax.plot(*path.T, color=PALETTE["loss"], lw=1)
ax.plot(*path[0], "ko"); ax.plot(1, 1, "*", color=PALETTE["grad"], ms=14)
ax.set_aspect("equal")
plt.show()
print(f"after 5000 steps: position {np.round(path[-1], 3)}, f = {rosen(*path[-1]):.4f}")
after 5000 steps: position [0.919 0.845], f = 0.0065

Two forces fight. The step must be small to stay stable across the steep walls (large curvature). Then it is too small to make progress along the floor (small curvature). Momentum and adaptive methods (Chapter 19) were invented for this.

17.6 Hessian–vector products: curvature without the matrix

A model with \(n=10^9\) parameters has a Hessian with \(10^{18}\) entries. We can never store it. We can, however, compute a Hessian–vector product \(\mathbf{H}\mathbf{v}\) by differentiating the gradient once more:

\[ \mathbf{H}\mathbf{v}\approx\frac{\nabla f(\mathbf{x}+\epsilon\mathbf{v})-\nabla f(\mathbf{x}-\epsilon\mathbf{v})}{2\epsilon}. \tag{17.10}\]

It costs two gradient evaluations and never forms \(\mathbf{H}\).

rng = np.random.default_rng(1)
n = 500
A = rng.normal(size=(n, n)); Hq = (A + A.T) / 2                      # symmetric
f_quad = lambda x: 0.5 * x @ Hq @ x
g_quad = lambda x: Hq @ x                                            # gradient

x0, v, eps = rng.normal(size=n), rng.normal(size=n), 1e-4
hv_fd = (g_quad(x0 + eps * v) - g_quad(x0 - eps * v)) / (2 * eps)
print("‖H v − finite-difference H v‖ / ‖H v‖ =",
      np.linalg.norm(Hq @ v - hv_fd) / np.linalg.norm(Hq @ v))
‖H v − finite-difference H v‖ / ‖H v‖ = 1.3446831044220557e-12

With this tool, power iteration finds the largest curvature \(\lambda_{\max}\) of a huge model without the matrix. It is how “sharpness” of a trained model is measured.

17.7 Production

PyTorch computes Jacobians and Hessians of any function written with its operations. We check the layer Jacobian and the line-fit Hessian.

import torch
from torch.autograd.functional import jacobian, hessian

Wt, bt = torch.tensor(W), torch.tensor(b)
xv = torch.tensor(rng.normal(size=4))
J_t = jacobian(lambda z: torch.tanh(Wt @ z + bt), xv)
J_ref = (1 - torch.tanh(Wt @ xv + bt) ** 2)[:, None] * Wt
print("autograd Jacobian == diag(1 - a²) W:", torch.allclose(J_t, J_ref))

xd, yd = torch.tensor(x), torch.tensor(y)
loss = lambda t: ((t[0] * xd + t[1] - yd) ** 2).mean()
H_t = hessian(loss, torch.tensor([0.3, -0.5], dtype=torch.float64))
print("autograd Hessian == analytic:", np.allclose(H_t.numpy(), H_analytic))
autograd Jacobian == diag(1 - a²) W: True
autograd Hessian == analytic: True

17.8 Failure modes

Ravines. A large condition number makes the gradient point across the valley, not along it. Plain gradient descent zig-zags (above).

Saddle points. The gradient is zero, but the point is not a minimum. In high dimension, saddles are far more common than local minima, since many eigenvalues must all be positive to make a minimum. A small noise usually lets the optimiser escape.

Plateaus. Where the surface is nearly flat, the gradient is tiny and progress stalls. Saturating activations (Chapter 10) make plateaus.

Scale of the gradient. The gradient depends on the scale of the parameters and the loss. Multiply the loss by 100 and the gradient is 100 times larger. A learning rate must be tuned to this scale.

Size of the Hessian. For \(n\) parameters, \(\mathbf{H}\) has \(n^2\) entries.

\(n\) Entries in \(\mathbf{H}\) Memory in float32
\(10^3\) \(10^6\) 4 MB
\(10^6\) \(10^{12}\) 4 TB
\(10^9\) \(10^{18}\) 4 EB

Models use first-order methods (the gradient) or products with \(\mathbf{H}\), never the matrix.

17.9 Where this appears in modern AI

Place Gradient idea
Training \(\nabla_\theta L\) tells the optimiser which way to go
Backpropagation (Chapter 18) multiplies Jacobians layer by layer
Adaptive optimisers (Chapter 19) rescale each coordinate by a running gradient magnitude
Learning-rate stability (Chapter 20) the step must satisfy \(\eta<2/\lambda_{\max}(\mathbf{H})\)
Sharpness and generalisation the curvature of the minimum a model converges to
Adversarial examples \(\nabla_{\mathbf{x}}L\): the gradient with respect to the input
Saliency and attribution gradient of the output with respect to input features

17.10 System connection

NoteWhat the system gained in this chapter

The system can now describe where to go and what the terrain is like. The gradient gives the direction of steepest descent. The Hessian describes curvature: bowls, valleys, and saddles. The Jacobian generalises the derivative to layers with vector outputs.

Computing \(\nabla_\theta L\) for a deep network by hand is not feasible. Chapter 18 shows how the chain rule gives it exactly, in a single backward pass.

Chapter summary

  • \(\nabla f\) is the vector of partial derivatives. \(D_{\mathbf{u}}f=\nabla f\cdot\mathbf{u}\).
  • The gradient points in the direction of steepest ascent. It is perpendicular to level sets.
  • The Jacobian is the matrix of first derivatives of a vector function. Jacobians of compositions multiply.
  • The Hessian is the matrix of second derivatives. Its eigenvalues describe curvature and classify critical points.
  • The condition number \(\lambda_{\max}/\lambda_{\min}\) measures how elongated a valley is.
  • The Hessian is too large to store, but \(\mathbf{H}\mathbf{v}\) is cheap.
