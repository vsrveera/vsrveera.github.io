9  Linear Transformations

NoteKey ideas
  • A function is linear if it respects addition and scaling. Matrices are exactly the linear functions on vectors.
  • A layer \(\mathbf{y}=\mathbf{W}\mathbf{x}+\mathbf{b}\) is affine: linear plus a shift. The bias trick makes it linear in one more dimension.
  • Each output of a linear layer is a hyperplane test: which side of a flat boundary is \(\mathbf{x}\) on?
  • A linear layer can rotate, stretch, project, and shift. It can never bend.
  • One linear classifier cannot compute XOR. Stacking linear layers does not help.

9.1 The system problem

Part II gave us vectors and matrices. Part III asks how a model transforms a representation into another one. The simplest transformation that can be learned is a matrix plus a shift.

What can \(\mathbf{y}=\mathbf{W}\mathbf{x}+\mathbf{b}\) do, and why is it the main building block of neural networks despite its limits?

9.2 What linear means

A function \(f:\mathbb{R}^{n}\to\mathbb{R}^m\) is linear if for all vectors \(\mathbf{x},\mathbf{z}\) and scalars \(a,b\):

\[ f(a\mathbf{x}+b\mathbf{z})=a\,f(\mathbf{x})+b\,f(\mathbf{z}). \tag{9.1}\]

Two special cases carry the idea: additivity \(f(\mathbf{x}+\mathbf{z})=f(\mathbf{x})+f(\mathbf{z})\) and homogeneity \(f(a\mathbf{x})=af(\mathbf{x})\). One consequence: \(f(\mathbf{0})=\mathbf{0}\).

Every matrix gives a linear function. The reverse also holds: a linear function on \(\mathbb{R}^n\) is a matrix whose columns are \(f(\mathbf{e}_1),\dots,f(\mathbf{e}_n)\) (Chapter 5).

We test linearity numerically. The test samples random inputs and checks Equation 9.1.

rng = np.random.default_rng(0)

def is_linear(f, n, trials=100, tol=1e-9):
    for _ in range(trials):
        x, z = rng.normal(size=n), rng.normal(size=n)
        a, b = rng.normal(size=2)
        if not np.allclose(f(a * x + b * z), a * f(x) + b * f(z), atol=tol):
            return False
    return True

W = rng.normal(size=(3, 4)); bias = rng.normal(size=3)
tests = {
    "W x":              lambda x: W @ x,
    "W x + b":          lambda x: W @ x + bias,
    "ReLU(W x)":        lambda x: np.maximum(0, W @ x),
    "x ⊙ x  (square)":  lambda x: x * x,
    "sum of x":         lambda x: np.array([x.sum()]),
}
for name, f in tests.items():
    n = 4
    print(f"{name:18s} linear: {is_linear(f, n)}")
W x                linear: True
W x + b            linear: False
ReLU(W x)          linear: False
x ⊙ x  (square)    linear: False
sum of x           linear: True

Note that \(\mathbf{W}\mathbf{x}+\mathbf{b}\) fails the test. It is affine, not linear, because \(f(\mathbf{0})=\mathbf{b}\ne\mathbf{0}\). In machine learning we call it a “linear layer”, and the context decides what is meant.

9.2.1 The bias trick

An affine map can be written as a linear map in one more dimension. Append a constant \(1\) to the input and a column \(\mathbf{b}\) to the matrix:

\[ \begin{pmatrix}\mathbf{W}&\mathbf{b}\end{pmatrix} \begin{pmatrix}\mathbf{x}\\1\end{pmatrix} =\mathbf{W}\mathbf{x}+\mathbf{b}. \tag{9.2}\]

x = rng.normal(size=4)
W_aug = np.hstack([W, bias[:, None]])            # (3, 5)
x_aug = np.append(x, 1.0)                        # (5,)
print("bias trick matches:", np.allclose(W_aug @ x_aug, W @ x + bias))
bias trick matches: True

This is why we may study \(\mathbf{W}\mathbf{x}\) and treat the bias as a weight on a constant input.

9.3 Geometry: what a layer does to space

Chapter 7 showed that any matrix is rotate–stretch–rotate (SVD). A linear layer adds one more step: translate by \(\mathbf{b}\).

W2 = np.array([[1.6, 0.5], [0.3, 0.9]]); b2 = np.array([1.2, 0.8])
U, s, Vt = np.linalg.svd(W2)
t = np.linspace(0, 2 * np.pi, 200); C = np.stack([np.cos(t), np.sin(t)])
steps = [("input: circle", C),
         ("rotate  Vᵀ", Vt @ C),
         ("stretch  Σ", np.diag(s) @ Vt @ C),
         ("rotate  U, shift  b", U @ np.diag(s) @ Vt @ C + b2[:, None])]
fig, axes = plt.subplots(1, 4, figsize=(11, 3.0))
for ax, (title, pts) in zip(axes, steps):
    setup_2d(ax, xlim=(-2.5, 3.5), ylim=(-2.5, 3.5), xlabel="", ylabel="")
    ax.plot(*pts, color=PALETTE["data"], lw=2); ax.set_title(title, fontsize=10)
draw_arrow(axes[3], b2, color=PALETTE["model"], lw=2.5)
plt.tight_layout(); plt.show()
print("singular values (stretch factors):", np.round(s, 3))
singular values (stretch factors): [1.786 0.722]

Four things cannot happen in a linear layer:

  • Straight lines never become curves.
  • Parallel lines stay parallel.
  • The origin moves only by the shift \(\mathbf{b}\).
  • A rank-deficient \(\mathbf{W}\) flattens space onto a lower-dimensional subspace. Information is lost for good.

9.4 Hyperplanes: each output is a boundary

Consider one output of a layer: \(y=\mathbf{w}\cdot\mathbf{x}+b\). The set where \(y=0\) is a hyperplane: a line in 2D, a plane in 3D, and a flat \((n-1)\)-dimensional surface in \(\mathbb{R}^n\). The vector \(\mathbf{w}\) is normal (perpendicular) to it. The sign of \(y\) tells on which side a point lies.

TipDerivation: signed distance to a hyperplane

Let \(H=\{\mathbf{x}:\mathbf{w}\cdot\mathbf{x}+b=0\}\). Take any point \(\mathbf{p}\in H\). The unit normal is \(\hat{\mathbf{w}}=\mathbf{w}/\lVert\mathbf{w}\rVert\). The signed distance of \(\mathbf{x}\) from \(H\) is the length of the projection of \(\mathbf{x}-\mathbf{p}\) onto \(\hat{\mathbf{w}}\) (Chapter 4):

\[ d(\mathbf{x})=\hat{\mathbf{w}}\cdot(\mathbf{x}-\mathbf{p})=\frac{\mathbf{w}\cdot\mathbf{x}-\mathbf{w}\cdot\mathbf{p}}{\lVert\mathbf{w}\rVert}=\frac{\mathbf{w}\cdot\mathbf{x}+b}{\lVert\mathbf{w}\rVert}, \]

because \(\mathbf{w}\cdot\mathbf{p}=-b\) for \(\mathbf{p}\in H\). \(\blacksquare\)

So the output \(y\) is the signed distance to the boundary, scaled by \(\lVert\mathbf{w}\rVert\). A linear classifier decides by the sign of \(y\).

9.4.1 A linear classifier: the perceptron

The perceptron is the oldest learning rule. For each misclassified point, move the boundary towards it: \(\mathbf{w}\leftarrow\mathbf{w}+y_{i}\mathbf{x}_i\), where \(y_{i}\in\{-1,+1\}\). We use the bias trick, so \(b\) is part of \(\mathbf{w}\).

def perceptron(X, y, epochs=50):
    Xa = np.hstack([X, np.ones((len(X), 1))])        # bias trick, (N, d+1)
    w = np.zeros(Xa.shape[1])
    for _ in range(epochs):
        mistakes = 0
        for xi, yi in zip(Xa, y):
            if yi * (w @ xi) <= 0:                   # wrong side (or on boundary)
                w += yi * xi
                mistakes += 1
        if mistakes == 0:
            break
    return w

from sklearn.datasets import make_blobs
Xb, yb = make_blobs(n_samples=120, centers=[[-1.5, -1.0], [1.5, 1.2]],
                    cluster_std=0.9, random_state=0)
yb = 2 * yb - 1                                       # labels in {-1, +1}
w = perceptron(Xb, yb)
acc = np.mean(np.sign(np.hstack([Xb, np.ones((len(Xb), 1))]) @ w) == yb)
print("weights (w1, w2, b):", np.round(w, 2), "  accuracy:", acc)
weights (w1, w2, b): [ 2.68  0.7  -1.  ]   accuracy: 1.0
fig, ax = plt.subplots(figsize=(5.6, 4.2))
ax.scatter(*Xb[yb == -1].T, color=PALETTE["data"], s=14, label="class −1")

ax.plot(xs, line(0), color="black", lw=2)

           color=PALETTE["loss"], lw=2.5)

9.4.2 What a single hyperplane cannot do: XOR

XOR is true when exactly one input is true. Its four points \((0,0),(1,1)\mapsto-1\) and \((0,1),(1,0)\mapsto+1\) cannot be separated by one line. No choice of \(\mathbf{w},b\) works.

TipProof that no line separates XOR

Suppose \(\mathbf{w}\cdot\mathbf{x}+b\) is positive at \((0,1)\) and \((1,0)\), and negative at \((0,0)\) and \((1,1)\). Adding the two positive conditions: \(w_1+w_2+2b>0\). Adding the two negative ones: \(w_1+w_2+2b<0\). Contradiction. \(\blacksquare\)

Xx = np.array([[0, 0], [1, 1], [0, 1], [1, 0]], dtype=float)
yx = np.array([-1, -1, 1, 1])
Xxa = np.hstack([Xx, np.ones((4, 1))])
best = 0.0
w_x = np.zeros(3)
for epoch in range(200):
    for xi, yi in zip(Xxa, yx):
        if yi * (w_x @ xi) <= 0:
            w_x += yi * xi
    best = max(best, np.mean(np.sign(Xxa @ w_x) == yx))
print(f"best accuracy over 200 epochs: {best:.2f}")

fig, ax = plt.subplots(figsize=(3.6, 3.4))
for pt, lab in zip(Xx, yx):
    ax.scatter(*pt, s=160, color=PALETTE["model"] if lab == 1 else PALETTE["data"])
ax.set_xlim(-0.5, 1.5); ax.set_ylim(-0.5, 1.5); ax.set_aspect("equal")
ax.set_xlabel("$x_1$"); ax.set_ylabel("$x_2$")
plt.show()
best accuracy over 200 epochs: 0.50

9.5 A linear classifier for digits

For many classes, we use one hyperplane per class: \(\mathbf{W}\in\mathbb{R}^{10\times64}\). The score vector is \(\mathbf{s}=\mathbf{W}\mathbf{x}+\mathbf{b}\), and the prediction is the largest score. We fit \(\mathbf{W}\) by least squares against one-hot targets. This is a closed-form solve (Chapter 5). We do not need gradients yet.

from sklearn.datasets import load_digits
from sklearn.model_selection import train_test_split
digits = load_digits()
Xtr, Xte, ytr, yte = train_test_split(digits.data / 16.0, digits.target,
                                      test_size=0.25, random_state=0,
                                      stratify=digits.target)
A_tr = np.hstack([Xtr, np.ones((len(Xtr), 1))])        # bias trick, (N, 65)
T = np.eye(10)[ytr]                                    # one-hot targets, (N, 10)
Wls = np.linalg.lstsq(A_tr, T, rcond=None)[0]          # (65, 10)

A_te = np.hstack([Xte, np.ones((len(Xte), 1))])
pred = (A_te @ Wls).argmax(axis=1)
print(f"test accuracy of the linear classifier: {np.mean(pred == yte):.3f}")
print("parameters:", Wls.size)
test accuracy of the linear classifier: 0.938
parameters: 650

A linear model recognises most digits. Each row of \(\mathbf{W}\) is a template: it scores an image by how well it matches a pixel pattern.

fig, axes = plt.subplots(1, 10, figsize=(11, 1.5))
for c, ax in enumerate(axes):
    ax.imshow(Wls[:64, c].reshape(8, 8), cmap="RdBu_r",
              vmin=-1.2, vmax=1.2)

9.6 Cost: parameters and FLOPs

A layer from \(n_{\text{in}}\) to \(n_{\text{out}}\) has \(n_{\text{out}}n_{\text{in}}+n_{\text{out}}\) parameters. It needs about \(2\,n_{\text{out}}n_{\text{in}}\) FLOPs per input vector: one multiply and one add per weight.

def layer_cost(n_in, n_out):
    params = n_out * n_in + n_out
    flops = 2 * n_out * n_in
    return params, flops

rows = [("digits classifier", 64, 10),
        ("MNIST classifier", 784, 10),
        ("hidden layer", 784, 256),
        ("transformer projection", 4096, 4096),
        ("LLM MLP up-projection", 4096, 16384)]
print(f"{'layer':26s} {'params':>14s} {'FLOPs / vector':>16s}")
for name, n_in, n_out in rows:
    p, f = layer_cost(n_in, n_out)
    print(f"{name:26s} {p:14,d} {f:16,d}")
layer                              params   FLOPs / vector
digits classifier                     650            1,280
MNIST classifier                    7,850           15,680
hidden layer                      200,960          401,408
transformer projection         16,781,312       33,554,432
LLM MLP up-projection          67,125,248      134,217,728

9.7 Stacked linear layers collapse

What if we stack two linear layers? The result is again one linear layer.

\[ \mathbf{W}_2(\mathbf{W}_{1}\mathbf{x}+\mathbf{b}_1)+\mathbf{b}_2=(\mathbf{W}_{2}\mathbf{W}_1)\mathbf{x}+(\mathbf{W}_{2}\mathbf{b}_1+\mathbf{b}_2). \tag{9.3}\]

rng = np.random.default_rng(3)
W1, b1 = rng.normal(size=(5, 4)), rng.normal(size=5)
W2, b2 = rng.normal(size=(3, 5)), rng.normal(size=3)
x = rng.normal(size=4)

two_layers = W2 @ (W1 @ x + b1) + b2
one_layer = (W2 @ W1) @ x + (W2 @ b1 + b2)
print("two layers == one layer:", np.allclose(two_layers, one_layer))
two layers == one layer: True

Depth gives no new power without something between the layers. Chapter 10 adds it.

9.8 From first principles to production

nn.Linear is this layer. We load our least-squares weights into it and check that it gives the same predictions.

import torch
import torch.nn as nn

lin = nn.Linear(64, 10).double()
with torch.no_grad():
    lin.weight.copy_(torch.tensor(Wls[:64].T))        # (10, 64)
    lin.bias.copy_(torch.tensor(Wls[64]))             # (10,)
out = lin(torch.tensor(Xte))
print("same predictions as NumPy:", bool((out.argmax(1).numpy() == pred).all()))
same predictions as NumPy: True

9.9 Failure modes

Not linearly separable. XOR is the smallest example. Real data is often not separable in the raw feature space. A richer representation or a nonlinearity is needed.

Collinear features. If one feature is a combination of others, the least-squares problem has no unique answer and the normal equations \(\mathbf{A}^{\intercal}\mathbf{A}\) are singular.

rng = np.random.default_rng(0)
a = rng.normal(size=(50, 2))
A_col = np.column_stack([a, a[:, 0] + a[:, 1]])        # third column = sum of first two
print("rank of A:", np.linalg.matrix_rank(A_col), " columns:", A_col.shape[1])
print("condition number of AᵀA: %.1e" % np.linalg.cond(A_col.T @ A_col))
rank of A: 2  columns: 3
condition number of AᵀA: 1.9e+16

lstsq returns the minimum-norm solution and is safe. Solving the normal equations by hand is not.

Features at different scales. The weights on large-scale features are tiny and on small-scale features are huge. Standardise first (Chapter 3).

A boundary is only a sign. The raw output \(y\) is a distance times \(\lVert\mathbf{w}\rVert\). It is not a probability. Chapter 24 turns scores into probabilities.

9.10 Where this appears in modern AI

Place Linear layer role
MLP in a Transformer two large linear layers (up and down projection)
Attention \(\mathbf{W}_Q,\mathbf{W}_K,\mathbf{W}_V,\mathbf{W}_O\) are linear maps
Classification head one linear layer from features to class scores
Token output head linear map from hidden state to vocabulary scores
\(1\times1\) convolution a linear layer applied at every pixel
LoRA (Chapter 7) a low-rank update to a linear layer
Most model parameters live in linear layers; most FLOPs are matrix products

9.11 System connection

NoteWhat the system gained in this chapter

The system has its first learnable transformation: an affine layer that rotates, stretches, projects, and shifts, and whose rows are hyperplane tests. It is cheap, differentiable, and runs fast on hardware.

It has a hard limit. Any stack of linear layers is one linear layer. The system still cannot compute XOR. Chapter 10 adds the missing ingredient.

Chapter summary

  • A function is linear if \(f(a\mathbf{x}+b\mathbf{z})=af(\mathbf{x})+bf(\mathbf{z})\). Matrices are exactly the linear maps.
  • \(\mathbf{W}\mathbf{x}+\mathbf{b}\) is affine. The bias trick appends a 1 to the input.
  • A layer is rotate–stretch–rotate–shift. It never bends space.
  • Each output is a hyperplane. \(y/\lVert\mathbf{w}\rVert\) is the signed distance.
  • A perceptron learns a hyperplane by moving it towards mistakes. It cannot learn XOR.
  • A layer has \(n_{\text{out}}n_{\text{in}}+n_{\text{out}}\) parameters and about \(2n_{\text{out}}n_{\text{in}}\) FLOPs.
  • Stacked linear layers collapse into one.
