49  Operating Curves, ROC and Confidence

NoteKey ideas
  • A decision component has two kinds of error: missing a true case (miss) and reporting a false one (false alarm). The ROC curve shows the trade-off at every threshold.
  • A single threshold is an operating point. Requirements are stated at an operating point (for example “detection rate at 1 false alarm per 1,000 samples”).
  • A measured rate from a finite test set is an estimate with a confidence interval. A rate that is zero in the test set is not zero in the world.
  • Two algorithms are compared on the same test items with a paired analysis. The difference, not the two separate scores, carries the evidence.
  • The size of the test set follows from the requirement. It is computed before the experiment.

49.1 The system problem

The detector of Chapter 47 outputs a score and compares it with a threshold. A low threshold finds more true cases and raises more false alarms. A high threshold does the opposite. We cannot say how good the detector is without saying at which threshold.

We have two detectors and a test set of 400 items. Detector B scores higher. Is B better, and by how much, and how sure are we?

The answer needs three tools: the ROC curve, a confidence interval and a paired test.

49.2 Two errors and one curve

For a score \(s\) and a threshold \(\tau\), we declare “positive” if \(s>\tau\). Four counts follow: true positives (TP), false positives (FP), true negatives (TN), false negatives (FN). Two rates describe the detector:

\[ \text{TPR}(\tau)=\frac{\text{TP}}{\text{TP}+\text{FN}},\qquad \text{FPR}(\tau)=\frac{\text{FP}}{\text{FP}+\text{TN}}. \tag{49.1}\]

TPR is the detection rate (also recall or sensitivity). FPR is the false alarm rate (one minus specificity). The ROC curve (receiver operating characteristic) is the set of points \((\text{FPR}(\tau),\text{TPR}(\tau))\) for all \(\tau\).

The area under the curve (AUC) has a simple meaning: it is the probability that a randomly chosen positive item has a higher score than a randomly chosen negative item. This is the Mann–Whitney statistic (Chapter 26).

We use a model where we know the truth. Negatives have scores \(\mathcal N(0,1)\). Positives have scores \(\mathcal N(d,1)\). The separation \(d\) (“d-prime”) sets the difficulty. In this model the ROC and AUC are known exactly: \(\text{TPR}=Q\bigl(Q^{-1}(\text{FPR})-d\bigr)\) and \(\text{AUC}=\Phi(d/\sqrt2)\).

rng = np.random.default_rng(49)

def roc(scores, labels):
    order = np.argsort(-scores)
    l = labels[order]
    tpr = np.concatenate([[0], np.cumsum(l) / l.sum()])
    fpr = np.concatenate([[0], np.cumsum(1 - l) / (1 - l).sum()])
    return fpr, tpr

def auc_rank(scores, labels):
    # Mann-Whitney: P(score_pos > score_neg), ties count one half
    pos, neg = scores[labels == 1], scores[labels == 0]
    return ((pos[:, None] > neg[None, :]).mean() + 0.5 * (pos[:, None] == neg[None, :]).mean())

d_A, d_B = 1.5, 1.8
print("exact AUC  A:", norm.cdf(d_A / np.sqrt(2)).round(4), "  B:", norm.cdf(d_B / np.sqrt(2)).round(4))

n_pos = n_neg = 200
labels = np.r_[np.ones(n_pos, int), np.zeros(n_neg, int)]
# a SHARED latent per item makes the two detectors' errors correlated, as real detectors are
shared = rng.normal(size=labels.size)
sA = labels * d_A + 0.7 * shared + np.sqrt(1 - 0.49) * rng.normal(size=labels.size)
sB = labels * d_B + 0.7 * shared + np.sqrt(1 - 0.49) * rng.normal(size=labels.size)
print("test set (400 items) AUC  A:", auc_rank(sA, labels).round(3), "  B:", auc_rank(sB, labels).round(3))
exact AUC  A: 0.8556   B: 0.8985
test set (400 items) AUC  A: 0.874   B: 0.896

On this one test set, B has the higher AUC: \(0.896\) against \(0.874\). The exact values are \(0.899\) and \(0.856\), so the measured gap (\(0.022\)) is about half of the true gap (\(0.043\)). That is sampling noise at work. We quantify it.

49.3 A confidence interval for an operating point

At one threshold, TPR is a proportion: \(k\) detections out of \(n\) positives. The sampling distribution of \(k\) is binomial (Chapter 23). The exact (Clopper–Pearson) interval at confidence \(1-\alpha\) uses the beta distribution:

\[ \bigl[\,B^{-1}(\tfrac\alpha2;\,k,\,n-k+1),\;B^{-1}(1-\tfrac\alpha2;\,k+1,\,n-k)\,\bigr]. \tag{49.2}\]

def clopper_pearson(k, n, alpha=0.05):
    lo = 0.0 if k == 0 else beta.ppf(alpha / 2, k, n - k + 1)
    hi = 1.0 if k == n else beta.ppf(1 - alpha / 2, k + 1, n - k)
    return lo, hi

# operating point: threshold at which A gives FPR about 5%
tau = np.sort(sA[labels == 0])[::-1][int(0.05 * n_neg) - 1]
kA = int((sA[labels == 1] > tau).sum()); fa = int((sA[labels == 0] > tau).sum())
lo, hi = clopper_pearson(kA, n_pos)
print(f"detector A at tau={tau:.2f}: TPR {kA}/{n_pos} = {kA/n_pos:.3f}   95% CI [{lo:.3f}, {hi:.3f}]")
lo, hi = clopper_pearson(fa, n_neg)
print(f"                        FPR {fa}/{n_neg} = {fa/n_neg:.3f}   95% CI [{lo:.3f}, {hi:.3f}]")
detector A at tau=1.70: TPR 98/200 = 0.490   95% CI [0.419, 0.561]
                        FPR 9/200 = 0.045   95% CI [0.021, 0.084]

With 200 positives, the detection rate \(0.490\) is known to within about \(\pm0.07\). The false alarm rate \(0.045\) has an interval from \(0.021\) to \(0.084\). It is wide relative to its size, because only 9 events were counted.

49.3.1 A zero is not a zero

If a detector makes no false alarm in \(n\) trials, the 95% upper bound on the false alarm rate is about \(3/n\) (the “rule of three”). Exactly, it is \(1-0.05^{1/n}\).

for n in (100, 300, 1000, 3000, 10000):
    exact = 1 - 0.05 ** (1 / n)
    print(f"n = {n:6d} negatives, 0 false alarms: upper 95% bound {exact:.5f}   (3/n = {3/n:.5f})")
n =    100 negatives, 0 false alarms: upper 95% bound 0.02951   (3/n = 0.03000)
n =    300 negatives, 0 false alarms: upper 95% bound 0.00994   (3/n = 0.01000)
n =   1000 negatives, 0 false alarms: upper 95% bound 0.00299   (3/n = 0.00300)
n =   3000 negatives, 0 false alarms: upper 95% bound 0.00100   (3/n = 0.00100)
n =  10000 negatives, 0 false alarms: upper 95% bound 0.00030   (3/n = 0.00030)

A requirement of “at most 1 false alarm in 1,000” with 95% confidence needs about 3,000 clean negative samples with no false alarm at all. If the detector makes some, the test set must be larger still. This is why Section 45.3 in Chapter 45 includes a confidence statement: it fixes the data size.

49.4 Confidence on a curve and on a score: the bootstrap

For AUC there is no simple closed form that is exact. The bootstrap (Chapter 26) resamples the test items with replacement and recomputes the statistic. We resample positives and negatives separately, so that each replicate keeps the class counts.

def boot_auc(s, y, B=2000, seed=0):
    r = np.random.default_rng(seed)
    pos, neg = s[y == 1], s[y == 0]
    out = np.empty(B)
    for b in range(B):
        p = pos[r.integers(0, pos.size, pos.size)]
        q = neg[r.integers(0, neg.size, neg.size)]
        out[b] = (p[:, None] > q[None, :]).mean()
    return out

bA = boot_auc(sA, labels)
print(f"A: AUC {auc_rank(sA, labels):.3f}   95% bootstrap CI [{np.percentile(bA, 2.5):.3f}, {np.percentile(bA, 97.5):.3f}]")
bB = boot_auc(sB, labels, seed=1)
print(f"B: AUC {auc_rank(sB, labels):.3f}   95% bootstrap CI [{np.percentile(bB, 2.5):.3f}, {np.percentile(bB, 97.5):.3f}]")
A: AUC 0.874   95% bootstrap CI [0.838, 0.905]
B: AUC 0.896   95% bootstrap CI [0.864, 0.925]

The two intervals overlap. It is tempting to conclude “no difference”. That conclusion is wrong in general, because both detectors were scored on the same items. Their errors are correlated, and the intervals of the separate scores ignore this.

49.5 Paired comparison

We resample the items, and compute for each replicate the difference of the two AUCs. A paired analysis uses the correlation between the detectors.

def boot_diff(sA, sB, y, B=2000, seed=2):
    r = np.random.default_rng(seed)
    ip, in_ = np.where(y == 1)[0], np.where(y == 0)[0]
    out = np.empty(B)
    for b in range(B):
        p = ip[r.integers(0, ip.size, ip.size)]
        q = in_[r.integers(0, in_.size, in_.size)]
        a = (sA[p][:, None] > sA[q][None, :]).mean()
        c = (sB[p][:, None] > sB[q][None, :]).mean()
        out[b] = c - a
    return out

dd = boot_diff(sA, sB, labels)
print(f"AUC(B) - AUC(A) = {auc_rank(sB, labels) - auc_rank(sA, labels):+.3f}   "
      f"95% paired CI [{np.percentile(dd, 2.5):+.3f}, {np.percentile(dd, 97.5):+.3f}]")
print("independent-style width of the difference CI:",
      (np.sqrt(bA.var() + bB.var()) * 2 * 1.96).round(3), "   paired width:",
      (np.percentile(dd, 97.5) - np.percentile(dd, 2.5)).round(3))
print("share of bootstrap replicates with B > A:", (dd > 0).mean().round(3))
AUC(B) - AUC(A) = +0.022   95% paired CI [-0.010, +0.056]
independent-style width of the difference CI: 0.092    paired width: 0.066
share of bootstrap replicates with B > A: 0.91

The paired interval has width \(0.066\). The one that treats the scores as independent has width \(0.092\). The paired interval still contains zero: \([-0.010,\,+0.056]\). In \(91\%\) of the replicates B beats A. So the data suggest that B is better and do not establish it. We know from the simulation that B is better, with a gap of \(0.043\). The experiment, with 400 items, is too small to show a gap of this size with confidence. A report must say this, and not “B is better” or “no difference”.

49.6 How big must the test set be?

The width of an interval shrinks like \(1/\sqrt n\). We estimate the AUC interval width as a function of the number of test items, using the model where the truth is known.

ns = [25, 50, 100, 200, 400, 800, 1600]
widths = []
r = np.random.default_rng(3)
for n in ns:
    ws = []
    for rep in range(6):
        y = np.r_[np.ones(n, int), np.zeros(n, int)]
        s = r.normal(size=2 * n) + d_A * y
        b = boot_auc(s, y, B=300, seed=int(r.integers(1e6)))
        ws.append(np.percentile(b, 97.5) - np.percentile(b, 2.5))
    widths.append(np.mean(ws))
fig, ax = plt.subplots(figsize=(6.2, 3.4))
ax.loglog(ns, widths, "o-", color=PALETTE["loss"], label="measured width")
ref = widths[0] * np.sqrt(ns[0] / np.array(ns))
ax.loglog(ns, ref, "--", color="gray", label=r"$\propto 1/\sqrt{n}$")
ax.set_xlabel("items per class n"); ax.set_ylabel("95% CI width of AUC"); ax.legend()
plt.show()
for n, w in zip(ns, widths):
    print(f"n = {n:5d} per class: mean width {w:.3f}")
n =    25 per class: mean width 0.209
n =    50 per class: mean width 0.148
n =   100 per class: mean width 0.097
n =   200 per class: mean width 0.070
n =   400 per class: mean width 0.050
n =   800 per class: mean width 0.035
n =  1600 per class: mean width 0.025

A rule of thumb: AUC near 0.85 needs about 100 items per class for a width near \(0.1\), and about 1,600 per class for a width near \(0.025\). For a difference between two detectors with a gap of \(0.02\), the sample must be large enough that the paired interval is narrower than the gap.

49.7 Operating points are requirements

A production system works at one threshold. The ROC curve lets us choose it from a requirement: the largest TPR subject to \(\text{FPR}\le\alpha\), or the lowest cost under stated costs of the two errors.

For costs \(c_{FN}\) and \(c_{FP}\) and prior probability \(\pi\) of a positive, the expected cost at a threshold is \(\pi\,c_{FN}(1-\text{TPR})+(1-\pi)\,c_{FP}\,\text{FPR}\). The best point on the ROC curve is where its slope equals \(\frac{(1-\pi)c_{FP}}{\pi\,c_{FN}}\). The threshold depends on \(\pi\). If the prevalence of positives in deployment differs from the test set, the best threshold moves (Chapter 27).

fprA, tprA = roc(sA, labels); fprB, tprB = roc(sB, labels)
fig, ax = plt.subplots(figsize=(5.2, 4.2))
ax.plot(fprA, tprA, color=PALETTE["model"], lw=2, label=f"A  (AUC {auc_rank(sA, labels):.3f})")
ax.plot(fprB, tprB, color=PALETTE["data"], lw=2, label=f"B  (AUC {auc_rank(sB, labels):.3f})")
ax.plot([0, 1], [0, 1], color="gray", lw=1, ls="--")
ax.plot(fa / n_neg, kA / n_pos, "ko"); ax.annotate("operating point of A", (fa / n_neg + 0.02, kA / n_pos - 0.07))
ax.set_xlabel("false alarm rate FPR"); ax.set_ylabel("detection rate TPR"); ax.legend(loc="lower right")
plt.show()
at = 0.01
print("TPR at FPR <= 0.01:  A", tprA[fprA <= at].max().round(3), "  B", tprB[fprB <= at].max().round(3),
      "  (one false alarm = 0.005 in FPR with 200 negatives)")
TPR at FPR <= 0.01:  A 0.23   B 0.38   (one false alarm = 0.005 in FPR with 200 negatives)

The curve values at FPR \(0.01\) rest on two false-alarm items. Any claim made at such a point has a very wide interval. For this reason ROC plots in a report should show the interval band, or the claim should be restricted to the region where the data are dense.

49.8 Failure modes

One score for a curve. AUC averages over operating points that nobody will use. Report the point of the requirement.

Rate without count. “0% false alarms” with no number of trials.

Unpaired comparison. Separate intervals for two systems tested on the same items. This is conservative and can hide a real improvement.

Test set reuse. Choosing a threshold, a model and a report from one set (Chapter 27).

Prevalence mismatch. Precision depends on the share of positives. A detector with TPR 0.9 and FPR 0.05 has precision \(0.5\) when positives are 5% of items. It is \(0.95\) when they are 50%.

Interval on the wrong unit. If several frames come from one video, the independent unit is the video. Resample by video.

49.9 Where this appears in modern AI

Place Operating curve
Classification and screening ROC, precision-recall; sensitivity at fixed specificity
Object detection recall at false positives per image; mean average precision
Anomaly and fraud detection detection at a low false alarm rate; alert budget
Safety filters for language models false refusal against missed harm
Face and speaker verification false accept against false reject; equal error rate
Model comparison paired bootstrap, McNemar test, significance of benchmark gains

49.10 System connection

NoteWhat the system gained in this chapter

The system can now make a claim with a stated confidence. We have the two-error picture, the ROC curve, an exact interval for a rate, a bootstrap for a score, a paired comparison of two detectors, and a way to compute the data size from the requirement.

What remains is a protocol: how to choose conditions and parameters to test, how to separate tuning data from reporting data, how to test the model when its assumptions are wrong, and how to write the result. Chapter 50 gives the protocol. Chapter 51 applies it to large models.

Chapter summary

  • TPR and FPR are the two error rates. The ROC curve shows every operating point.
  • AUC is the probability that a positive outscores a negative.
  • A rate from \(n\) trials has an interval of width about \(1/\sqrt n\). Zero events in \(n\) trials gives an upper bound near \(3/n\).
  • Compare two systems on the same items with a paired bootstrap.
  • The requirement fixes the operating point and the test size.
