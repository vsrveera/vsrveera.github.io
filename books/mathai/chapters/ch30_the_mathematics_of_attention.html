30  The Mathematics of Attention

NoteKey ideas
  • Attention is a soft dictionary lookup: a query is compared with keys, the scores become weights by softmax, and the output is the weighted average of the values.
  • The equation is \(\text{softmax}\!\bigl(QK^{\intercal}/\sqrt{d_k}\bigr)V\). Every symbol is an object from Parts II–VI.
  • Dividing by \(\sqrt{d_k}\) keeps the variance of the scores at 1, so the softmax does not saturate.
  • A mask sets forbidden scores to \(-\infty\) before the softmax. The causal mask forbids looking at the future.
  • Multi-head attention runs several lookups in parallel subspaces. Cost is \(O(T^2d)\) in time and \(O(T^2)\) in memory.

30.1 The system problem

A sentence is a sequence of token vectors. To understand a token, the model needs information from other tokens: in “the animal did not cross the street because it was tired”, the vector for it must draw on animal. Which tokens matter depends on the content, not on fixed positions.

How can each token build its new representation from all other tokens, with weights that depend on the content?

A fixed linear layer cannot do it (its weights do not depend on the input). A convolution looks only at a fixed neighbourhood. Attention does exactly this job. It is the core of every Transformer.

30.3 Intuition: soft lookup

A Python dictionary maps a key to a value. A lookup returns the value of the key that equals the query. A soft lookup compares the query with every key, and returns a blend of values weighted by how well each key matches.

This is the idea of semantic search (Chapters 4 and 13): the key is the embedding of a document, the query is the embedding of a question. Attention does it inside the network, for every token at once.

Take a query \(\mathbf{q}\), keys \(\mathbf{k}_1,\dots,\mathbf{k}_T\), values \(\mathbf{v}_1,\dots,\mathbf{v}_T\):

\[ s_j=\mathbf{q}\cdot\mathbf{k}_j,\qquad a_j=\frac{e^{s_j}}{\sum_ie^{s_i}},\qquad \mathbf{o}=\sum_ja_j\,\mathbf{v}_j. \tag{30.1}\]

The scores come from the dot product (Chapter 4). The weights come from the softmax (Chapter 24): non-negative and summing to one. The output is a convex combination of the values.

import math
keys   = [[1.0, 0.0], [0.0, 1.0], [0.7, 0.7]]
values = [[10.0, 0.0], [0.0, 10.0], [5.0, 5.0]]
query  = [0.9, 0.1]                                   # close to the first key

scores = [sum(q * k for q, k in zip(query, key)) for key in keys]
m = max(scores)                                       # stable softmax
exps = [math.exp(s - m) for s in scores]
weights = [e / sum(exps) for e in exps]
output = [sum(w * v[c] for w, v in zip(weights, values)) for c in range(2)]
print("scores :", [round(s, 3) for s in scores])
print("weights:", [round(w, 3) for w in weights], " sum =", round(sum(weights), 6))
print("output :", [round(o, 3) for o in output])
scores : [0.9, 0.1, 0.7]
weights: [0.441, 0.198, 0.361]  sum = 1.0
output : [6.214, 3.786]

The query is closest to the first key, so the output leans towards the first value. Sharper queries give a harder lookup.

30.4 From tokens to queries, keys and values

In a Transformer, queries, keys, and values all come from the same token matrix \(\mathbf{X}\in\mathbb{R}^{T\times d}\) (hence “self-attention”), through three learned linear maps (Chapter 9):

\[ \mathbf{Q}=\mathbf{X}\mathbf{W}_Q,\qquad \mathbf{K}=\mathbf{X}\mathbf{W}_K,\qquad \mathbf{V}=\mathbf{X}\mathbf{W}_V, \tag{30.2}\]

with \(\mathbf{W}_Q,\mathbf{W}_{K}\in\mathbb{R}^{d\times d_k}\) and \(\mathbf{W}_{V}\in\mathbb{R}^{d\times d_v}\). Each token plays three roles: what it asks (query), what it offers for matching (key), and what it hands over (value). Separate maps let a token ask for one thing and offer another.

For all tokens at once, all scores form one matrix product:

\[ \mathbf{S}=\frac{\mathbf{Q}\mathbf{K}^{\intercal}}{\sqrt{d_k}}\in\mathbb{R}^{T\times T},\qquad \mathbf{A}=\text{softmax}_{\text{rows}}(\mathbf{S}),\qquad \mathbf{O}=\mathbf{A}\mathbf{V}\in\mathbb{R}^{T\times d_v}. \tag{30.3}\]

Row \(i\) of \(\mathbf{A}\) is the distribution of attention that token \(i\) pays to every token.

def softmax(z, axis=-1):
    z = z - z.max(axis=axis, keepdims=True)
    e = np.exp(z)
    return e / e.sum(axis=axis, keepdims=True)

def attention(Q, K, V, mask=None):
    """Q, K: (T, d_k); V: (T, d_v); mask: (T, T) bool, True = allowed."""
    S = Q @ K.T / np.sqrt(K.shape[-1])                   # (T, T) scores
    if mask is not None:
        S = np.where(mask, S, -np.inf)                   # forbid masked pairs
    A = softmax(S, axis=-1)                              # (T, T) rows sum to 1
    return A @ V, A                                      # (T, d_v)

rng = np.random.default_rng(0)
T, d, dk = 6, 16, 8
X = rng.normal(size=(T, d))
Wq, Wk, Wv = (rng.normal(size=(d, dk)) / np.sqrt(d) for _ in range(3))
O, A = attention(X @ Wq, X @ Wk, X @ Wv)
print("output shape:", O.shape, "  attention shape:", A.shape)
print("rows of A sum to 1:", np.allclose(A.sum(axis=1), 1.0))
output shape: (6, 8)   attention shape: (6, 6)
rows of A sum to 1: True

30.5 Why divide by \(\sqrt{d_k}\)

TipDerivation: the variance of a dot product

Suppose the components of \(\mathbf{q}\) and \(\mathbf{k}\) are independent, with mean 0 and variance 1. Each product \(q_ik_i\) has mean 0 and variance \(\mathbb{E}[q_i^2]\,\mathbb{E}[k_i^2]=1\). The dot product is a sum of \(d_k\) independent such terms. Variances of independent terms add (Chapter 21): \[ \text{Var}(\mathbf{q}\cdot\mathbf{k})=d_k. \] So the standard deviation of a score grows like \(\sqrt{d_k}\). Dividing by \(\sqrt{d_k}\) gives a score of variance 1. \(\blacksquare\)

Why does it matter? The softmax is sensitive to the scale of its input (temperature, Chapter 24). When scores have a large variance, the largest one dominates, the weights become almost one-hot, and the Jacobian of the softmax is near zero: gradients vanish (Chapter 18).

rng = np.random.default_rng(0)
dks = [1, 4, 16, 64, 256, 1024]
var_raw, var_scaled, ent_raw, ent_scaled = [], [], [], []
for dk_ in dks:
    q = rng.normal(size=(20000, dk_)); k = rng.normal(size=(20000, dk_))
    s = (q * k).sum(axis=1)
    var_raw.append(s.var()); var_scaled.append((s / np.sqrt(dk_)).var())
    Q_ = rng.normal(size=(2000, dk_)); K_ = rng.normal(size=(16, dk_))     # 16 keys
    for scale, store in [(1.0, ent_raw), (1 / np.sqrt(dk_), ent_scaled)]:
        P = softmax(Q_ @ K_.T * scale)
        H = -(P * np.log(P + 1e-300)).sum(axis=1)
        store.append(H.mean() / np.log(16))

30.6 Masks

Some pairs must not interact. In a language model that predicts the next token, position \(i\) must not see positions \(j>i\) (they are the answers). A causal mask sets those scores to \(-\infty\) before the softmax. Since \(e^{-\infty}=0\), they receive weight 0, and the remaining weights renormalise.

\[ \tilde S_{ij}=\begin{cases}S_{ij}&j\le i\\-\infty&j>i\end{cases} \tag{30.4}\]

rng = np.random.default_rng(1)
T, dk = 8, 16
Qm, Km, Vm = (rng.normal(size=(T, dk)) for _ in range(3))
causal = np.tril(np.ones((T, T), dtype=bool))
_, A_full = attention(Qm, Km, Vm)
_, A_caus = attention(Qm, Km, Vm, mask=causal)
fig, axes = plt.subplots(1, 2, figsize=(8.5, 3.6))
for ax, A_, title in zip(axes, [A_full, A_caus], ["bidirectional", "causal mask"]):
    im = ax.imshow(A_, cmap="viridis", vmin=0, vmax=0.6)
    ax.set_title(title); ax.set_xlabel("key position j"); ax.set_ylabel("query position i"); ax.grid(False)
plt.colorbar(im, ax=axes, fraction=0.03)
plt.show()
print("upper triangle of causal weights is zero:", np.allclose(np.triu(A_caus, 1), 0))
print("rows still sum to 1:", np.allclose(A_caus.sum(axis=1), 1))

30.7 Multi-head attention

One attention layer computes one distribution of weights per token. Multi-head attention runs \(h\) lookups in parallel, each in its own lower-dimensional subspace, and concatenates the results. Each head can attend to a different relation (previous word, a matching bracket, a subject).

With model width \(d\) and \(d_h=d/h\):

\[ \text{head}_m=\text{Attention}(\mathbf{X}\mathbf{W}_Q^{(m)},\ \mathbf{X}\mathbf{W}_K^{(m)},\ \mathbf{X}\mathbf{W}_V^{(m)}),\qquad \text{MHA}(\mathbf{X})=\bigl[\text{head}_1;\dots;\text{head}_{h}\bigr]\mathbf{W}_O. \tag{30.5}\]

In practice the \(h\) projections are one big matrix. The result is reshaped (Chapter 6) from \((T,d)\) to \((h,T,d_h)\), so all heads run as one batched matrix product.

def mha(X, Wq, Wk, Wv, Wo, h, causal=False):
    T, d = X.shape; dh = d // h
    def split(M):                                        # (T, d) -> (h, T, dh)
        return M.reshape(T, h, dh).transpose(1, 0, 2)
    Q, K, V = split(X @ Wq), split(X @ Wk), split(X @ Wv)
    S = Q @ K.transpose(0, 2, 1) / np.sqrt(dh)           # (h, T, T)
    if causal:
        S = np.where(np.tril(np.ones((T, T), bool)), S, -np.inf)
    A = softmax(S)
    heads = A @ V                                        # (h, T, dh)
    concat = heads.transpose(1, 0, 2).reshape(T, d)      # (T, d)
    return concat @ Wo, A

rng = np.random.default_rng(2)
T, d, h = 6, 32, 4
X = rng.normal(size=(T, d))
Wq, Wk, Wv, Wo = (rng.normal(size=(d, d)) / np.sqrt(d) for _ in range(4))
out, A = mha(X, Wq, Wk, Wv, Wo, h)

# the same computation head by head, with plain slices
dh = d // h
manual = []
for m in range(h):
    sl = slice(m * dh, (m + 1) * dh)
    o_m, _ = attention(X @ Wq[:, sl], X @ Wk[:, sl], X @ Wv[:, sl])
    manual.append(o_m)
out_loop = np.concatenate(manual, axis=1) @ Wo
print("batched reshape version equals the loop over heads:", np.allclose(out, out_loop))
print("output (T, d):", out.shape, "  attention (h, T, T):", A.shape)
print("parameters of MHA: 4 d² =", 4 * d * d)

30.8 Properties

Convex combinations. Each output row is a weighted average of value vectors. It lies inside the convex hull of the values (the smallest convex set containing them).

from scipy.spatial import ConvexHull
rng = np.random.default_rng(0)
Vv = rng.normal(size=(6, 2)) * 2
Kk = rng.normal(size=(6, 4)); Qq = rng.normal(size=(300, 4)) * 1.5
W = softmax(Qq @ Kk.T / 2)
Out = W @ Vv
hull = ConvexHull(Vv)
fig, ax = plt.subplots(figsize=(4.6, 4.2))
poly = np.vstack([Vv[hull.vertices], Vv[hull.vertices][:1]])
ax.plot(*poly.T, "--", color="black")
ax.scatter(*Out.T, s=8, color=PALETTE["model"], alpha=0.6)
ax.scatter(*Vv.T, s=70, color="black"); ax.set_aspect("equal")
plt.show()
inside = np.all(hull.equations[:, :2] @ Out.T + hull.equations[:, 2:3] <= 1e-9, axis=0)
print("fraction of outputs inside the hull:", inside.mean())
fraction of outputs inside the hull: 1.0

Permutation equivariance. Attention has no notion of position. If we shuffle the input tokens, the outputs are shuffled in the same way. The model must therefore be given positions (Chapter 31).

rng = np.random.default_rng(3)
T, d = 7, 16
X = rng.normal(size=(T, d)); W3 = [rng.normal(size=(d, d)) / np.sqrt(d) for _ in range(3)]
perm = rng.permutation(T)
run = lambda X_: attention(X_ @ W3[0], X_ @ W3[1], X_ @ W3[2])[0]
print("attention(P X) == P attention(X):", np.allclose(run(X[perm]), run(X)[perm]))
attention(P X) == P attention(X): True

Cost. The score matrix has \(T^2\) entries. Time is \(O(T^2d)\) and score memory is \(O(T^2)\) (Chapter 6). Doubling the context length multiplies the attention cost by four.

30.9 The backward pass

Training needs \(\partial L/\partial\mathbf{Q}\), \(\partial L/\partial\mathbf{K}\), \(\partial L/\partial\mathbf{V}\). Using the rules of Chapter 18 and the softmax Jacobian of Chapter 24:

TipDerivation

Let \(\mathbf{G}=\partial L/\partial\mathbf{O}\) be the upstream gradient. From \(\mathbf{O}=\mathbf{A}\mathbf{V}\) (a matrix product, Chapter 5): \[ \frac{\partial L}{\partial\mathbf{V}}=\mathbf{A}^{\intercal}\mathbf{G},\qquad \frac{\partial L}{\partial\mathbf{A}}=\mathbf{G}\mathbf{V}^{\intercal}. \] Row \(i\) of \(\mathbf{A}\) is a softmax of row \(i\) of \(\mathbf{S}\). With Jacobian \(\text{diag}(\mathbf{a})-\mathbf{a}\mathbf{a}^{\intercal}\) (Chapter 24), for each row: \[ \frac{\partial L}{\partial S_{ij}}=a_{ij}\Bigl(\frac{\partial L}{\partial A_{ij}}-\sum_{m}a_{im}\frac{\partial L}{\partial A_{im}}\Bigr). \] Finally, from \(\mathbf{S}=\mathbf{Q}\mathbf{K}^{\intercal}/\sqrt{d_k}\): \[ \frac{\partial L}{\partial\mathbf{Q}}=\frac{1}{\sqrt{d_k}}\frac{\partial L}{\partial\mathbf{S}}\,\mathbf{K},\qquad \frac{\partial L}{\partial\mathbf{K}}=\frac{1}{\sqrt{d_k}}\Bigl(\frac{\partial L}{\partial\mathbf{S}}\Bigr)^{\!\intercal}\mathbf{Q}.\ \blacksquare \]

We check these formulas against automatic differentiation.

import torch
rng = np.random.default_rng(4)
T, dk, dv = 5, 8, 6
Qn, Kn, Vn = rng.normal(size=(T, dk)), rng.normal(size=(T, dk)), rng.normal(size=(T, dv))
G = rng.normal(size=(T, dv))                                  # upstream gradient dL/dO

def backward_manual(Q, K, V, G):
    S = Q @ K.T / np.sqrt(K.shape[1]); A = softmax(S)
    dV = A.T @ G
    dA = G @ V.T
    dS = A * (dA - (A * dA).sum(axis=1, keepdims=True))      # softmax Jacobian, row-wise
    dQ = dS @ K / np.sqrt(K.shape[1])
    dK = dS.T @ Q / np.sqrt(K.shape[1])
    return dQ, dK, dV

Qt, Kt, Vt = (torch.tensor(a, requires_grad=True) for a in (Qn, Kn, Vn))
St = Qt @ Kt.T / np.sqrt(dk)
Ot = torch.softmax(St, dim=-1) @ Vt
Ot.backward(torch.tensor(G))
for name, mine, ref in zip(["dQ", "dK", "dV"], backward_manual(Qn, Kn, Vn, G),
                           [Qt.grad, Kt.grad, Vt.grad]):
    print(f"{name}: max |manual − autograd| = {np.abs(mine - ref.numpy()).max():.1e}")
dQ: max |manual − autograd| = 3.3e-16
dK: max |manual − autograd| = 3.3e-16
dV: max |manual − autograd| = 2.2e-16

30.10 From first principles to production

PyTorch fuses the whole operation into one function that never has to store the full \(T\times T\) matrix on suitable hardware (Chapter 34). We check that it equals ours, with and without the causal mask.

import torch.nn.functional as F
rng = np.random.default_rng(5)
T, dk = 10, 16
Qn, Kn, Vn = (rng.normal(size=(1, 2, T, dk)) for _ in range(3))            # (batch, heads, T, d_k)
Qt, Kt, Vt = (torch.tensor(a) for a in (Qn, Kn, Vn))
for causal in (False, True):
    ref = F.scaled_dot_product_attention(Qt, Kt, Vt, is_causal=causal).numpy()
    mask = np.tril(np.ones((T, T), bool)) if causal else None
    ours = np.stack([[attention(Qn[0, h], Kn[0, h], Vn[0, h], mask)[0] for h in range(2)]])
    print(f"causal = {causal!s:5s}: matches F.scaled_dot_product_attention:", np.allclose(ref, ours))

mha_layer = torch.nn.MultiheadAttention(embed_dim=64, num_heads=8, batch_first=True)
print("nn.MultiheadAttention parameters:", sum(p.numel() for p in mha_layer.parameters()),
      "  4d² + 4d =", 4 * 64 * 64 + 4 * 64)

30.12 Failure modes

Saturated softmax. Without \(1/\sqrt{d_k}\), scores are large and the weights are nearly one-hot. Gradients vanish (Figure 34.4). Large learned query and key norms can cause the same effect during training.

Fully masked rows. If all entries of a row are \(-\infty\), the softmax gives \(0/0=\text{NaN}\). This happens with padding masks. Add a safe value or skip such rows.

S_bad = np.full((1, 4), -np.inf)
with np.errstate(invalid="ignore"):
    print("softmax of an all-masked row:", softmax(S_bad))
softmax of an all-masked row: [[nan nan nan nan]]

Quadratic cost. Memory for the score matrix grows with \(T^2\) (Figure 6.5 of Chapter 6). Long contexts need restructured computation (Chapter 34).

No notion of order. Attention is permutation-equivariant. Without positional information, “dog bites man” and “man bites dog” look the same.

Numerical precision. In 16-bit arithmetic, the exponentials and sums need float32 accumulation.

30.14 System connection

NoteWhat the system gained in this chapter

The system can now let every element of a sequence read from every other with content-dependent weights. Attention is a soft lookup built entirely from dot products, a softmax, and weighted averages, with a variance-preserving scale, optional masks, and several heads.

Attention alone is not a model. It has no position, no non-linearity, and no depth. Chapter 31 combines it with an MLP, residual connections, and normalisation into the Transformer block.

Chapter summary

  • Attention is a soft key–value lookup: \(\text{softmax}(\mathbf{Q}\mathbf{K}^{\intercal}/\sqrt{d_k})\mathbf{V}\).
  • \(\mathbf{Q},\mathbf{K},\mathbf{V}\) are linear projections of the tokens.
  • The scale \(1/\sqrt{d_k}\) keeps \(\text{Var}(s)=1\) and prevents softmax saturation.
  • A mask adds \(-\infty\) before the softmax. The causal mask makes the weights lower-triangular.
  • Multi-head attention splits \(d\) into \(h\) subspaces by reshape and concatenates the heads.
  • Outputs lie in the convex hull of the values. Attention is permutation-equivariant. Cost is \(O(T^2d)\).

Exercises

  1. Compute. For two tokens with \(\mathbf{q}=(1,0)\), \(\mathbf{k}_1=(1,0)\), \(\mathbf{k}_2=(0,1)\) and \(\mathbf{v}_1=(2,0)\), \(\mathbf{v}_2=(0,4)\), compute the weights and the output (with \(d_k=2\)).
  2. Derive. Show that if \(\mathbf{q}\) is multiplied by a constant \(c\), the attention weights are those of the softmax at temperature \(1/c\).
  3. Derive. Show that the rows of \(\partial L/\partial\mathbf{S}\) sum to zero. Why is that expected?
  4. Derive. Count the parameters and the multiply–adds of a multi-head attention layer with width \(d\) and sequence length \(T\) (ignore the softmax).
  5. Code. Add a padding mask for sequences of different lengths in a batch. Check that padded keys receive zero weight.
  6. Code. Show with a simulation that attention weights from scaled dot products have an entropy that does not depend on \(d_k\) for random inputs.
  7. Code. Implement cross-attention where the queries come from one sequence and the keys and values from another. Check the shapes.
  8. Code. Measure the time of your NumPy attention for \(T=128,256,512,1024\). Fit the exponent.
  9. Diagnose. A model’s attention weights become exactly one-hot after a few hundred steps and training stalls. Give two causes.
  10. Explain. Why does attention need separate \(\mathbf{W}_Q\) and \(\mathbf{W}_K\) instead of using \(\mathbf{X}\) for both?
