31  The Mathematics of the Transformer

NoteKey ideas
  • A Transformer block is two residual sub-layers: attention (tokens exchange information) and an MLP (each token is transformed). Each is wrapped in normalisation.
  • Positional information must be added, because attention is permutation-equivariant. Sinusoidal encodings make a shift by \(k\) positions a fixed linear map.
  • The residual connection \(\mathbf{x}+F(\mathbf{x})\) gives gradients an identity path: they do not vanish with depth.
  • A block has about \(12d^2\) parameters. A model has about \(12Ld^2\) plus embeddings.
  • A two-layer Transformer can learn to copy a sequence: a task that requires attention.

31.1 The system problem

Attention (Chapter 30) is one operation. It has no position, no non-linearity, no depth. We need an architecture that can be stacked dozens of times, trained with gradient descent, and that reads and writes information in a sequence.

How are attention, a feed-forward network, normalisation, and residual paths arranged into a trainable sequence model?

The model is a stack of such blocks between an embedding and an output head:

\[ \text{tokens}\to\mathbf{E}[\cdot]+\mathbf{P}\to\underbrace{\text{Block}\to\dots\to\text{Block}}_{L}\to\text{LayerNorm}\to\mathbf{W}_{\text{out}}\to\text{logits}. \tag{31.1}\]

31.3 Embeddings and positions

Token ids become vectors by lookup in an embedding matrix \(\mathbf{E}\in\mathbb{R}^{V\times d}\) (Chapters 3, 5). Attention cannot distinguish positions: shuffling tokens shuffles outputs (Chapter 30). Positional information is therefore added to each token vector.

Two common choices:

  • Learned: a table \(\mathbf{P}\in\mathbb{R}^{T_{\max}\times d}\) of parameters.
  • Sinusoidal (the original Transformer): a fixed function of position,

\[ \text{PE}(p,2i)=\sin\!\bigl(p\,\omega_{i}\bigr),\quad \text{PE}(p,2i+1)=\cos\!\bigl(p\,\omega_{i}\bigr),\qquad \omega_i=10000^{-2i/d}. \tag{31.2}\]

TipDerivation: a shift is a linear map

For one frequency \(\omega\), the pair \((\sin\omega p,\cos\omega p)\) is a point on a circle. By the angle-addition formulas, \[ \begin{pmatrix}\sin\omega(p+k)\\\cos\omega(p+k)\end{pmatrix}= \begin{pmatrix}\cos\omega k&\sin\omega k\\-\sin\omega k&\cos\omega k\end{pmatrix} \begin{pmatrix}\sin\omega p\\\cos\omega p\end{pmatrix}. \] The matrix is a rotation (Chapter 5) that depends only on the offset \(k\), not on \(p\). The full encoding is a stack of such pairs, so \(\text{PE}(p+k)=\mathbf{M}_k\,\text{PE}(p)\) for a fixed block-diagonal \(\mathbf{M}_k\). A model can therefore learn relations such as “the token \(k\) steps before”. \(\blacksquare\)

def sinusoidal(T, d):
    p = np.arange(T)[:, None]; i = np.arange(d // 2)[None, :]
    ang = p * 10000.0 ** (-2 * i / d)
    PE = np.zeros((T, d)); PE[:, 0::2] = np.sin(ang); PE[:, 1::2] = np.cos(ang)
    return PE

31.4 The sub-layers

Attention sub-layer (Chapter 30): \(\text{MHA}(\text{LN}(\mathbf{x}))\).

MLP sub-layer (Chapter 11): applied to each token independently with the same weights:

\[ \text{MLP}(\mathbf{x})=\mathbf{W}_2\,\text{GELU}(\mathbf{W}_{1}\mathbf{x}+\mathbf{b}_1)+\mathbf{b}_2,\qquad\mathbf{W}_{1}\in\mathbb{R}^{4d\times d},\ \mathbf{W}_{2}\in\mathbb{R}^{d\times4d}. \tag{31.3}\]

Attention mixes across positions. The MLP transforms each position. The two alternate.

Pre-norm block (the modern default):

\[ \mathbf{x}'=\mathbf{x}+\text{MHA}(\text{LN}(\mathbf{x})),\qquad \mathbf{x}''=\mathbf{x}'+\text{MLP}(\text{LN}(\mathbf{x}')). \tag{31.4}\]

The original post-norm block applied \(\text{LN}\) after the addition: \(\text{LN}(\mathbf{x}+\text{MHA}(\mathbf{x}))\).

31.4.1 Why residual connections

TipDerivation: an identity path for the gradient

For \(\mathbf{y}=\mathbf{x}+F(\mathbf{x})\), the Jacobian is \(\partial\mathbf{y}/\partial\mathbf{x}=\mathbf{I}+\partial F/\partial\mathbf{x}\) (Chapter 17). Through \(L\) blocks, the backward signal (Chapter 18) is multiplied by \[ \prod_{l=1}^{L}\bigl(\mathbf{I}+\mathbf{J}_{l}\bigr)=\mathbf{I}+\sum_{l}\mathbf{J}_l+\sum_{l<m}\mathbf{J}_{m}\mathbf{J}_l+\cdots. \] There is a term \(\mathbf{I}\): the gradient of the loss with respect to an early layer always contains a direct, unattenuated path from the output. Without the skip, the factor is \(\prod_{l}\mathbf{J}_l\) and shrinks or grows exponentially. \(\blacksquare\)

import torch, torch.nn as nn
torch.manual_seed(0)
L_, dd = 24, 64
Ws = [torch.randn(dd, dd) / math.sqrt(dd) * 0.7 for _ in range(L_)]
def grad_norms(skip):
    x = torch.randn(32, dd, requires_grad=True); h = x; hs = []
    for W in Ws:
        h = h + torch.tanh(h @ W) if skip else torch.tanh(h @ W)
        h.retain_grad(); hs.append(h)
    (h ** 2).mean().backward()
    return [t.grad.norm().item() for t in hs]
g_skip, g_plain = grad_norms(True), grad_norms(False)

31.5 Counting parameters

With width \(d\), an attention sub-layer has \(4d^2\) weights (Chapter 30). The MLP has \(d\cdot4d+4d\cdot d=8d^2\). So one block has about \(12d^2\) parameters. Adding biases and LayerNorm scales gives exactly \(12d^2+13d\).

\[ N_{\text{params}}\approx\underbrace{12\,L\,d^2}_{\text{blocks}}+\underbrace{V\,d}_{\text{embedding}}\;(+\,V\,d\text{ if the output head is not tied}). \tag{31.5}\]

For \(d=4096\), \(L=32\): \(12\cdot32\cdot4096^{2}\approx6.4\times10^9\) parameters in the blocks.

31.6 A complete model in PyTorch

We write the whole Transformer as three small classes: about 40 lines. It uses causal self-attention (a decoder). The pre flag selects pre- or post-norm.

class Block(nn.Module):
    def __init__(self, d, h, pre=True):
        super().__init__()
        self.h, self.pre = h, pre
        self.ln1, self.ln2 = nn.LayerNorm(d), nn.LayerNorm(d)
        self.qkv, self.o = nn.Linear(d, 3 * d), nn.Linear(d, d)
        self.mlp = nn.Sequential(nn.Linear(d, 4 * d), nn.GELU(), nn.Linear(4 * d, d))

    def attn(self, x):
        B, T, d = x.shape
        q, k, v = self.qkv(x).chunk(3, dim=-1)
        split = lambda t: t.view(B, T, self.h, d // self.h).transpose(1, 2)   # (B, h, T, dh)
        q, k, v = split(q), split(k), split(v)
        S = q @ k.transpose(-1, -2) / math.sqrt(d // self.h)
        S = S.masked_fill(~torch.tril(torch.ones(T, T, dtype=torch.bool)), float("-inf"))
        A = S.softmax(-1)
        out = (A @ v).transpose(1, 2).reshape(B, T, d)
        return self.o(out), A

    def forward(self, x):
        if self.pre:
            a, A = self.attn(self.ln1(x)); x = x + a
            x = x + self.mlp(self.ln2(x))
        else:
            a, A = self.attn(x); x = self.ln1(x + a)
            x = self.ln2(x + self.mlp(x))
        return x, A

class TinyLM(nn.Module):
    def __init__(self, V, T, d=64, h=4, L=2, pre=True, use_pos=True):
        super().__init__()
        self.E, self.P, self.use_pos = nn.Embedding(V, d), nn.Embedding(T, d), use_pos
        self.blocks = nn.ModuleList([Block(d, h, pre) for _ in range(L)])
        self.ln, self.head = nn.LayerNorm(d), nn.Linear(d, V, bias=False)

    def forward(self, idx):
        x = self.E(idx)
        if self.use_pos:
            x = x + self.P(torch.arange(idx.shape[1]))
        attn = []
        for b in self.blocks:
            x, A = b(x); attn.append(A)
        return self.head(self.ln(x)), attn

V_, T_, d_, h_, L2 = 16, 12, 64, 4, 2
model = TinyLM(V_, T_, d_, h_, L2)
n_actual = sum(p.numel() for p in model.parameters())

31.6.1 Pre-norm versus post-norm

The block order changes how well deep models train. We train the copy task (defined in the next section) with 2 and 8 blocks, at two learning rates, without warmup, for both orders. One seed each.

Vc, halfc = 16, 6
def copy_batch(B):
    a = torch.randint(0, Vc - 1, (B, halfc)); sep = torch.full((B, 1), Vc - 1)
    return torch.cat([a, sep, a], dim=1)

def train_copy(pre, L, lr, steps=600, seed=0):
    torch.manual_seed(seed)
    m = TinyLM(Vc, 12, d=64, h=4, L=L, pre=pre)
    opt = torch.optim.AdamW(m.parameters(), lr=lr); hist = []
    for _ in range(steps):
        x = copy_batch(128)
        logits, _ = m(x[:, :-1])
        loss = nn.functional.cross_entropy(logits.reshape(-1, Vc), x[:, 1:].reshape(-1))
        opt.zero_grad(); loss.backward(); opt.step(); hist.append(loss.item())
    return np.array(hist)

curves = {}
print(f"{'order':10s} {'blocks':>6s} {'lr':>7s} {'final loss':>11s}")
for pre in (True, False):
    for L in (2, 8):
        for lr in (3e-3, 1e-2):
            h = train_copy(pre, L, lr)
            curves[(pre, L, lr)] = h
            print(f"{'pre-norm' if pre else 'post-norm':10s} {L:6d} {lr:7.3f} {h[-30:].mean():11.3f}")

The original Transformer used post-norm and needed a long learning-rate warmup. With pre-norm, the residual stream is never normalised in place, so the identity path of the residual connection stays intact (see the derivation above). This is why pre-norm became the default.

31.7 Training: learning to copy

We train a small Transformer on a synthetic task that requires attention. Each sequence is six random symbols, a separator, then the same six symbols again. The model reads left to right and predicts the next token. The first half is unpredictable (random). The second half is a copy of the first, and can only be predicted by looking back six positions: at the position of the separator, the next token equals the token at position 0.

V, half = 16, 6                      # symbols 0..14, separator 15
def make_batch(B):
    a = torch.randint(0, V - 1, (B, half))
    sep = torch.full((B, 1), V - 1)
    return torch.cat([a, sep, a], dim=1)                      # length 13

torch.manual_seed(0)
lm = TinyLM(V, 12, d=64, h=4, L=2)
opt = torch.optim.AdamW(lm.parameters(), lr=3e-3)
losses = []
t0 = time.time()
for step in range(1500):
    x = make_batch(128); inp, tgt = x[:, :-1], x[:, 1:]
    logits, _ = lm(inp)
    loss = nn.functional.cross_entropy(logits.reshape(-1, V), tgt.reshape(-1))
    opt.zero_grad(); loss.backward(); opt.step(); losses.append(loss.item())

x = make_batch(2000); inp, tgt = x[:, :-1], x[:, 1:]
with torch.no_grad():
    pred = lm(inp)[0].argmax(-1)
acc_first = (pred[:, :half] == tgt[:, :half]).float().mean().item()
acc_copy = (pred[:, half:] == tgt[:, half:]).float().mean().item()
floor = (half - 1) * math.log(V - 1) / (2 * half)            # loss if only the copy part is learned
print(f"trained in {time.time() - t0:.0f} s; final loss {np.mean(losses[-50:]):.3f}  "
      f"(floor if the copy half is perfect: {floor:.3f})")
print(f"accuracy on the random first half: {acc_first:.3f};  on the copied second half: {acc_copy:.3f}")
trained in 15 s; final loss 1.130  (floor if the copy half is perfect: 1.128)
accuracy on the random first half: 0.224;  on the copied second half: 1.000

The loss reaches its theoretical floor: the copy half is predicted perfectly, and the random half costs \(\ln15\) per token, which cannot be reduced. The model learned an algorithm.

31.10 Failure modes

No positional information. A model without positions is blind to order. We confirm this below.

torch.manual_seed(1)
one_layer = TinyLM(V, 12, d=64, h=4, L=1, use_pos=False).eval()   # no positional information
idx = torch.randint(0, V, (1, 8)); perm = torch.randperm(7)
shuffled_prefix = torch.cat([idx[:, :7][:, perm], idx[:, 7:]], dim=1)   # same tokens, other order
with torch.no_grad():
    first = one_layer(idx)[0][0, -1]
    second = one_layer(shuffled_prefix)[0][0, -1]
print("last-token logits identical when only the order of earlier tokens changes:",
      torch.allclose(first, second, atol=1e-5))
last-token logits identical when only the order of earlier tokens changes: True

Post-norm fragility. Deep post-norm models are hard to train without warmup (Figure 31.5).

Wrong mask in training. If the model can see the future during training, the loss falls to zero and the model is useless at generation. Always verify that the upper triangle of the attention is zero.

Context-length limits. The positional table has a fixed size. Sinusoidal encodings extrapolate in form but not necessarily in behaviour (Chapter 32).

Cost. Attention is \(O(T^2d)\) and the MLP is \(O(Td^2)\). For small \(d\) and long \(T\), attention dominates. For large \(d\) and short \(T\), the MLP dominates, and it holds two thirds of the parameters.

31.12 System connection

NoteWhat the system gained in this chapter

System C is now complete as a trainable model: tokens \(\to\) embeddings \(\to\) attention \(\to\) contextual representations \(\to\) prediction. We trained one from scratch, saw it find the copy algorithm, and read the algorithm out of its attention map.

Modern language models change several details of this block: how positions are encoded, which normalisation, which MLP. Chapter 32 reconstructs the decoder-only model used by GPT and Llama.

Chapter summary

  • A block: \(\mathbf{x}'=\mathbf{x}+\text{MHA}(\text{LN}\mathbf{x})\); \(\mathbf{x}''=\mathbf{x}'+\text{MLP}(\text{LN}\mathbf{x}')\).
  • Attention mixes across positions. The MLP transforms each position.
  • Positions are added. Sinusoidal encodings make a shift a rotation.
  • Residuals give the gradient an identity path.
  • A block has \(12d^2+13d\) parameters. A model has about \(12Ld^2+Vd\).
  • A two-block Transformer learns copying through attention heads with a fixed offset of six positions.
