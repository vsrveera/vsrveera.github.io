37  Detection and Structured Prediction

NoteKey ideas
  • Detection outputs a set of objects, each with a class and a box. The number of objects is not fixed.
  • IoU (intersection over union) measures box overlap. It is zero, with no gradient, for boxes that do not overlap. GIoU repairs that.
  • Non-maximum suppression removes duplicate boxes. Set prediction (DETR) avoids duplicates by design.
  • Bipartite matching assigns each prediction to at most one target. The Hungarian algorithm finds the best assignment in \(O(n^3)\).
  • The set loss is computed after matching: classification and box losses for matched pairs, and a “no object” loss for the rest.

37.1 The system problem

Classification outputs one label for an image. A street scene contains many objects. The model must output a list: for each object, a class and a rectangle. The list has no natural order, and a variable length. Comparing a predicted list with a true list is not obvious.

How does a model output a set of objects with locations, and how is a predicted set compared with a target set?

37.2 Boxes and overlap

An axis-aligned box is stored as corners \((x_1,y_1,x_2,y_2)\) or as centre and size \((c_x,c_y,w,h)\). The two are related by \(x_1=c_x-w/2\), \(x_2=c_x+w/2\), and similarly for \(y\). Coordinates are usually divided by the image size, so that they lie in \([0,1]\).

The intersection of two boxes is a box (or empty). Its width is the overlap of the two \(x\)-intervals, clipped at zero:

\[ w_\cap=\max\bigl(0,\ \min(x_2,x_2')-\max(x_1,x_1')\bigr),\qquad A_\cap=w_\cap\,h_\cap. \tag{37.1}\]

The intersection over union is

\[ \text{IoU}(A,B)=\frac{A_\cap}{A_A+A_B-A_\cap}\in[0,1]. \tag{37.2}\]

It is 1 for identical boxes and 0 for disjoint ones. \(1-\text{IoU}\) is a metric (Chapter 13): it is the Jaccard distance of the two regions.

def box_area(b):
    return np.clip(b[..., 2] - b[..., 0], 0, None) * np.clip(b[..., 3] - b[..., 1], 0, None)

def iou_giou(a, b):
    """a: (..., 4), b: (..., 4) in x1,y1,x2,y2 -> IoU and GIoU (elementwise)."""
    lt = np.maximum(a[..., :2], b[..., :2]); rb = np.minimum(a[..., 2:], b[..., 2:])
    inter = np.prod(np.clip(rb - lt, 0, None), axis=-1)
    union = box_area(a) + box_area(b) - inter
    iou = inter / np.maximum(union, 1e-12)
    clt = np.minimum(a[..., :2], b[..., :2]); crb = np.maximum(a[..., 2:], b[..., 2:])
    enclose = np.prod(crb - clt, axis=-1)                       # smallest enclosing box
    giou = iou - (enclose - union) / np.maximum(enclose, 1e-12)
    return iou, giou

37.2.1 Why IoU is a poor loss, and GIoU

If two boxes do not overlap, \(\text{IoU}=0\) whatever the distance between them. The loss \(1-\text{IoU}\) is then flat and gives no gradient to move the prediction towards the target (Chapters 14, 18).

The generalised IoU subtracts the fraction of the smallest enclosing box \(C\) that is not covered by the union:

\[ \text{GIoU}(A,B)=\text{IoU}(A,B)-\frac{|C|-|A\cup B|}{|C|}\in(-1,1]. \tag{37.3}\]

For far-apart boxes the enclosing box is large and mostly empty, so GIoU is close to \(-1\), and it rises smoothly as the boxes approach.

37.3 Duplicates and non-maximum suppression

Classic detectors predict a box at thousands of positions. Several boxes land on the same object. Non-maximum suppression (NMS) keeps the highest-scoring box and removes any other whose IoU with it exceeds a threshold, then repeats.

def nms(boxes, scores, thr=0.5):
    order = np.argsort(-scores); keep = []
    while len(order):
        i = order[0]; keep.append(int(i))
        if len(order) == 1:
            break
        ious, _ = iou_giou(np.broadcast_to(boxes[i], (len(order) - 1, 4)), boxes[order[1:]])
        order = order[1:][ious <= thr]
    return keep

boxes = np.array([[10, 10, 50, 50], [12, 12, 52, 52], [8, 14, 48, 54],       # three boxes on object 1
                  [100, 20, 140, 70], [102, 22, 138, 68]], float)             # two on object 2
scores = np.array([0.9, 0.8, 0.6, 0.95, 0.7])
print("kept boxes:", nms(boxes, scores, 0.5), "  (one per object)")
print("threshold 0.95 keeps:", nms(boxes, scores, 0.95), "  (too lax: duplicates survive)")
kept boxes: [3, 0]   (one per object)
threshold 0.95 keeps: [3, 0, 1, 4, 2]   (too lax: duplicates survive)

NMS is a hand-made post-processing step with a threshold that must be tuned. It fails for crowded scenes, where real objects overlap.

37.4 Set prediction and matching

An alternative (DETR) predicts a fixed number \(N\) of boxes (one per learned query), each with a class, including a special “no object” class, and compares the set with the target set directly. Duplicates are discouraged by the loss, so no NMS is needed.

The comparison needs a correspondence: which prediction answers which target? The loss is computed after finding the best one-to-one assignment \(\hat\sigma\) between predictions and targets:

\[ \hat\sigma=\arg\min_{\sigma}\sum_{i}\mathcal{C}\bigl(i,\sigma(i)\bigr), \tag{37.4}\]

with a cost matrix \(\mathcal{C}_{ij}\) combining, for prediction \(j\) and target \(i\): the negative probability of the correct class, an L1 box distance, and \(1-\text{GIoU}\).

37.4.1 The Hungarian algorithm

Enumerating all assignments costs \(n!\). The Hungarian algorithm solves the assignment problem exactly in \(O(n^3)\). We check it against brute force for \(n=6\) (720 assignments).

from scipy.optimize import linear_sum_assignment
rng = np.random.default_rng(0)
Cm = rng.random((6, 6))

best_b = min(sum(Cm[i, p[i]] for i in range(6)) for p in itertools.permutations(range(6)))
print(f"Hungarian optimum {best_h:.6f};  brute force over {math.factorial(6)} permutations {best_b:.6f}")

37.5 The set loss

After matching, the loss has three parts: classification of each query (matched queries must predict the object class; unmatched ones must predict “no object”), and box regression on matched pairs only:

\[ \mathcal{L}=\sum_{j=1}^{N}\Bigl[-\ln p_j(c_{\hat\sigma^{-1}(j)})\Bigr]+\sum_{i\in\text{targets}}\Bigl[\lambda_{1}\lVert b_i-\hat b_{\hat\sigma(i)}\rVert_1+\lambda_{2}\bigl(1-\text{GIoU}(b_i,\hat b_{\hat\sigma(i)})\bigr)\Bigr]. \tag{37.5}\]

The matching is a discrete step with no gradient. It selects which pairs the (differentiable) losses apply to. The class term is weighted down for “no object”, since most queries are unmatched.

37.6 A small detector

We build the smallest set-prediction detector. The data: \(24\times24\) images containing one to three bright rectangles. The model: a small CNN to a feature vector, then one linear head that outputs, for each of \(N=4\) queries, two class logits (object / no object) and a box (four numbers in \([0,1]\), passed through a sigmoid). The loss is Equation 37.5, with matching by the Hungarian algorithm for every image.

import torch, torch.nn as nn, torch.nn.functional as F
S, NQ = 24, 4
rng = np.random.default_rng(0)

def make_images(B):
    imgs = np.zeros((B, 1, S, S), np.float32); gts = []
    for b in range(B):
        boxes = []
        for _ in range(rng.integers(1, 4)):
            w, h = rng.integers(4, 9, 2); x, y = rng.integers(0, S - w), rng.integers(0, S - h)
            imgs[b, 0, y:y + h, x:x + w] = 1.0
            boxes.append([x / S, y / S, (x + w) / S, (y + h) / S])
        gts.append(np.array(boxes, np.float32))
    return torch.tensor(imgs), gts

def giou_t(a, b):                                   # torch version, (n,4) x (m,4) -> (n,m)
    lt = torch.max(a[:, None, :2], b[None, :, :2]); rb = torch.min(a[:, None, 2:], b[None, :, 2:])
    inter = (rb - lt).clamp(min=0).prod(-1)
    aa = ((a[:, 2] - a[:, 0]) * (a[:, 3] - a[:, 1]))[:, None]; bb = ((b[:, 2] - b[:, 0]) * (b[:, 3] - b[:, 1]))[None]
    union = aa + bb - inter
    clt = torch.min(a[:, None, :2], b[None, :, :2]); crb = torch.max(a[:, None, 2:], b[None, :, 2:])
    enc = (crb - clt).prod(-1)
    return inter / (union + 1e-9) - (enc - union) / (enc + 1e-9)

class Detector(nn.Module):
    def __init__(self):
        super().__init__()
        self.f = nn.Sequential(nn.Conv2d(1, 16, 3, padding=1), nn.ReLU(), nn.MaxPool2d(2),
                               nn.Conv2d(16, 32, 3, padding=1), nn.ReLU(), nn.MaxPool2d(2),
                               nn.Flatten(), nn.Linear(32 * 6 * 6, 256), nn.ReLU())
        self.cls, self.box = nn.Linear(256, NQ * 2), nn.Linear(256, NQ * 4)
    def forward(self, x):
        h = self.f(x)
        return self.cls(h).view(len(x), NQ, 2), self.box(h).view(len(x), NQ, 4).sigmoid()

def set_loss(logits, boxes, gts):
    total = 0.0
    for b, g in enumerate(gts):
        g = torch.tensor(g); p = boxes[b]; logp = logits[b].log_softmax(-1)
        cost = -logp[:, 1][:, None] + 5 * torch.cdist(p, g, p=1) + 2 * (1 - giou_t(p, g))
        r, c = linear_sum_assignment(cost.detach().numpy())          # Hungarian matching
        tgt = torch.zeros(NQ, dtype=torch.long); tgt[r] = 1          # matched queries are "object"
        l_cls = F.cross_entropy(logits[b], tgt, weight=torch.tensor([0.5, 1.0]))
        l_box = (5 * (p[r] - g[c]).abs().sum(-1) + 2 * (1 - giou_t(p[r], g[c]).diagonal())).mean()
        total = total + l_cls + l_box
    return total / len(gts)

torch.manual_seed(0)
det = Detector(); opt = torch.optim.Adam(det.parameters(), lr=2e-3)
hist, t0 = [], time.time()
for step in range(1500):
    x, g = make_images(32)
    lg, bx = det(x)
    loss = set_loss(lg, bx, g)
    opt.zero_grad(); loss.backward(); opt.step(); hist.append(loss.item())
print(f"trained in {time.time() - t0:.0f} s;  loss {hist[0]:.2f} -> {np.mean(hist[-20:]):.2f}")

37.7 From first principles to production

Real detectors differ in scale, not in principle. DETR replaces our CNN feature vector with a CNN or ViT backbone producing a grid of feature tokens (Chapter 36). A Transformer decoder takes \(N\) learned query vectors and uses cross-attention over the image tokens (Chapter 30) to produce one output vector per query. A small feed-forward head turns each into a class and a box. The loss is Equation 37.5. Libraries provide box_iou, generalized_box_iou, and nms operators, and the Hungarian solver is the one used here.

37.9 Failure modes

IoU has no gradient for disjoint boxes. It is a poor training loss for boxes far apart. Use GIoU, or L1 on coordinates, or a combination.

Duplicates and thresholds. NMS thresholds trade missed objects in crowds against duplicate detections.

Class imbalance. Most queries (or anchors) match nothing. Without a lower weight on “no object”, the model predicts “no object” everywhere.

Unstable matching early in training. At the start, predictions are random and the assignment changes from step to step. Training is slow to start and needs patience.

Small objects. A box of few pixels has noisy IoU: one pixel of error changes IoU a lot. Evaluation therefore reports average precision at several IoU thresholds.

Fixed number of queries. If there are more objects than queries, some cannot be detected.

Evaluation is not the loss. Detection is scored by mean average precision, which depends on ranking by confidence and on IoU thresholds. It is not differentiable. The loss is a surrogate.

37.11 System connection

NoteWhat the system gained in this chapter

The system can now output structured, variable-size predictions and be trained on them. The new ingredients are a geometric overlap measure (IoU and GIoU), a differentiable surrogate for it, and an optimal matching step that turns “compare two unordered sets” into a well-defined loss.

So far, every model was trained with labels. Labels are expensive. Chapter 38 shows how models learn useful representations without them.

Chapter summary

  • A detection is a class and a box. A detector outputs a set of them.
  • \(\text{IoU}=A_\cap/(A_A+A_B-A_\cap)\). It is flat at 0 for disjoint boxes. GIoU subtracts the uncovered share of the enclosing box and remains informative.
  • NMS removes duplicates by IoU thresholding. Set prediction avoids duplicates through one-to-one matching.
  • The Hungarian algorithm finds the optimal assignment in \(O(n^3)\).
  • The set loss is computed after matching: classification for all queries, box losses for matched ones.
