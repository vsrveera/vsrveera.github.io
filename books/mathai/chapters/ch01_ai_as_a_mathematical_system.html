1  AI as a Mathematical System

NoteKey ideas
  • A model is a function with adjustable numbers called parameters.
  • Data is fixed. Parameters change.
  • A loss is one number that tells how wrong the model is.
  • Learning is the repeated change of parameters to reduce the loss.
  • Six mathematical systems make this work: representation, transformation, measurement, learning, uncertainty, and generalization.

1.1 The system problem

An email program sorts mail into two groups: spam and not spam. Nobody wrote a rule for every spam message. The program learned from examples.

This raises a question. What does it mean for a machine to learn?

This book gives a precise answer. A machine learns when a mathematical procedure changes its numbers so that its errors become smaller. Every part of that sentence is mathematics:

  • “its numbers” are parameters.
  • “its errors” are measured by a loss.
  • “changes” follows a rule from calculus.
  • “become smaller” must hold for new examples, not only old ones. This needs probability and statistics.

Figure 1.1 shows the idea at the highest level.

1.2 A model is a function

A function takes an input and gives one output. The function \(f(x) = 2x + 1\) takes \(x = 3\) and gives \(7\).

A model is a function that has extra numbers inside it. These numbers are the parameters. We write all of them together as \(\theta\) (the Greek letter theta).

\[ \hat{y} = f_\theta(x) \tag{1.1}\]

Read Equation 1.1 as: “The prediction \(\hat{y}\) is the output of the function \(f\), with parameters \(\theta\), for the input \(x\).”

The simplest useful model is a straight line:

\[ f_\theta(x) = a\,x + b, \qquad \theta = (a, b) \tag{1.2}\]

The number \(a\) is the slope. The number \(b\) is the offset. Different values of \(\theta\) give different functions. A model is therefore not one function. It is a family of functions. Learning is the search for one good member of the family.

def f(x, theta):
    a, b = theta
    return a * x + b

xs = np.linspace(-2, 2, 50)
fig, ax = plt.subplots()
for theta in [(0.5, 0.0), (1.0, -1.0), (2.0, 1.0), (-1.0, 0.5), (0.0, 2.0)]:
    ax.plot(xs, f(xs, theta), label=f"a={theta[0]}, b={theta[1]}")
ax.set_xlabel("x"); ax.set_ylabel("f(x)"); ax.legend(fontsize=8)

1.3 Data and parameters

An AI system uses two kinds of numbers. They have different roles.

Data Parameters
Symbol \(x\), \(y\) \(\theta\)
Who sets it The world The learning procedure
Changes during learning? No Yes
Changes at inference? Yes (new inputs) No
Example (spam filter) Words in the email, spam label Word weights
Typical count Millions to billions Tens to hundreds of billions (large models)

A dataset is a set of \(N\) examples. Each example is an input and a target:

\[ \mathcal{D} = \{(x_1, y_1), (x_2, y_2), \dots, (x_N, y_N)\} \tag{1.3}\]

We now create a small dataset. The true rule is \(y = 2x + 1\). We add noise, because real measurements are never exact. The learning procedure does not know the true rule. It sees only the points.

rng = np.random.default_rng(0)
N = 30
x = rng.uniform(-2, 2, size=N)                  # (N,)
y = 2.0 * x + 1.0 + rng.normal(0, 0.5, size=N)  # (N,)

1.4 Measuring error

How wrong is a model? We need one number. This number is the loss.

For one example, the error is the difference between the prediction and the target: \(\hat{y}_i - y_i\). A negative error and a positive error must not cancel. We square the error. This gives the squared error:

\[ \ell(y_i, \hat{y}_i) = (\hat{y}_i - y_i)^2 \tag{1.4}\]

The mean squared error (MSE) is the average over the dataset:

\[ L(\theta) = \frac{1}{N} \sum_{i=1}^{N} \bigl( f_\theta(x_i) - y_i \bigr)^2 \tag{1.5}\]

The loss \(L\) depends on \(\theta\) because the data is fixed. This is the key point. The loss is a function of the parameters. A better parameter set gives a smaller number.

def mse(theta, x, y):
    y_hat = f(x, theta)               # (N,)
    return np.mean((y_hat - y) ** 2)  # scalar

for theta in [(0.0, 0.0), (1.0, 1.0), (2.0, 1.0)]:
    print(f"theta = {theta}  ->  loss = {mse(theta, x, y):.3f}")
theta = (0.0, 0.0)  ->  loss = 8.620
theta = (1.0, 1.0)  ->  loss = 1.892
theta = (2.0, 1.0)  ->  loss = 0.238

The third choice, \((2, 1)\), is the true rule. Its loss is not zero. It equals the noise level. No line can remove noise.

We now fix \(b = 1\) and change only \(a\). Figure 1.4 shows the loss as a height over the \(a\) axis.

a_grid = np.linspace(-2, 6, 200)
losses = [mse((a, 1.0), x, y) for a in a_grid]
a_best = a_grid[int(np.argmin(losses))]

fig, ax = plt.subplots()
ax.plot(a_grid, losses, color=PALETTE["loss"])

ax.set_title(f"minimum near a = {a_best:.2f}")

1.5 Changing the model

We have a loss curve. We need a rule that moves \(a\) toward the minimum.

The derivative \(dL/da\) is the slope of the loss curve at the current \(a\). If the slope is positive, the loss rises when \(a\) rises. So we must decrease \(a\). If the slope is negative, we must increase \(a\). In both cases, we move against the derivative.

\[ a' = a - \eta \, \frac{dL}{da} \tag{1.6}\]

The number \(\eta\) (eta) is the learning rate. It is a small positive number. It controls the step size.

For a model with many parameters, the vector of all derivatives is the gradient \(\nabla_\theta L\). The update becomes:

\[ \theta' = \theta - \eta \, \nabla_\theta L \tag{1.7}\]

TipDerivation: why does the update reduce the loss?

Take one parameter. For a small step \(\Delta\), the first-order approximation is

\[ L(a + \Delta) \approx L(a) + \Delta \, \frac{dL}{da}. \]

Put \(\Delta = -\eta \, dL/da\). Then

\[ L(a') \approx L(a) - \eta \left( \frac{dL}{da} \right)^2. \]

The square is never negative. Therefore \(L(a') \le L(a)\) for a small enough \(\eta\). For many parameters, the same steps give \(L(\theta') \approx L(\theta) - \eta \,\lVert \nabla L \rVert^2\).

The word “small” matters. The approximation is valid only near \(a\). A large \(\eta\) breaks it. We show this later in Section 51.9.

For our model, the derivatives follow from the chain rule (Chapter 18). We state them here:

\[ \frac{\partial L}{\partial a} = \frac{2}{N} \sum_i (\hat{y}_i - y_i)\, x_i, \qquad \frac{\partial L}{\partial b} = \frac{2}{N} \sum_i (\hat{y}_i - y_i) \tag{1.8}\]

WarningAlways verify a gradient

A wrong gradient does not raise an error. The program runs, and the model silently learns badly. We therefore compare the formula with a finite difference: \(\frac{L(\theta + \epsilon) - L(\theta - \epsilon)}{2\epsilon}\).

def grad(theta, x, y):
    err = f(x, theta) - y                         # (N,)
    return np.array([2 * np.mean(err * x),        # dL/da
                     2 * np.mean(err)])           # dL/db

def numeric_grad(theta, x, y, eps=1e-5):
    g = np.zeros(2)
    for k in range(2):
        up, dn = list(theta), list(theta)
        up[k] += eps; dn[k] -= eps
        g[k] = (mse(up, x, y) - mse(dn, x, y)) / (2 * eps)
    return g

theta0 = (0.3, -0.7)
diff = np.max(np.abs(grad(theta0, x, y) - numeric_grad(theta0, x, y)))
print(f"largest difference: {diff:.2e}")
assert diff < 1e-6
largest difference: 1.67e-10

The two results agree. The formula is correct.

1.6 The complete loop

We now have all parts. The learning loop has four steps. We repeat them.

  1. Predict: compute \(\hat{y}_i = f_\theta(x_i)\).
  2. Measure: compute the loss \(L(\theta)\).
  3. Differentiate: compute the gradient \(\nabla_\theta L\).
  4. Update: set \(\theta \leftarrow \theta - \eta \nabla_\theta L\).

First, we write the loop in plain Python. We use no libraries. Every operation is visible.

def train_plain(xs, ys, eta=0.1, steps=50):
    a, b = 0.0, 0.0
    n = len(xs)
    history = []
    for _ in range(steps):
        # predict and measure
        errs = [(a * xi + b) - yi for xi, yi in zip(xs, ys)]
        loss = sum(e * e for e in errs) / n
        history.append(loss)
        # differentiate
        da = 2 * sum(e * xi for e, xi in zip(errs, xs)) / n
        db = 2 * sum(errs) / n
        # update
        a, b = a - eta * da, b - eta * db
    return (a, b), history

theta_plain, hist_plain = train_plain(list(x), list(y))
print(f"learned a = {theta_plain[0]:.3f}, b = {theta_plain[1]:.3f}")
print(f"loss: {hist_plain[0]:.3f} -> {hist_plain[-1]:.3f}")
learned a = 1.997, b = 1.138
loss: 8.620 -> 0.219

The learned values are close to the true values \(a = 2\), \(b = 1\). The procedure found the rule from the points alone.

Next, we write the same loop with NumPy. The loops over examples become array operations. The result is the same.

def train_numpy(x, y, eta=0.1, steps=50):
    theta = np.zeros(2)
    history = []
    for _ in range(steps):
        history.append(mse(theta, x, y))
        theta = theta - eta * grad(theta, x, y)   # update rule
    return theta, np.array(history)

theta_np, hist_np = train_numpy(x, y)
assert np.allclose(theta_np, theta_plain)
print("Plain Python and NumPy agree:", np.round(theta_np, 3))
Plain Python and NumPy agree: [1.997 1.138]

Figure 1.6 shows the result. The left panel shows the line before and after learning. The right panel shows the loss over the steps.

1.7 Training and inference

The same model is used in two different modes.

  • Training: the data has targets. The system changes \(\theta\).
  • Inference: the data has no target. The system keeps \(\theta\) fixed and computes \(\hat{y}\).

Most of the cost of an AI system is in training. Most of the use is in inference. Both use the same function \(f_\theta\).

1.8 The six mathematical systems

The small example used several kinds of mathematics. We now name them. Each one answers one question. Each one has its own part in this book.

The chain of operations for a neural network has one more element: a nonlinear function \(\sigma\) after the linear part. We introduce it in Chapter 10.

\[ x \;\to\; Wx + b \;\to\; \sigma \;\to\; \hat{y} \;\to\; L(y,\hat{y}) \;\to\; \nabla L \;\to\; \theta' \tag{1.9}\]

This chain is the backbone of the book. Every model in this book is a more detailed version of Equation 1.9.

1.9 What can go wrong

The loop works for our simple model. It can fail in several ways. Each failure points to a later chapter.

The learning rate \(\eta\) is wrong. If \(\eta\) is too small, learning is slow. If \(\eta\) is too large, each step overshoots and the loss grows.

fig, ax = plt.subplots()
runs = [(0.001, PALETTE["neutral"]), (0.1, PALETTE["grad"]),
        (1.1, PALETTE["loss"])]
for eta, color in runs:
    _, h = train_numpy(x, y, eta=eta, steps=30)
    ax.plot(h, color=color, label=f"η = {eta}")
ax.set_yscale("log")
ax.set_xlabel("step"); ax.set_ylabel("loss L (log scale)")
ax.legend()
plt.show()

We study this in Chapters 19 and 20.

The loss does not describe the goal. A model minimizes the number we give it. If the number is a poor description of what we want, the model satisfies the number and not the goal. This is why loss design is a full chapter (Chapter 14).

The model memorizes. A model with many parameters can match the training points exactly and fail on new points. We cannot see this from the training loss. We study it in Part VII.

The numbers are not stable. Computers store numbers with finite precision. Some operations lose accuracy or overflow. We study this at the end of the relevant chapters.

1.10 Where this appears in modern AI

The loop in Section 1.6 is the same loop that trains the largest models. Only the model \(f_\theta\), the loss, and the scale are different.

System Input \(x\) Model \(f_\theta\) Loss \(L\) Scale of \(\theta\)
Our line a number \(ax+b\) MSE 2
Image classifier (System A) pixels convolutional network cross-entropy millions
Semantic search (System B) text text encoder → vector contrastive loss hundreds of millions
Language model (System C) tokens Transformer next-token cross-entropy billions to trillions
Image generator noisy image denoising network denoising error billions

The same four steps appear in all rows: predict, measure, differentiate, update. This is why the book can cover all of these systems with one set of mathematical tools.

1.11 System connection

NoteWhat the system gained in this chapter

We built a complete learning system in 30 lines. It has a model, a loss, a gradient, and an update rule. It is small, but it is not a toy in its structure. The rest of the book replaces each part with a stronger one:

  • the number \(x\) becomes vectors and tensors (Part II),
  • the line becomes a deep network (Part III),
  • MSE becomes a family of losses based on information and probability (Parts IV and VI),
  • the hand-written gradient becomes backpropagation (Part V),
  • “does it work on new data?” becomes a theory (Part VII).

In Chapter 2 we fix the language: scalars, vectors, matrices, tensors, and shapes.

Chapter summary

  • A model is a function \(f_\theta\). The parameters \(\theta\) select one function from a family.
  • Data is fixed. Parameters change.
  • The loss \(L(\theta)\) is one number that measures error.
  • The gradient \(\nabla_\theta L\) gives the direction of fastest increase. The update moves against it.
  • Learning is the loop: predict, measure, differentiate, update.
  • Training changes parameters. Inference only uses them.
  • Six mathematical systems support this loop. Each has a part in this book.
