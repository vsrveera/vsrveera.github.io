11  Neural Networks as Function Composition

NoteKey ideas
  • A multilayer perceptron (MLP) is a composition of affine layers and activations: \(f=f_{L}\circ\dots\circ f_1\).
  • The parameter count follows from the layer sizes: \(\sum_l(n_ln_{l-1}+n_l)\).
  • Early layers bend the input space. Later layers make the result easy to separate.
  • The output head and the loss must match the task.
  • In this chapter, PyTorch computes gradients as a black box. Chapter 18 opens the box.

11.1 The system problem

We have all parts: a linear layer (Chapter 9), a nonlinearity (Chapter 10), and the language of composition (Chapter 8). Now we assemble them.

How do layers compose into a model, and what does each layer represent?

This chapter also gives us the first complete System A: pixels in, class out, with parameters learned from data.

11.2 The mathematical object

An MLP with \(L\) layers computes

\[ \mathbf{a}_0=\mathbf{x},\qquad \mathbf{a}_l=\sigma(\mathbf{W}_{l}\mathbf{a}_{l-1}+\mathbf{b}_l)\ \ (l<L),\qquad \mathbf{z}_L=\mathbf{W}_{L}\mathbf{a}_{L-1}+\mathbf{b}_L. \tag{11.1}\]

In words, it is \(f=f_{L}\circ\dots\circ f_1\) with each \(f_l\) an affine map followed by \(\sigma\). The last layer has no \(\sigma\). It outputs scores (logits).

The vectors \(\mathbf{a}_1,\dots,\mathbf{a}_{L-1}\) are the hidden representations. Each layer changes the representation into a new one.

11.2.1 Shapes and parameters

For layer sizes \(n_0,n_1,\dots,n_L\), layer \(l\) has \(\mathbf{W}_{l}\in\mathbb{R}^{n_{l}\times n_{l-1}}\) and \(\mathbf{b}_{l}\in\mathbb{R}^{n_l}\):

\[ \#\text{parameters}=\sum_{l=1}^{L}\bigl(n_l\,n_{l-1}+n_{l}\bigr). \tag{11.2}\]

def n_params(sizes):
    return sum(n_out * n_in + n_out for n_in, n_out in zip(sizes[:-1], sizes[1:]))

for name, sizes in [("digits MLP", [64, 32, 10]),
                    ("MNIST MLP", [784, 256, 128, 10]),

11.3 A forward pass in NumPy

We write the forward pass for any depth. We keep the shape convention: a batch has shape (N, d), and a weight has shape (d_out, d_in).

rng = np.random.default_rng(0)

def init(sizes, rng):
    """He initialisation: weights ~ N(0, 2 / fan_in)."""
    return [(rng.normal(0, np.sqrt(2.0 / n_in), (n_out, n_in)), np.zeros(n_out))
            for n_in, n_out in zip(sizes[:-1], sizes[1:])]

def forward(params, X, trace=False):
    a = X                                          # (N, n_0)
    for l, (W, b) in enumerate(params):
        z = a @ W.T + b                            # (N, n_l)
        last = (l == len(params) - 1)
        a = z if last else np.maximum(0, z)        # ReLU on hidden layers
        if trace:
            print(f"layer {l + 1}: W {W.shape}  ->  output {a.shape}")
    return a

params = init([64, 32, 16, 10], rng)
out = forward(params, rng.normal(size=(5, 64)), trace=True)
layer 1: W (32, 64)  ->  output (5, 32)
layer 2: W (16, 32)  ->  output (5, 16)
layer 3: W (10, 16)  ->  output (5, 10)

The pattern is the same as in Chapter 2: the batch axis passes through unchanged, and only the feature axis changes.

11.4 Training: gradients as a black box

To train, we need \(\nabla_\theta L\). We have not yet derived how to compute it for a deep network. That is Chapter 18. For this chapter, PyTorch provides it:

  • loss.backward() computes \(\partial L/\partial\theta\) for every parameter.
  • optimizer.step() applies \(\theta\leftarrow\theta-\eta\,\nabla_\theta L\). This is the update of Chapter 1. Better optimisers are the subject of Chapter 19.
import torch
import torch.nn as nn

def fit(model, X, y, loss_fn, steps, lr):
    opt = torch.optim.SGD(model.parameters(), lr=lr)    # θ ← θ − η ∇L
    for _ in range(steps):
        opt.zero_grad()
        loss = loss_fn(model(X), y)
        loss.backward()                                  # Chapter 18 explains this
        opt.step()
    return loss.item()

11.5 Experiment 1: a spiral

We build a 2D problem that no hyperplane can solve: two interleaved spirals. We compare a linear model and MLPs of growing size.

def spiral(n=200, noise=0.2, seed=0):
    r = np.random.default_rng(seed)
    t = np.sqrt(r.uniform(0, 1, n)) * 3 * np.pi / 1.5 + 0.3
    X, y = [], []
    for c in (0, 1):
        th = t + c * np.pi
        pts = np.stack([t * np.cos(th), t * np.sin(th)], 1) / (3 * np.pi / 1.5)
        X.append(pts + r.normal(0, noise / 3, (n, 2))); y += [c] * n
    return np.vstack(X).astype(np.float32), np.array(y, dtype=np.float32)

Xs, ys = spiral()

11.6 Experiment 2: digits, the first complete System A

We now build the whole classifier for \(8\times8\) digits: 64 pixels \(\to\) 32 hidden units \(\to\) 10 scores. We train it with cross-entropy and test it on images it has not seen.

from sklearn.datasets import load_digits
from sklearn.model_selection import train_test_split

D = load_digits()
Xtr, Xte, ytr, yte = train_test_split(D.data / 16.0, D.target, test_size=0.25,
                                      random_state=0, stratify=D.target)
Xtr_t, Xte_t = (torch.tensor(a, dtype=torch.float32) for a in (Xtr, Xte))
ytr_t, yte_t = torch.tensor(ytr), torch.tensor(yte)

def test_acc(model, X=Xte_t, y=yte_t):
    with torch.no_grad():
        return (model(X).argmax(1) == y).float().mean().item()

torch.manual_seed(0)
linear_clf = nn.Linear(64, 10)
mlp = nn.Sequential(nn.Linear(64, 32), nn.ReLU(), nn.Linear(32, 10))
ce = nn.CrossEntropyLoss()
for name, m in [("linear", linear_clf), ("MLP 64-32-10", mlp)]:
    loss = fit(m, Xtr_t, ytr_t, ce, steps=600, lr=0.5)
    n = sum(p.numel() for p in m.parameters())
    print(f"{name:14s} params {n:5d}  train loss {loss:.3f}  test accuracy {test_acc(m):.3f}")
linear         params   650  train loss 0.155  test accuracy 0.958
MLP 64-32-10   params  2410  train loss 0.040  test accuracy 0.976

The MLP is more accurate than the linear model. The gain is small on this easy data. The linear model already reads digits well (Chapter 9).

11.7 Production: modules

PyTorch packages the composition as a Module. A class makes the structure explicit and reusable.

class MLP(nn.Module):
    def __init__(self, sizes):
        super().__init__()
        layers = []
        for i, (n_in, n_out) in enumerate(zip(sizes[:-1], sizes[1:])):
            layers.append(nn.Linear(n_in, n_out))
            if i < len(sizes) - 2:
                layers.append(nn.ReLU())                  # none after the last layer
        self.net = nn.Sequential(*layers)

    def forward(self, x):
        return self.net(x)

m = MLP([64, 32, 10])
print(m)
print("parameters:", sum(p.numel() for p in m.parameters()),
      "  formula:", n_params([64, 32, 10]))
print("state dict shapes:", {k: tuple(v.shape) for k, v in m.state_dict().items()})

    (1): ReLU()
    (2): Linear(in_features=32, out_features=10, bias=True)
  )
)

11.8 Failure modes

11.8.1 The same architecture can fail to train

We train a 9-layer ReLU network on the digits with the same data, loss, and optimiser. The only difference is the initial weights.

def deep_net(he_init):
    layers = [nn.Linear(64, 32), nn.ReLU()]
    for _ in range(8):
        layers += [nn.Linear(32, 32), nn.ReLU()]
    net = nn.Sequential(*layers, nn.Linear(32, 10))
    if he_init:
        for mod in net:
            if isinstance(mod, nn.Linear):
                nn.init.kaiming_normal_(mod.weight, nonlinearity="relu")
                nn.init.zeros_(mod.bias)
    return net

def fit_curve(model, steps, lr):
    opt = torch.optim.SGD(model.parameters(), lr=lr); hist = []
    for _ in range(steps):
        opt.zero_grad(); loss = ce(model(Xtr_t), ytr_t); loss.backward(); opt.step()
        hist.append(loss.item())
    return hist

torch.manual_seed(0); h_default = fit_curve(deep_net(False), 600, 0.1)
torch.manual_seed(0); net_he = deep_net(True); h_he = fit_curve(net_he, 600, 0.1)

fig, ax = plt.subplots()
ax.plot(h_default, color=PALETTE["loss"], label="default init")
ax.plot(h_he, color=PALETTE["grad"], label="He init")
ax.set_xlabel("step"); ax.set_ylabel("training loss"); ax.legend()
plt.show()
print(f"default init: final loss {h_default[-1]:.3f}")
print(f"He init:      final loss {h_he[-1]:.4f}, test accuracy {test_acc(net_he):.3f}")
default init: final loss 2.302
He init:      final loss 0.0026, test accuracy 0.953

11.8.2 Other failures

  • Wrong head and loss. A softmax output with a squared-error loss, or a ReLU on the final layer of a regression model, can train badly or never work. Match them as in the table above.
  • No nonlinearity. Forgetting the activation gives a linear model with extra parameters (Chapter 10).
  • Shape mismatch. The output size of a layer must equal the input size of the next. Shape errors appear at the first forward pass.
  • Overfitting. A network with enough parameters can fit noise. The training accuracy is then no guide to test accuracy (Part VII).
  • Standardisation. Inputs with very different scales slow or break training (Chapter 3).

11.10 System connection

NoteWhat the system gained in this chapter

The system is now a complete model: input → affine → nonlinearity → … → scores. System A runs from pixels to class, and its parameters are learned from data. We also see why composition works: early layers bend space, and later layers read off the result.

Two parts are still borrowed: the loss (we named cross-entropy, Chapter 14 explains it) and the gradient (PyTorch computed it, Chapter 18 derives it). First, Chapter 12 adds a transformation designed for images.

Chapter summary

  • An MLP is \(f_{L}\circ\dots\circ f_1\) with affine layers and activations. The last layer outputs scores.
  • Parameters: \(\sum_l(n_ln_{l-1}+n_l)\).
  • The head and the loss must match the task.
  • Hidden units are learned feature detectors. Hidden layers re-represent the input.
  • On the spiral, more units and layers give a boundary that follows the data.
  • System A: a 64-32-10 MLP reaches about 97% test accuracy on digits.
  • Initialisation can decide whether a deep network trains at all.
