48  Random Perturbation and Error Propagation

NoteKey ideas
  • When a pipeline stage takes an uncertain input, its output is uncertain too. We describe uncertainty by a mean and a covariance.
  • To first order, a covariance \(\boldsymbol\Sigma\) passes through a function \(f\) as \(\mathbf J\boldsymbol\Sigma\mathbf J^{\intercal}\), where \(\mathbf J\) is the Jacobian of \(f\).
  • A fitted parameter has a covariance that follows from the design (where the data points are). It is not only a function of the noise level.
  • The first-order rule fails when the function is strongly non-linear over the size of the noise. A near-parallel line intersection is a clear example. Test the rule by simulation.
  • Propagation lets us budget the error of a system: which stage contributes how much.

48.1 The system problem

Chapter 47 characterised one component against noise on its input. In a pipeline, the input of stage 2 is the output of stage 1. Its noise is not an assumption any more. It is a result.

A line is fitted to noisy points, and two such lines are intersected. How uncertain is the intersection, and which part of the pipeline controls it?

This is the second step in the programme of Haralick and Ramesh: carry the perturbation model through the whole sequence of operations, so that the uncertainty at the end is predicted from the uncertainty at the start (see the sources in Chapter 47).

48.2 Propagating a covariance

Let \(\mathbf u\in\mathbb R^n\) be a random vector with mean \(\boldsymbol\mu\) and covariance \(\boldsymbol\Sigma\) (Chapter 23). Let \(\mathbf v=f(\mathbf u)\). The first-order (Taylor) expansion around \(\boldsymbol\mu\) is

\[ \mathbf v\approx f(\boldsymbol\mu)+\mathbf J\,(\mathbf u-\boldsymbol\mu),\qquad \mathbf J=\left.\frac{\partial f}{\partial\mathbf u}\right|_{\boldsymbol\mu}. \tag{48.1}\]

Taking the covariance of both sides gives the propagation rule:

\[ \operatorname{Cov}(\mathbf v)\approx\mathbf J\,\boldsymbol\Sigma\,\mathbf J^{\intercal}. \tag{48.2}\]

It is exact if \(f\) is linear. It is the covariance form of the chain rule (Chapter 18). For a chain \(f_2\circ f_1\) we apply it twice, which multiplies the Jacobians (Equation 46.1).

We implement the rule with a numerical Jacobian, so that it works for any function we can call.

def jacobian(f, u, h=1e-6):
    u = np.asarray(u, float); f0 = np.atleast_1d(f(u))
    J = np.empty((f0.size, u.size))
    for j in range(u.size):
        d = np.zeros_like(u); d[j] = h
        J[:, j] = (np.atleast_1d(f(u + d)) - np.atleast_1d(f(u - d))) / (2 * h)
    return J

def propagate(f, mu, Sigma):
    J = jacobian(f, mu)
    return J @ Sigma @ J.T

# a check on a function whose answer is known: v = u1 * u2 with u independent
mu = np.array([3.0, 2.0]); S = np.diag([0.01, 0.04])
print("propagated variance of u1*u2:", propagate(lambda u: u[0] * u[1], mu, S)[0, 0].round(4))
print("by hand: u2^2 var1 + u1^2 var2 =", (2.0**2 * 0.01 + 3.0**2 * 0.04))
propagated variance of u1*u2: 0.4
by hand: u2^2 var1 + u1^2 var2 = 0.39999999999999997

48.3 Stage 1: the covariance of a fitted line

We observe \(y_i=a x_i+b+\epsilon_i\) at fixed positions \(x_i\) with independent noise of standard deviation \(\sigma\). Least squares gives \((\hat a,\hat b)\). Write the design matrix \(\mathbf X\) with rows \((x_i,1)\). Then, exactly (Chapter 25),

\[ \operatorname{Cov}\begin{pmatrix}\hat a\\\hat b\end{pmatrix}=\sigma^2\,(\mathbf X^{\intercal}\mathbf X)^{-1}. \tag{48.3}\]

The matrix \(\mathbf X^{\intercal}\mathbf X\) depends on where we sample. Points that spread widely in \(x\) give a precise slope. Points that cluster give an uncertain one. The uncertainty is partly a design property, not only a noise property.

rng = np.random.default_rng(48)
sigma = 0.3
def cov_ab(x, sigma):
    X = np.column_stack([x, np.ones_like(x)])
    return sigma**2 * np.linalg.inv(X.T @ X)

x_wide = np.linspace(0, 10, 20)
x_narrow = np.linspace(4, 6, 20)
for name, x in [("x in [0,10]", x_wide), ("x in [4,6] ", x_narrow)]:
    C = cov_ab(x, sigma)
    print(f"{name}: std(a) = {np.sqrt(C[0,0]):.4f}   std(b) = {np.sqrt(C[1,1]):.4f}")

# confirm by simulation
a_true, b_true = 0.5, 1.0
est = []
for _ in range(20000):
    y = a_true * x_wide + b_true + rng.normal(0, sigma, x_wide.size)
    est.append(np.polyfit(x_wide, y, 1))
est = np.array(est)
print("simulated std(a), std(b) for x in [0,10]:", est.std(0).round(4))
x in [0,10]: std(a) = 0.0221   std(b) = 0.1293
x in [4,6] : std(a) = 0.1105   std(b) = 0.5566
simulated std(a), std(b) for x in [0,10]: [0.022  0.1283]

Squeezing the sample positions into \([4,6]\) makes the slope five times less certain. The simulation agrees with Equation 48.3.

48.4 Stage 2: the intersection of two lines

Two lines \(y=a_1x+b_1\) and \(y=a_2x+b_2\) meet at

\[ x^*=\frac{b_2-b_1}{a_1-a_2},\qquad y^*=a_1x^*+b_1. \tag{48.4}\]

The denominator \(a_1-a_2\) explains the behaviour: when the lines are nearly parallel, a small slope error moves \(x^*\) a long way. We compute the predicted covariance with Equation 48.2 and compare with a Monte Carlo experiment for two configurations: lines crossing at a wide angle and at a narrow angle. Both cross at \((5,\,3.5)\).

def intersect(p):
    a1, b1, a2, b2 = p
    x = (b2 - b1) / (a1 - a2)
    return np.array([x, a1 * x + b1])

configs = {
    "wide angle   (slopes  0.5, -0.5)": (0.5, 1.0, -0.5, 6.0),
    "narrow angle (slopes  0.5,  0.4)": (0.5, 1.0, 0.4, 1.5),
}
x = x_wide
rows = {}
for name, (a1, b1, a2, b2) in configs.items():
    # block-diagonal covariance of the four line parameters (the two fits are independent)
    C = cov_ab(x, sigma)
    S = np.block([[C, np.zeros((2, 2))], [np.zeros((2, 2)), C]])
    p0 = np.array([a1, b1, a2, b2])
    pred = propagate(intersect, p0, S)
    # Monte Carlo
    pts = []
    for _ in range(20000):
        pa = np.polyfit(x, a1 * x + b1 + rng.normal(0, sigma, x.size), 1)
        pb = np.polyfit(x, a2 * x + b2 + rng.normal(0, sigma, x.size), 1)
        pts.append(intersect([pa[0], pa[1], pb[0], pb[1]]))
    pts = np.array(pts)
    rows[name] = (pred, pts)
    print(name)
    print("   predicted std (x, y):", np.sqrt(np.diag(pred)).round(3))
    print("   simulated std (x, y):", pts.std(0).round(3))
wide angle   (slopes  0.5, -0.5)
   predicted std (x, y): [0.095 0.047]
   simulated std (x, y): [0.095 0.048]
narrow angle (slopes  0.5,  0.4)
   predicted std (x, y): [0.949 0.43 ]
   simulated std (x, y): [2.887 1.334]

At the wide angle, theory and simulation agree: \(0.095\) against \(0.095\) for \(x^*\). At the narrow angle the prediction is \(0.949\), ten times larger, and the simulation gives \(2.887\), about three times larger again. The narrow angle is a different regime, and the first-order prediction is too optimistic there, because \(x^*\) is a ratio whose denominator \(a_1-a_2\) can come close to zero. We look at the distribution, not only at the standard deviation.

fig, axs = plt.subplots(1, 2, figsize=(9.6, 3.6))
t = np.linspace(0, 2 * np.pi, 200)
for ax, (name, (pred, pts)) in zip(axs, rows.items()):
    ax.plot(*pts[:1500].T, ".", ms=2, alpha=0.4, color=PALETTE["data"])
    mu = intersect(configs[name])
    w, V = np.linalg.eigh(pred)
    E = mu[:, None] + V @ (2 * np.sqrt(w)[:, None] * np.array([np.cos(t), np.sin(t)]))
    ax.plot(*E, color=PALETTE["loss"], lw=2, label="predicted 2σ ellipse")
    ax.plot(*mu, "k+", ms=10)
    ax.set_title(name.split("(")[0].strip()); ax.set_xlabel("x*"); ax.set_ylabel("y*")
    ax.set_aspect("equal", adjustable="datalim"); ax.legend(fontsize=8)
plt.show()
for name, (pred, pts) in rows.items():
    mu = intersect(configs[name])
    inside = []
    Pinv = np.linalg.inv(pred)
    d2 = np.einsum("ij,jk,ik->i", pts - mu, Pinv, pts - mu)
    print(f"{name.split('(')[0].strip():13s}: share of points inside the predicted 2-sigma ellipse "
          f"(Mahalanobis² < 4): {(d2 < 4).mean():.3f}   (Gaussian: 0.865)")
wide angle   : share of points inside the predicted 2-sigma ellipse (Mahalanobis² < 4): 0.863   (Gaussian: 0.865)
narrow angle : share of points inside the predicted 2-sigma ellipse (Mahalanobis² < 4): 0.810   (Gaussian: 0.865)

For a Gaussian cloud, 86.5% of points fall inside the 2-sigma ellipse in two dimensions. The wide-angle cloud gives \(0.863\). The narrow-angle cloud gives \(0.810\), with a much longer tail than the model. The predicted covariance understates the probability of a large error. The correct statement is that first-order propagation is a design tool, valid where noise is small compared with the scale on which the function curves.

48.5 When does first order break?

We repeat the narrow-angle case with increasing noise and compare the predicted standard deviation of \(x^*\) with the simulated one.

a1, b1, a2, b2 = configs["narrow angle (slopes  0.5,  0.4)"]
sig_list = [0.02, 0.05, 0.1, 0.2, 0.3, 0.5]
ratio, rob = [], []
for sg in sig_list:
    C = cov_ab(x, sg); S = np.block([[C, np.zeros((2, 2))], [np.zeros((2, 2)), C]])
    pred = np.sqrt(propagate(intersect, np.array([a1, b1, a2, b2]), S)[0, 0])
    sims = []
    for _ in range(8000):
        pa = np.polyfit(x, a1 * x + b1 + rng.normal(0, sg, x.size), 1)
        pb = np.polyfit(x, a2 * x + b2 + rng.normal(0, sg, x.size), 1)
        sims.append(intersect([pa[0], pa[1], pb[0], pb[1]])[0])
    sims = np.array(sims)
    ratio.append(sims.std() / pred)
    # a robust width (IQR / 1.349) is not affected by the rare extremes
    q1, q3 = np.percentile(sims, [25, 75]); rob.append((q3 - q1) / 1.349 / pred)
fig, ax = plt.subplots(figsize=(6.4, 3.4))
ax.plot(sig_list, ratio, "o-", color=PALETTE["loss"], label="std ratio")
ax.plot(sig_list, rob, "s--", color=PALETTE["data"], label="robust (IQR) ratio")
ax.axhline(1, color="gray", lw=1)
ax.set_xlabel("noise σ"); ax.set_ylabel("simulated / predicted"); ax.legend()
plt.show()
for sg, r1, r2 in zip(sig_list, ratio, rob):
    print(f"sigma {sg:4.2f}: std ratio {r1:5.2f}   robust ratio {r2:5.2f}")
sigma 0.02: std ratio  1.00   robust ratio  1.00
sigma 0.05: std ratio  1.00   robust ratio  1.00
sigma 0.10: std ratio  1.02   robust ratio  1.01
sigma 0.20: std ratio  1.08   robust ratio  1.01
sigma 0.30: std ratio 18.21   robust ratio  1.03
sigma 0.50: std ratio 26.40   robust ratio  1.07

The ratio is \(1.00\) to \(1.08\) for \(\sigma\le0.2\), which confirms the rule in its range of validity. At \(\sigma=0.3\) and \(0.5\) the standard deviation ratio jumps to \(18\) and \(26\). In some trials \(a_1-a_2\) is close to zero and \(x^*\) explodes. A ratio of two Gaussians has no finite variance, so this sample standard deviation is not even stable: the same case gave a ratio of about \(3\) in the 20,000-trial run above and \(18\) here. The robust width (interquartile range) stays at \(1.03\) and \(1.07\). So the bulk of the distribution is predicted well and the tails are not. A report should state the regime where the first-order rule holds, and give quantiles for the tails.

48.6 An error budget

Propagation gives more than a total. The contribution of each input to the output variance is the sum of the terms \(J_{ij}\,\Sigma_{jj}\,J_{ij}\) (for uncorrelated inputs). For the wide-angle configuration we split the variance of \(x^*\) by line parameter.

a1, b1, a2, b2 = configs["wide angle   (slopes  0.5, -0.5)"]
C = cov_ab(x, sigma)
S = np.block([[C, np.zeros((2, 2))], [np.zeros((2, 2)), C]])
p0 = np.array([a1, b1, a2, b2])
J = jacobian(intersect, p0)
# contributions include correlation inside each line's (a, b) pair, so group by line
line1 = J[0, :2] @ C @ J[0, :2]
line2 = J[0, 2:] @ C @ J[0, 2:]
total = line1 + line2
print(f"variance of x*: {total:.4f}   line 1 share {line1/total:.2f}   line 2 share {line2/total:.2f}")
print("Jacobian row for x* with respect to (a1, b1, a2, b2):", J[0].round(3))
variance of x*: 0.0090   line 1 share 0.50   line 2 share 0.50
Jacobian row for x* with respect to (a1, b1, a2, b2): [-5. -1.  5.  1.]

The two lines contribute equally here, as the symmetric design suggests. If one line were fitted from fewer points, the budget would show that line as the one to improve. This is the engineering use of propagation: it says where to spend measurement effort.

48.7 Failure modes

Linearisation outside its range. The rule holds for small noise and mild curvature. Narrow angles, near-singular matrices and ratios break it (Figure 48.3).

Ignoring correlation. The outputs of one stage are usually correlated (here \(\hat a\) and \(\hat b\) are). Treating them as independent gives the wrong covariance.

Input noise model wrong. The rule propagates the model, whatever it is. If the model is wrong at the input, the result is exact and meaningless.

Bias ignored. First-order propagation gives the covariance. It does not give the bias of a non-linear transform. The mean of the output is not \(f(\boldsymbol\mu)\) in general.

Standard deviation as tail guarantee. A heavy-tailed output needs a quantile, not a standard deviation. Here the sample standard deviation differed by a factor of six between two runs.

48.9 System connection

NoteWhat the system gained in this chapter

The system can now predict the uncertainty of a pipeline output from the uncertainty of its input. We have a general propagation rule, an exact result for the fitted-line covariance that depends on the sampling design, a worked non-linear stage, a test that shows where the rule fails, and a budget that points to the dominant contributor.

Everything so far was about the spread of continuous errors. Many components make decisions: detect or not, accept or reject. Their quality is measured by two kinds of error at once, and the trade-off between them is the subject of Chapter 49, with the confidence that comes with a finite test set.

Chapter summary

  • A covariance passes through \(f\) as \(\mathbf J\boldsymbol\Sigma\mathbf J^{\intercal}\) to first order.
  • For least squares, \(\operatorname{Cov}=\sigma^2(\mathbf X^{\intercal}\mathbf X)^{-1}\). Design matters.
  • Intersecting nearly parallel lines amplifies error through the ratio in Equation 48.4.
  • First-order propagation fails for large noise and strong curvature. Check by simulation.
  • An error budget shows which input dominates.
