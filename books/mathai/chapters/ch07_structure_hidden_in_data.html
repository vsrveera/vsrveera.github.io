7  Structure Hidden in Data

NoteKey ideas
  • An eigenvector of a matrix is a direction that the matrix only stretches. The stretch factor is the eigenvalue.
  • The covariance matrix of a dataset records how features vary together. Its eigenvectors are the natural axes of the data cloud.
  • PCA projects data onto the top eigenvectors of the covariance. It keeps the directions of largest variance.
  • SVD factors any matrix into rotate–stretch–rotate. It gives the best low-rank approximation.
  • A low-rank structure lets us describe a large matrix with far fewer numbers. This is the idea behind compression and LoRA.

7.1 The system problem

A digit image has 64 numbers. A word embedding has hundreds. A weight matrix in a language model has millions.

Do we need all of these numbers? Often a few directions carry most of what matters. The other directions hold small variations or noise.

Can a 64-number image be described by far fewer numbers without losing what matters?

The tools of this chapter find those directions. They answer three practical questions: how to compress data, how to visualise it in 2D, and how to update a huge model with few parameters.

7.2 Eigenvectors: directions that survive

A matrix usually changes the direction of a vector. For a few special directions it does not. It only stretches or flips them.

\[ \mathbf{A}\mathbf{v}=\lambda\,\mathbf{v},\qquad \mathbf{v}\neq\mathbf{0}. \tag{7.1}\]

The vector \(\mathbf{v}\) is an eigenvector. The number \(\lambda\) is its eigenvalue.

Worked example. Take \(\mathbf{S}=\begin{pmatrix}2&1\\1&2\end{pmatrix}\). We need \((\mathbf{S}-\lambda\mathbf{I})\mathbf{v}=\mathbf{0}\) with \(\mathbf{v}\ne\mathbf{0}\). This needs \(\det(\mathbf{S}-\lambda\mathbf{I})=0\):

\[ (2-\lambda)^2-1=0\ \Rightarrow\ \lambda_1=3,\ \lambda_2=1. \]

For \(\lambda_1=3\): \(\mathbf{v}_{1}\propto(1,1)\). For \(\lambda_2=1\): \(\mathbf{v}_{2}\propto(1,-1)\). The matrix stretches the diagonal direction by 3 and leaves the anti-diagonal direction unchanged.

S = np.array([[2.0, 1.0], [1.0, 2.0]])
vals, vecs = np.linalg.eigh(S)                  # symmetric: eigh, ascending order
print("eigenvalues:", vals)
print("eigenvectors (columns):\n", np.round(vecs, 3))

fig, ax = plt.subplots(figsize=(4.6, 4.6))
warp_grid(ax, S, title="S = [[2, 1], [1, 2]]")
for k, col in zip([1, 0], [PALETTE["loss"], PALETTE["grad"]]):
    v = vecs[:, k]
    ax.plot([-3 * v[0], 3 * v[0]], [-3 * v[1], 3 * v[1]], color=col, lw=2,
            label=f"λ = {vals[k]:.0f}")

plt.show()

For a symmetric matrix (\(\mathbf{S}=\mathbf{S}^{\intercal}\)) a strong result holds. We state it without proof.

ImportantSpectral theorem

A real symmetric matrix has real eigenvalues. It has \(n\) eigenvectors that are orthonormal. So \(\mathbf{S}=\mathbf{V}\boldsymbol{\Lambda}\mathbf{V}^{\intercal}\) with \(\mathbf{V}\) orthogonal and \(\boldsymbol{\Lambda}\) diagonal.

7.3 The covariance matrix

How do we describe the shape of a data cloud? One number per feature (its spread) is not enough. Two features can vary together.

Take \(N\) data points \(\mathbf{x}_{i}\in\mathbb{R}^d\), stored as rows of \(\mathbf{X}\in\mathbb{R}^{N\times d}\). First centre the data by subtracting the mean: \(\mathbf{X}_c=\mathbf{X}-\boldsymbol{\mu}\). The sample covariance matrix is

\[ \mathbf{S}=\frac{1}{N}\mathbf{X}_c^{\intercal}\mathbf{X}_c, \qquad S_{jk}=\frac1N\sum_{i=1}^{N}(x_{ij}-\mu_j)(x_{ik}-\mu_k). \tag{7.2}\]

  • The diagonal \(S_{jj}\) is the variance of feature \(j\).
  • The off-diagonal \(S_{jk}\) is positive when features \(j\) and \(k\) rise together, and negative when one rises as the other falls.
  • \(\mathbf{S}\) is symmetric and \(d\times d\).

Chapter 21 gives the probabilistic meaning of covariance. Here we use it as a computed object.

rng = np.random.default_rng(0)
A = np.array([[2.0, 0.0], [1.2, 0.6]])                       # shapes the cloud
X2 = rng.normal(size=(400, 2)) @ A.T + np.array([3.0, 2.0])  # (400, 2)

mu = X2.mean(axis=0)                           # (2,)
Xc = X2 - mu                                   # centred
Scov = Xc.T @ Xc / len(X2)                     # (2, 2)
lam, V = np.linalg.eigh(Scov)                  # ascending

fig, ax = plt.subplots(figsize=(5.2, 4.2))
ax.scatter(*X2.T, s=10, alpha=0.5, color=PALETTE["data"])
for k, col in [(1, PALETTE["model"]), (0, PALETTE["loss"])]:
    draw_arrow(ax, 2 * np.sqrt(lam[k]) * V[:, k], origin=mu, color=col, lw=3)
ax.set_aspect("equal"); ax.set_xlabel("feature 1"); ax.set_ylabel("feature 2")
plt.show()
print("covariance:\n", np.round(Scov, 2))
print("eigenvalues (variance along each axis):", np.round(lam, 2))

7.4 PCA: the best directions

Principal component analysis (PCA) answers: in which direction does the data vary most? For a unit vector \(\mathbf{u}\), the data projected on it has coordinates \(\mathbf{u}\cdot\mathbf{x}_i\). The variance of these is

\[ \frac1N\sum_i(\mathbf{u}\cdot\mathbf{x}_{c,i})^2=\mathbf{u}^{\intercal}\mathbf{S}\,\mathbf{u}. \tag{7.3}\]

TipDerivation: the best direction is the top eigenvector

We want the unit vector \(\mathbf{u}\) that maximises \(\mathbf{u}^{\intercal}\mathbf{S}\mathbf{u}\).

By the spectral theorem, \(\mathbf{S}\) has orthonormal eigenvectors \(\mathbf{v}_1,\dots,\mathbf{v}_d\) with eigenvalues \(\lambda_{1}\ge\dots\ge\lambda_{d}\ge0\). Write \(\mathbf{u}=\sum_ic_{i}\mathbf{v}_i\). Because \(\mathbf{u}\) has unit length, \(\sum_ic_i^2=1\). Then

\[ \mathbf{u}^{\intercal}\mathbf{S}\mathbf{u}=\sum_{i}\lambda_i\,c_i^2. \]

This is a weighted average of the eigenvalues, with weights \(c_i^2\) that sum to 1. A weighted average cannot exceed the largest value. So \(\mathbf{u}^{\intercal}\mathbf{S}\mathbf{u}\le\lambda_1\), with equality exactly when \(\mathbf{u}=\mathbf{v}_1\).

The best direction is \(\mathbf{v}_1\), and the variance it captures is \(\lambda_1\). The same argument, restricted to vectors orthogonal to \(\mathbf{v}_1\), gives \(\mathbf{v}_2\) with variance \(\lambda_2\), and so on. \(\blacksquare\)

The procedure is:

  1. Centre the data.
  2. Compute \(\mathbf{S}\).
  3. Find its eigenvectors, sorted by eigenvalue.
  4. Keep the top \(k\). Project: \(\mathbf{z}_i=\mathbf{V}_k^{\intercal}(\mathbf{x}_i-\boldsymbol{\mu})\).
  5. Reconstruct if needed: \(\hat{\mathbf{x}}_i=\boldsymbol{\mu}+\mathbf{V}_{k}\mathbf{z}_i\).

The fraction of variance kept by \(k\) components is \(\sum_{i\le k}\lambda_{i}\big/\sum_{i}\lambda_i\).

def pca_fit(X):
    mu = X.mean(axis=0)
    Xc = X - mu
    S = Xc.T @ Xc / len(X)
    lam, V = np.linalg.eigh(S)
    order = np.argsort(lam)[::-1]              # largest first
    return mu, lam[order], V[:, order]

def pca_transform(X, mu, V, k):
    return (X - mu) @ V[:, :k]                 # (N, k)

def pca_inverse(Z, mu, V):
    k = Z.shape[1]
    return mu + Z @ V[:, :k].T                 # (N, d)

7.5 SVD: the general factorisation

The eigen-decomposition works for symmetric square matrices. The singular value decomposition (SVD) works for every matrix \(\mathbf{A}\in\mathbb{R}^{m\times n}\):

\[ \mathbf{A}=\mathbf{U}\boldsymbol{\Sigma}\mathbf{V}^{\intercal}, \tag{7.4}\]

with \(\mathbf{U}\) (\(m\times m\)) and \(\mathbf{V}\) (\(n\times n\)) orthogonal, and \(\boldsymbol{\Sigma}\) diagonal with \(\sigma_{1}\ge\sigma_{2}\ge\dots\ge0\), the singular values.

The geometry is clear: rotate (by \(\mathbf{V}^{\intercal}\)), stretch along the axes (by \(\boldsymbol{\Sigma}\)), rotate (by \(\mathbf{U}\)). The image of the unit circle is an ellipse whose semi-axes are the singular values.

M = np.array([[2.0, 0.6], [1.0, 1.4]])
U, s, Vt = np.linalg.svd(M)
t = np.linspace(0, 2 * np.pi, 200)
circle = np.stack([np.cos(t), np.sin(t)])

fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(8, 3.8))
setup_2d(ax1, xlim=(-3, 3), ylim=(-3, 3)); ax1.set_title("input: unit circle")
ax1.plot(*circle, color=PALETTE["data"])
for k, col in enumerate([PALETTE["model"], PALETTE["prob"]]):
    draw_arrow(ax1, Vt[k], color=col, lw=2.5, label=f"v{k+1}",
               label_offset=(0.1, 0.1))
setup_2d(ax2, xlim=(-3, 3), ylim=(-3, 3)); ax2.set_title("output: M · circle")
ax2.plot(*(M @ circle), color=PALETTE["data"])
for k, col in enumerate([PALETTE["model"], PALETTE["prob"]]):
    draw_arrow(ax2, s[k] * U[:, k], color=col, lw=2.5,
               label=f"σ{k+1}u{k+1}", label_offset=(0.1, 0.1))
plt.tight_layout(); plt.show()
print("singular values:", np.round(s, 3))
print("check  U Σ Vᵀ = M :", np.allclose(U @ np.diag(s) @ Vt, M))

7.5.1 SVD and PCA are the same computation

For centred data \(\mathbf{X}_c=\mathbf{U}\boldsymbol{\Sigma}\mathbf{V}^{\intercal}\). Then

\[ \mathbf{S}=\frac1N\mathbf{X}_c^{\intercal}\mathbf{X}_c=\mathbf{V}\,\frac{\boldsymbol{\Sigma}^2}{N}\,\mathbf{V}^{\intercal}. \tag{7.5}\]

So the right singular vectors \(\mathbf{V}\) are the principal directions, and the eigenvalues of \(\mathbf{S}\) are \(\sigma_i^2/N\). SVD is the numerically preferred way to do PCA because it never forms \(\mathbf{X}_c^{\intercal}\mathbf{X}_c\).

Xc = X - X.mean(axis=0)
U, s, Vt = np.linalg.svd(Xc, full_matrices=False)       # (1797,64) (64,) (64,64)
print("eigenvalues from SVD match covariance:", np.allclose(s ** 2 / len(X), lam))
cos = np.abs(np.sum(Vt.T * V, axis=0))                  # |cosine| per component
print("directions match up to sign (first 5):", np.round(cos[:5], 6))
eigenvalues from SVD match covariance: True
directions match up to sign (first 5): [1. 1. 1. 1. 1.]

7.5.2 Best low-rank approximation

Keep only the top \(k\) terms of the SVD:

\[ \mathbf{A}_k=\sum_{i=1}^{k}\sigma_i\,\mathbf{u}_{i}\mathbf{v}_i^{\intercal}. \tag{7.6}\]

ImportantEckart–Young theorem (statement)

Among all matrices of rank at most \(k\), \(\mathbf{A}_k\) is closest to \(\mathbf{A}\) in Frobenius norm. The error is \[ \lVert\mathbf{A}-\mathbf{A}_{k}\rVert_F^2=\sum_{i>k}\sigma_i^2. \]

The error is exactly the energy in the discarded singular values. We verify it numerically below. The proof that no other rank-\(k\) matrix does better needs more tools. We omit it.

7.5.3 Compressing an image

A greyscale image is a matrix. If its singular values fall fast, a low-rank approximation stores it in far fewer numbers.

from sklearn.datasets import load_sample_image
gray = load_sample_image("china.jpg").astype(float).mean(axis=2)     # (427, 640)
Ug, sg, Vtg = np.linalg.svd(gray, full_matrices=False)

def rank_k(k):
    return (Ug[:, :k] * sg[:k]) @ Vtg[:k]          # sum of k rank-1 terms

fig, axes = plt.subplots(1, 5, figsize=(11, 2.4))
axes[0].imshow(gray, cmap="gray"); axes[0].set_title("original")
for ax, k in zip(axes[1:], [1, 5, 20, 50]):
    ax.imshow(rank_k(k), cmap="gray"); ax.set_title(f"rank {k}")
for ax in axes: ax.axis("off")
plt.tight_layout(); plt.show()
m, n = gray.shape
ks = np.arange(1, 201)
total = np.sum(sg ** 2)
rel_err = np.sqrt(np.array([np.sum(sg[k:] ** 2) for k in ks]) / total)
storage = ks * (m + n + 1) / (m * n)            # k (m + n + 1) numbers

# check the Eckart–Young error formula at k = 20
direct = np.linalg.norm(gray - rank_k(20)) / np.linalg.norm(gray)
print(f"k=20: relative error from formula {rel_err[19]:.4f}, direct {direct:.4f}")

fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(9, 3.2))
ax1.semilogy(ks, rel_err, color=PALETTE["loss"])
ax1.set_xlabel("rank k"); ax1.set_ylabel("relative error ‖A − A_k‖ / ‖A‖")
ax2.plot(ks, storage, color=PALETTE["data"])
ax2.set_xlabel("rank k"); ax2.set_ylabel("storage / original")
plt.tight_layout(); plt.show()
print(f"k=50: storage {storage[49]:.1%}, relative error {rel_err[49]:.1%}")

7.6 Low rank in modern AI: LoRA

The weight matrices of large models have millions of entries. Fine-tuning a model for a new task changes them. Updating every entry is expensive: it needs gradients and optimizer state for every weight.

Low-Rank Adaptation (LoRA) freezes the pre-trained matrix \(\mathbf{W}_{0}\in\mathbb{R}^{d\times d}\) and learns only a low-rank update:

\[ \mathbf{W}=\mathbf{W}_0+\Delta\mathbf{W}, \qquad \Delta\mathbf{W}=\mathbf{B}\mathbf{A}, \qquad \mathbf{B}\in\mathbb{R}^{d\times r},\ \mathbf{A}\in\mathbb{R}^{r\times d},\ r\ll d. \tag{7.7}\]

The update has rank at most \(r\). It has \(2dr\) parameters instead of \(d^2\).

d = 4096
ranks = [1, 4, 8, 16, 64]
full = d * d
lora = [2 * d * r for r in ranks]
for r, p in zip(ranks, lora):
    print(f"r = {r:3d}: {p:>9,d} parameters   ({p / full:.2%} of full)")

fig, ax = plt.subplots(figsize=(6.5, 3.4))
ax.bar(["full"] + [f"r={r}" for r in ranks], [full] + lora,
       color=[PALETTE["loss"]] + [PALETTE["grad"]] * len(ranks))
ax.set_yscale("log"); ax.set_ylabel("trainable parameters")
plt.show()
r =   1:     8,192 parameters   (0.05% of full)
r =   4:    32,768 parameters   (0.20% of full)
r =   8:    65,536 parameters   (0.39% of full)
r =  16:   131,072 parameters   (0.78% of full)
r =  64:   524,288 parameters   (3.12% of full)

The method works if the update is approximately low rank. This is an assumption about the task, not a law. We can test the idea on a toy update: a rank-4 matrix plus noise.

rng = np.random.default_rng(0)
dd, true_r = 256, 4
low_rank = rng.normal(size=(dd, true_r)) @ rng.normal(size=(true_r, dd))
delta = low_rank + 0.05 * rng.normal(size=(dd, dd))    # rank 4 plus noise
Ud, sd, Vtd = np.linalg.svd(delta)
rel = [np.sqrt(np.sum(sd[r:] ** 2) / np.sum(sd ** 2)) for r in range(0, 21)]

fig, ax = plt.subplots(figsize=(5.8, 3.4))
ax.semilogy(range(0, 21), np.maximum(rel, 1e-3), "o-",
            color=PALETTE["model"])
ax.axvline(true_r, ls="--", color=PALETTE["neutral"])
ax.set_xlabel("rank r of the approximation")
ax.set_ylabel("relative error")
plt.show()
print(f"relative error  r=3: {rel[3]:.3f}  r=4: {rel[4]:.3f}  r=8: {rel[8]:.3f}")
relative error  r=3: 0.453  r=4: 0.025  r=8: 0.024

LoRA initialises \(\mathbf{B}=\mathbf{0}\), so \(\Delta\mathbf{W}=\mathbf{0}\) at the start. The model begins exactly as the pre-trained one.

7.7 From first principles to production

Libraries provide the same decompositions. We confirm they agree with our code.

from sklearn.decomposition import PCA
import torch

skl = PCA(n_components=10).fit(X)
print("sklearn variance ratio matches ours:",
      np.allclose(skl.explained_variance_ratio_, (lam / lam.sum())[:10]))

Ut, st, Vht = torch.linalg.svd(torch.tensor(Xc), full_matrices=False)
print("torch singular values match NumPy:", np.allclose(st.numpy(), s))

# a LoRA layer in PyTorch: frozen W0 + trainable low-rank update
class LoRALinear(torch.nn.Module):
    def __init__(self, d_in, d_out, r):
        super().__init__()
        self.W0 = torch.nn.Parameter(torch.randn(d_out, d_in),
                                     requires_grad=False)
        self.A = torch.nn.Parameter(torch.randn(r, d_in) * 0.01)
        self.B = torch.nn.Parameter(torch.zeros(d_out, r))      # B = 0 at start
    def forward(self, x):
        return x @ self.W0.T + (x @ self.A.T) @ self.B.T

layer = LoRALinear(512, 512, r=8)
x_in = torch.randn(4, 512)
print("output equals frozen layer at start:",
      torch.allclose(layer(x_in), x_in @ layer.W0.T))
n_train = sum(p.numel() for p in layer.parameters() if p.requires_grad)
print("trainable parameters:", n_train, "  frozen:", layer.W0.numel())

7.8 Failure modes

7.8.1 Forgetting to centre

Without centring, the first “principal component” points at the mean, not at the direction of largest spread.

rng = np.random.default_rng(1)
Xoff = rng.normal(size=(500, 2)) * [1.0, 0.3] + np.array([10.0, 10.0])
ev, evec = np.linalg.eigh(Xoff.T @ Xoff / len(Xoff))
pc1_uncentred = evec[:, -1]
mean_dir = Xoff.mean(axis=0) / np.linalg.norm(Xoff.mean(axis=0))
print("PC1 without centring vs mean direction, |cos| =",
      round(abs(pc1_uncentred @ mean_dir), 4))
_, _, evec_c = pca_fit(Xoff)
print("PC1 with centring: ", np.round(np.abs(evec_c[:, 0]), 3),
      " (spread is along axis 0)")
PC1 without centring vs mean direction, |cos| = 1.0
PC1 with centring:  [1.    0.018]  (spread is along axis 0)

7.8.2 Features on different scales

PCA maximises variance. A feature measured in large units has a large variance and dominates. Standardise features first, unless the scale carries meaning (Chapter 3).

7.8.3 Sign and ties

Eigenvectors are defined up to sign: \(\mathbf{v}\) and \(-\mathbf{v}\) are both valid. Two eigenvalues that are nearly equal give directions that are unstable under small data changes. Do not interpret such directions individually.

7.8.4 Nonlinear structure

PCA is linear. It finds flat subspaces. Data on a curved surface can have no good linear summary.

from sklearn.datasets import make_circles
Xcir, ycir = make_circles(n_samples=600, factor=0.4, noise=0.04, random_state=0)
mu_c, lam_c, V_c = pca_fit(Xcir)
z1 = pca_transform(Xcir, mu_c, V_c, 1)[:, 0]

7.10 System connection

NoteWhat the system gained in this chapter

The system can now find structure. It can rank directions by how much variation they carry, compress data to a few of them, and describe a large matrix by a small one. This closes Part II: the system can represent the world as vectors, matrices, and tensors, measure them, and simplify them.

Part III turns to transformation. A model must not just hold representations. It must change them, step by step, into something useful. Chapter 8 starts with the general notion of a function.

Chapter summary

  • An eigenvector keeps its direction under a matrix: \(\mathbf{A}\mathbf{v}=\lambda\mathbf{v}\).
  • The covariance matrix \(\mathbf{S}=\frac1N\mathbf{X}_c^{\intercal}\mathbf{X}_c\) describes the shape of a data cloud.
  • PCA keeps the top eigenvectors of \(\mathbf{S}\). They maximise the variance of the projection.
  • SVD factors any matrix as rotate–stretch–rotate: \(\mathbf{A}=\mathbf{U}\boldsymbol{\Sigma}\mathbf{V}^{\intercal}\).
  • The best rank-\(k\) approximation drops the small singular values. Its error is \(\sum_{i>k}\sigma_i^2\).
  • LoRA trains \(\Delta\mathbf{W}=\mathbf{B}\mathbf{A}\) with \(2dr\ll d^2\) parameters.
  • Always centre. Standardise features when scales differ. PCA cannot find nonlinear structure.
