20  The Geometry and Dynamics of Learning

NoteKey ideas
  • On a quadratic, gradient descent is stable only if \(\eta<2/\lambda_{\max}\). The speed is set by the condition number \(\kappa=\lambda_{\max}/\lambda_{\min}\).
  • A convex loss has no bad local minima. Neural-network losses are not convex, and saddle points are common.
  • Initialisation must keep the variance of activations and gradients stable across layers: \(\text{Var}(w)=2/n_{\text{in}}\) for ReLU.
  • Normalisation layers (LayerNorm, RMSNorm) hold activation scale fixed and improve conditioning.
  • Gradient clipping limits a single step. It guards against rare, huge gradients.

20.1 The system problem

We have a loss, a gradient, and an optimiser. Sometimes training converges quickly. Sometimes it crawls. Sometimes the loss explodes to nan, or sticks at the loss of a random guess.

Why does training sometimes converge, sometimes crawl, and sometimes explode, and what can we control?

The answer uses the geometry of Chapter 17, the eigenvalues of Chapter 7, and the variance rules of Chapter 15.

20.2 Convexity

A function is convex if the line segment between two points on its graph lies above the graph:

\[ f(\lambda\mathbf{x}+(1-\lambda)\mathbf{y})\le\lambda f(\mathbf{x})+(1-\lambda)f(\mathbf{y}),\qquad\lambda\in[0,1]. \tag{20.1}\]

For a differentiable \(f\), this is equivalent to the first-order condition: the tangent plane lies below the function,

\[ f(\mathbf{y})\ge f(\mathbf{x})+\nabla f(\mathbf{x})\cdot(\mathbf{y}-\mathbf{x}). \tag{20.2}\]

The consequence is strong. If \(\nabla f(\mathbf{x}^*)=\mathbf{0}\), then Equation 20.2 gives \(f(\mathbf{y})\ge f(\mathbf{x}^*)\) for every \(\mathbf{y}\). Every stationary point is a global minimum. There are no bad local minima.

The mean squared error of a linear model is convex (its Hessian is positive semi-definite: Chapter 17). The loss of a neural network is not. We can see this by training two networks from different starts and walking the straight line between their weights.

import torch, torch.nn as nn
from sklearn.datasets import make_moons
from torch.nn.utils import parameters_to_vector as p2v, vector_to_parameters as v2p

Xm, ym = make_moons(300, noise=0.15, random_state=0)
Xm = torch.tensor(Xm, dtype=torch.float32)
ym = torch.tensor(ym, dtype=torch.float32).unsqueeze(1)
bce = nn.functional.binary_cross_entropy_with_logits

def train_net(seed):
    torch.manual_seed(seed)
    m = nn.Sequential(nn.Linear(2, 16), nn.Tanh(), nn.Linear(16, 1))
    opt = torch.optim.SGD(m.parameters(), lr=0.5)
    for _ in range(2000):
        opt.zero_grad(); bce(m(Xm), ym).backward(); opt.step()
    return m

net_a, net_b = train_net(0), train_net(1)
th_a, th_b = p2v(net_a.parameters()).detach(), p2v(net_b.parameters()).detach()
probe = train_net(0)
alphas = np.linspace(0, 1, 41)
losses = []
for al in alphas:
    v2p((1 - al) * th_a + al * th_b, probe.parameters())
    losses.append(bce(probe(Xm), ym).item())
fig, ax = plt.subplots(figsize=(5.8, 3.3))
ax.plot(alphas, losses, color=PALETTE["loss"], lw=2)
ax.set_xlabel("interpolation α  (0 = network A, 1 = network B)"); ax.set_ylabel("loss")
plt.show()
print(f"loss at A: {losses[0]:.3f}, at B: {losses[-1]:.3f}, peak in between: {max(losses):.3f}")

20.3 Stability and speed on a quadratic

Take \(f(\mathbf{x})=\frac12\mathbf{x}^{\intercal}\mathbf{H}\mathbf{x}\) with \(\mathbf{H}\) symmetric positive definite. The gradient is \(\mathbf{H}\mathbf{x}\). Gradient descent is \(\mathbf{x}_{t+1}=(\mathbf{I}-\eta\mathbf{H})\mathbf{x}_t\).

TipDerivation: stability bound and convergence rate

By the spectral theorem, \(\mathbf{H}=\mathbf{V}\boldsymbol{\Lambda}\mathbf{V}^{\intercal}\). Write the position in the eigenbasis: \(\mathbf{c}_t=\mathbf{V}^{\intercal}\mathbf{x}_t\). Then \[ \mathbf{c}_{t+1}=(\mathbf{I}-\eta\boldsymbol{\Lambda})\,\mathbf{c}_t \quad\Longrightarrow\quad c_{t,i}=(1-\eta\lambda_i)^t\,c_{0,i}. \] Each eigen-direction evolves independently. It decays if and only if \(|1-\eta\lambda_i|<1\), which is \(0<\eta\lambda_i<2\). All directions are stable if \[ \boxed{\;\eta<\frac{2}{\lambda_{\max}}\;} \] The slowest direction is the one with the smallest eigenvalue: its factor \(1-\eta\lambda_{\min}\) is close to 1. With the best step \(\eta^*=\frac{2}{\lambda_{\max}+\lambda_{\min}}\), the worst-case factor per step is \[ \rho=\frac{\lambda_{\max}-\lambda_{\min}}{\lambda_{\max}+\lambda_{\min}}=\frac{\kappa-1}{\kappa+1}. \] The number of steps to reduce the error by a factor \(\varepsilon\) is about \(\frac{\kappa}{2}\ln\frac1\varepsilon\). \(\blacksquare\)

The stability limit is set by the steepest direction. The speed is set by the shallowest one. The ratio \(\kappa\) is the price of an elongated valley.

lam = np.array([1.0, 50.0])
def gd_error(eta, steps=100, x0=np.array([1.0, 1.0])):
    x = x0.copy()
    for _ in range(steps):
        x = x - eta * lam * x
        if np.linalg.norm(x) > 1e150: return np.inf
    return np.linalg.norm(x)

etas = np.linspace(0.02, 1.4, 300) * (2 / lam.max())
err = [gd_error(e) for e in etas]

def steps_to_tol(kappa, tol=1e-6):
    l = np.array([1.0, kappa]); eta = 2 / (l.max() + l.min())
    x = np.array([1.0, 1.0]); n = 0
    while np.linalg.norm(x) > tol and n < 10**6:
        x = x - eta * l * x; n += 1
    return n
kappas = [2, 5, 10, 30, 100, 300, 1000]
steps = [steps_to_tol(k) for k in kappas]

fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(10, 3.4))
ax1.semilogy(etas / (2 / lam.max()), np.maximum(err, 1e-30), color=PALETTE["loss"], lw=2)
ax1.axvline(1.0, ls="--", color=PALETTE["neutral"]); ax1.set_ylim(1e-30, 1e30)
ax1.set_xlabel("η / (2/λmax)"); ax1.set_ylabel("‖x‖ after 100 steps")
ax2.loglog(kappas, steps, "o-", color=PALETTE["model"], label="measured")
ax2.loglog(kappas, [steps[0] * k / kappas[0] for k in kappas], "--", color=PALETTE["neutral"], label="∝ κ")
ax2.set_xlabel("condition number κ"); ax2.set_ylabel("steps to reach 1e-6"); ax2.legend()
plt.tight_layout(); plt.show()
print("steps:", dict(zip(kappas, steps)))

20.4 Saddles and local minima

At a critical point, the Hessian classifies the point (Chapter 17). For a minimum we need all eigenvalues positive. How likely is that?

For a random symmetric matrix, the fraction that is positive definite falls extremely fast with the dimension.

rng = np.random.default_rng(0)
print(f"{'dimension':>10s} {'fraction with all eigenvalues > 0':>36s}")
for d in [1, 2, 4, 8]:
    ok = 0
    for _ in range(3000):
        A = rng.normal(size=(d, d)); H = (A + A.T) / 2
        ok += np.all(np.linalg.eigvalsh(H) > 0)
    print(f"{d:10d} {ok / 3000:36.4f}")
 dimension    fraction with all eigenvalues > 0
         1                               0.4787
         2                               0.1577
         4                               0.0017
         8                               0.0000

This is a toy model, not a statement about real networks. It does suggest why, in high dimension, a critical point with some negative eigenvalue (a saddle) is far more likely than a minimum. Saddles are escapable: gradient descent moves away along the negative-curvature direction, even from a tiny perturbation.

f = lambda x, y: x ** 2 - y ** 2 + y ** 4 / 4
grad = lambda p: np.array([2 * p[0], -2 * p[1] + p[1] ** 3])
p = np.array([1.5, 1e-6]); path = [p.copy()]
for _ in range(120):
    p = p - 0.1 * grad(p); path.append(p.copy())
path = np.array(path)
near = np.sum(np.linalg.norm(path, axis=1) < 0.1)

gx, gy = np.meshgrid(np.linspace(-2, 2, 300), np.linspace(-2.2, 2.2, 300))
fig, ax = plt.subplots(figsize=(5.2, 4.4))
ax.contour(gx, gy, f(gx, gy), levels=20, cmap="viridis")
ax.plot(*path.T, "o-", ms=3, color=PALETTE["loss"], lw=1)
ax.plot(0, 0, "kx", ms=10); ax.plot([0, 0], [np.sqrt(2), -np.sqrt(2)], "*", color=PALETTE["grad"], ms=14)
ax.set_aspect("equal")
plt.show()
print(f"steps within distance 0.1 of the saddle: {near}; final point {np.round(path[-1], 2)}")
steps within distance 0.1 of the saddle: 51; final point [0.   1.41]

20.5 Initialisation

Weights start random. How large should they be? If too small, the signal shrinks layer by layer. If too large, it grows. Either way the gradient suffers (Chapter 18).

TipDerivation: variance-preserving initialisation

Take one layer \(z=\sum_{j=1}^{n}w_ja_j\) with \(n\) inputs. Let the weights be independent with mean \(0\) and variance \(\sigma_w^2\), independent of the inputs \(a_j\), which have \(\mathbb{E}[a_j^2]=q\). Then (Chapter 15 primer) \[ \text{Var}(z)=\sum_{j}\text{Var}(w_ja_j)=n\,\sigma_w^2\,q. \]

  • Linear or tanh near zero: \(q=\text{Var}(z_{\text{prev}})\). To keep \(\text{Var}(z)=\text{Var}(z_{\text{prev}})\) we need \(\sigma_w^2=1/n\) (Xavier/Glorot uses the average of fan-in and fan-out).
  • ReLU: it zeroes the negative half of a symmetric input, so \(q=\tfrac12\text{Var}(z_{\text{prev}})\). We need \(\sigma_w^2=2/n\) (He initialisation). \(\blacksquare\)
rng = np.random.default_rng(0)
n, L = 256, 40
x0 = rng.normal(size=(64, n))
def activation_std(scale_fn):
    a = x0; out = []
    for _ in range(L):
        W = rng.normal(0, scale_fn(n), size=(n, n))
        a = np.maximum(0, a @ W.T); out.append(a.std())
    return out

variants = {"std = 0.01": lambda n: 0.01,
            "std = 1": lambda n: 1.0,
            "He: √(2/n)": lambda n: np.sqrt(2 / n)}
fig, ax = plt.subplots(figsize=(6.2, 3.5))
for (name, fn), c in zip(variants.items(), [PALETTE["data"], PALETTE["loss"], PALETTE["grad"]]):
    s = activation_std(fn)
    ax.semilogy(range(1, L + 1), s, color=c, lw=2, label=name)
    print(f"{name:12s} activation std at layer 40: {s[-1]:.2e}")
ax.set_xlabel("layer"); ax.set_ylabel("std of activations"); ax.legend()
plt.show()
std = 0.01   activation std at layer 40: 7.65e-39
std = 1      activation std at layer 40: 6.06e+41
He: √(2/n)   activation std at layer 40: 2.68e-01

20.6 Normalisation

Initialisation sets the scale at the start. Training changes weights, and the scale can drift. A normalisation layer fixes the scale at every step.

For a vector \(\mathbf{x}\in\mathbb{R}^d\) (one token’s features), LayerNorm subtracts the mean and divides by the standard deviation:

\[ \hat{\mathbf{x}}=\frac{\mathbf{x}-\mu}{\sqrt{\sigma^2+\epsilon}},\qquad\mu=\frac1d\sum_ix_i,\quad\sigma^2=\frac1d\sum_i(x_i-\mu)^2, \tag{20.3}\]

followed by a learned scale and shift, \(\gamma\odot\hat{\mathbf{x}}+\beta\). RMSNorm (used in Llama-style models, Chapter 32) skips the mean:

\[ \text{RMSNorm}(\mathbf{x})=\frac{\mathbf{x}}{\sqrt{\frac1d\sum_ix_i^2+\epsilon}}\odot\mathbf{g}. \tag{20.4}\]

Both make the output invariant to the scale of the input: \(\text{LN}(c\,\mathbf{x})=\text{LN}(\mathbf{x})\) for \(c>0\).

20.6.1 The backward pass of LayerNorm

LayerNorm is a function of the whole vector. For the output \(\hat{\mathbf{x}}\) with upstream gradient \(\hat{\mathbf{g}}=\partial L/\partial\hat{\mathbf{x}}\) (and \(\epsilon\to0\), no \(\gamma,\beta\)):

\[ \frac{\partial L}{\partial\mathbf{x}}=\frac{1}{\sigma}\Bigl(\hat{\mathbf{g}}-\overline{\hat{g}}\,\mathbf{1}-\overline{\hat{g}\odot\hat{x}}\;\hat{\mathbf{x}}\Bigr), \tag{20.5}\]

where overlines denote the mean over the \(d\) components. The gradient is projected so it has zero mean and no component along \(\hat{\mathbf{x}}\): the two directions the normalisation removes. We check it numerically (the habit of Chapters 1 and 18).

def ln_forward(x, eps=1e-12):
    mu = x.mean(); var = ((x - mu) ** 2).mean()
    return (x - mu) / np.sqrt(var + eps), np.sqrt(var + eps)

def ln_backward(x, g):
    xh, sigma = ln_forward(x)
    return (g - g.mean() - (g * xh).mean() * xh) / sigma

rng = np.random.default_rng(0)
x, g = rng.normal(size=8), rng.normal(size=8)
loss = lambda x: np.dot(g, ln_forward(x)[0])              # a scalar test loss
analytic = ln_backward(x, g)
numeric = np.array([(loss(x + 1e-6 * e) - loss(x - 1e-6 * e)) / 2e-6 for e in np.eye(8)])
print("max |analytic − numeric|:", np.abs(analytic - numeric).max())
print("scale invariance: LN(5x) == LN(x):", np.allclose(ln_forward(5 * x)[0], ln_forward(x)[0]))
max |analytic − numeric|: 5.434097616330291e-10
scale invariance: LN(5x) == LN(x): True

20.6.2 What normalisation buys

We repeat the 40-layer experiment with standard-normal weights (the bad setting) and add LayerNorm after each layer.

def run_net(use_ln):
    rng = np.random.default_rng(1)
    a = rng.normal(size=(64, 256)); out = []
    for _ in range(40):
        W = rng.normal(0, 1.0, size=(256, 256))           # deliberately too large
        a = np.maximum(0, a @ W.T)
        if use_ln:
            a = (a - a.mean(1, keepdims=True)) / np.sqrt(a.var(1, keepdims=True) + 1e-6)
        out.append(a.std())
    return out
fig, ax = plt.subplots(figsize=(6, 3.4))
ax.semilogy(run_net(False), color=PALETTE["loss"], lw=2, label="no normalisation")
ax.semilogy(run_net(True), color=PALETTE["grad"], lw=2, label="LayerNorm")
ax.set_xlabel("layer"); ax.set_ylabel("std of activations"); ax.legend()
plt.show()

Normalisation also changes the geometry of the loss. It removes sensitivity to the scale of each layer’s weights, which improves conditioning in practice. The precise reason is still debated. What we measure reliably is that deep networks train with larger learning rates and less careful initialisation when normalised.

20.7 Gradient clipping

Occasionally a batch produces a huge gradient. One huge step can destroy the model. Global-norm clipping rescales the whole gradient when its norm exceeds a threshold \(c\):

\[ \mathbf{g}\leftarrow\mathbf{g}\cdot\min\!\Bigl(1,\ \frac{c}{\lVert\mathbf{g}\rVert}\Bigr). \tag{20.6}\]

The direction is kept. Only the length is bounded.

from sklearn.datasets import load_digits
from sklearn.model_selection import train_test_split
D = load_digits()
Xtr, Xte, ytr, yte = train_test_split(D.data / 16.0, D.target, test_size=0.25,
                                      random_state=0, stratify=D.target)
Xt, yt = torch.tensor(Xtr, dtype=torch.float32), torch.tensor(ytr)

def train_clip(lr, clip=None, steps=100):
    torch.manual_seed(0)
    m = nn.Sequential(nn.Linear(64, 32), nn.ReLU(), nn.Linear(32, 32),
                      nn.ReLU(), nn.Linear(32, 10))
    opt = torch.optim.SGD(m.parameters(), lr=lr); hist = []
    for _ in range(steps):
        opt.zero_grad()
        loss = nn.functional.cross_entropy(m(Xt), yt); loss.backward()
        if clip:
            nn.utils.clip_grad_norm_(m.parameters(), clip)
        opt.step(); hist.append(loss.item())
    return hist

h_free, h_clip = train_clip(1.0), train_clip(1.0, clip=1.0)
fig, ax = plt.subplots(figsize=(5.8, 3.4))
ax.plot(h_free, color=PALETTE["loss"], lw=1.6, label="no clipping")
ax.plot(h_clip, color=PALETTE["grad"], lw=2, label="clip global norm to 1")
ax.set_xlabel("step"); ax.set_ylabel("training loss"); ax.legend()
plt.show()
print(f"no clipping: lowest loss {min(h_free):.3f}, final {h_free[-1]:.3f}")
print(f"clipping   : lowest loss {min(h_clip):.3f}, final {h_clip[-1]:.3f}")
no clipping: lowest loss 0.369, final 3.307
clipping   : lowest loss 0.132, final 0.132

Clipping is a safety rail, not a cure for a learning rate that is far too high. It bounds the size of an update but not the direction errors that come from curvature.

20.8 Failure modes

Exploding activations. Weights too large, or no normalisation in a deep network. Signs: nan loss in the first steps, gradient norm in the thousands.

Vanishing signal. Weights too small or saturating activations. The loss stays at its initial value (for 10 classes, \(\ln10=2.30\)). Chapter 11 showed a case.

Dead units. ReLUs with very negative pre-activations never recover (Chapter 10).

Normalisation at tiny batch size. BatchNorm computes statistics over the batch. With a batch of 2 they are noisy. LayerNorm and RMSNorm use one example only and avoid this.

Low precision. In 16-bit arithmetic, activations above about 65,000 overflow. Normalisation and loss scaling are needed (Chapter 34).

Stability depends on the largest curvature, which can change during training (a sudden “edge-of-stability” rise). A learning rate that worked at the start may not later. Warmup and decay (Chapter 19) manage this.

20.10 System connection

NoteWhat the system gained in this chapter

The system now understands when learning works. The step size must respect the steepest curvature (\(\eta<2/\lambda_{\max}\)). The speed is limited by the condition number. Initialisation and normalisation keep signal scale under control, and clipping bounds a single bad step.

This closes Part V. The system can learn: it has a loss, a gradient, an optimiser, and a theory of stability.

\[ x\to f_\theta(x)\to L\to\nabla_\theta L\to\theta'. \]

All the numbers so far came from data we treated as certain. Real data is noisy, and models must express doubt. Part VI develops the mathematics of uncertainty.

Chapter summary

  • A convex loss has no bad local minima. Neural-network losses are not convex.
  • GD on a quadratic is stable for \(\eta<2/\lambda_{\max}\) and needs about \(\kappa\) steps.
  • Saddles dominate in high dimension. Gradient descent escapes them slowly.
  • He initialisation: \(\text{Var}(w)=2/n_{\text{in}}\) for ReLU. Xavier: \(1/n\) (or \(2/(n_{\text{in}}+n_{\text{out}})\)).
  • LayerNorm and RMSNorm pin activation scale. Their output is scale-invariant.
  • Global-norm clipping bounds the step without changing the gradient direction.
