36  Vision Transformers

NoteKey ideas
  • A Vision Transformer (ViT) cuts an image into patches, embeds each patch as a token, and runs a standard Transformer encoder (Chapter 31). There is no convolution beyond the patch embedding.
  • Patch embedding is a linear map of the flattened patch. It equals a convolution with kernel size = stride = patch size.
  • A class token collects a summary for classification. Positional embeddings tell the model where each patch is.
  • Attention gives global interaction from the first layer, with few built-in assumptions. It needs more data than a CNN to learn locality.
  • Cost is \(O(N^2d)\) in the number of patches \(N\), so it grows quickly with resolution.

36.1 The system problem

Chapter 35 deepened the convolutional route for images. Chapter 30 gave attention, which was built for sequences. An image is a grid, not a sequence. Yet if it is cut into pieces, the grid becomes a sequence of tokens like any other.

36.3 Patches and patch embedding

Split an \(H\times W\) image with \(C\) channels into non-overlapping \(P\times P\) patches. There are \(N=HW/P^2\) of them. Flatten each to a vector of length \(P^2C\) and apply one linear map \(\mathbf{E}\in\mathbb{R}^{d\times P^2C}\):

\[ \mathbf{z}_i=\mathbf{E}\,\text{vec}(\text{patch}_i)+\mathbf{b},\qquad i=1,\dots,N. \tag{36.1}\]

Reshaping does the cutting (Chapter 6). The linear map is a layer of Chapter 9. Together they are one convolution (Chapter 12) with kernel size \(P\) and stride \(P\): each output position sees exactly one patch.

import torch, torch.nn as nn, torch.nn.functional as F
torch.manual_seed(0)
B, C, H, W, P, d = 2, 3, 16, 24, 4, 10
img = torch.randn(B, C, H, W)

# 1. reshape: (B, C, H, W) -> (B, N, P*P*C)
patches = (img.reshape(B, C, H // P, P, W // P, P)
              .permute(0, 2, 4, 3, 5, 1)                     # (B, H/P, W/P, P, P, C)
              .reshape(B, (H // P) * (W // P), P * P * C))
lin = nn.Linear(P * P * C, d)
z_linear = lin(patches)                                      # (B, N, d)

# 2. the same as a strided convolution
conv = nn.Conv2d(C, d, kernel_size=P, stride=P)
with torch.no_grad():                                        # copy the weights across layouts
    conv.weight.copy_(lin.weight.view(d, P, P, C).permute(0, 3, 1, 2))
    conv.bias.copy_(lin.bias)
z_conv = conv(img).flatten(2).transpose(1, 2)                # (B, N, d)
print("tokens:", z_linear.shape[1], " (", H // P, "×", W // P, ")")
print("linear-on-patches equals Conv2d(kernel = stride = P):", torch.allclose(z_linear, z_conv, atol=1e-5))
unf = F.unfold(img, P, stride=P)                         # PyTorch's own patch extraction
print("F.unfold gives (B, P·P·C, N):", tuple(unf.shape), "  N =", unf.shape[2])
tokens: 24  ( 4 × 6 )
linear-on-patches equals Conv2d(kernel = stride = P): True
F.unfold gives (B, P·P·C, N): (2, 48, 24)   N = 24

36.4 The class token and positions

After embedding, we have \(N\) tokens and no summary of the whole image. A learned class token \(\mathbf{z}_0\) is prepended. Through attention it can gather information from every patch. Its output after the last block is fed to the classifier.

Attention has no notion of position (Chapter 30), so we add positional embeddings \(\mathbf{p}_{i}\in\mathbb{R}^d\). In a basic ViT they are learned parameters, one per position. Nothing tells the model that patch 5 is next to patch 6 or above patch 9: the geometry must be learned.

The input to the encoder is

\[ \mathbf{Z}_0=\bigl[\mathbf{z}_{\text{cls}};\ \mathbf{z}_1;\ \dots;\ \mathbf{z}_{N}\bigr]+\bigl[\mathbf{p}_0;\ \mathbf{p}_1;\ \dots;\ \mathbf{p}_{N}\bigr]\in\mathbb{R}^{(N+1)\times d}. \tag{36.2}\]

The encoder is the block of Chapter 31, without the causal mask: every patch may attend to every other.

36.5 Cost: tokens and resolution

Attention builds an \(N\times N\) matrix per head per layer. Doubling the image side multiplies \(N\) by 4 and the attention cost by 16.

print(f"{'image':>10s} {'patch':>6s} {'tokens N':>9s} {'N² score entries':>18s} {'per layer, 12 heads, fp16':>26s}")
for side, P in [(224, 16), (384, 16), (224, 8), (512, 16), (1024, 16)]:
    N = (side // P) ** 2
    mb = 12 * N * N * 2 / 2 ** 20
    print(f"{side:4d}×{side:<4d} {P:6d} {N:9d} {N * N:18,d} {mb:22.0f} MiB")
     image  patch  tokens N   N² score entries  per layer, 12 heads, fp16
 224×224      16       196             38,416                      1 MiB
 384×384      16       576            331,776                      8 MiB
 224×224       8       784            614,656                     14 MiB

A \(1024\times1024\) image with \(16\times16\) patches has 4,096 tokens and needs about 400 MiB for one layer’s attention matrices (in this accounting). Higher resolution forces larger patches, windowed attention, or hierarchical designs.

36.6 A small ViT in PyTorch

We apply the ViT to the \(8\times8\) digits, with \(2\times2\) patches: \(N=16\) tokens. The model has width 48, 4 heads, 2 blocks.

import math
from sklearn.datasets import load_digits
from sklearn.model_selection import train_test_split
D = load_digits()
Xall, Xte, yall, yte = train_test_split(D.data / 16.0, D.target, test_size=0.25,
                                        random_state=0, stratify=D.target)
Xv = torch.tensor(Xte, dtype=torch.float32).view(-1, 1, 8, 8); yv = torch.tensor(yte)

class EncoderBlock(nn.Module):
    def __init__(self, d, h):
        super().__init__()
        self.h = h
        self.ln1, self.ln2 = nn.LayerNorm(d), nn.LayerNorm(d)
        self.qkv, self.o = nn.Linear(d, 3 * d), nn.Linear(d, d)
        self.mlp = nn.Sequential(nn.Linear(d, 2 * d), nn.GELU(), nn.Linear(2 * d, d))
    def forward(self, x):
        B, T, d = x.shape
        q, k, v = self.qkv(self.ln1(x)).chunk(3, dim=-1)
        sp = lambda t: t.view(B, T, self.h, d // self.h).transpose(1, 2)
        q, k, v = sp(q), sp(k), sp(v)
        A = (q @ k.transpose(-1, -2) / math.sqrt(d // self.h)).softmax(-1)     # (B, h, T, T), no mask
        x = x + self.o((A @ v).transpose(1, 2).reshape(B, T, d))
        return x + self.mlp(self.ln2(x)), A

class ViT(nn.Module):
    def __init__(self, patch=2, d=48, heads=4, layers=2, classes=10, side=8):
        super().__init__()
        n = (side // patch) ** 2
        self.embed = nn.Conv2d(1, d, patch, stride=patch)               # patch embedding
        self.cls = nn.Parameter(torch.zeros(1, 1, d))
        self.pos = nn.Parameter(torch.randn(1, n + 1, d) * 0.02)
        self.blocks = nn.ModuleList([EncoderBlock(d, heads) for _ in range(layers)])
        self.ln, self.head = nn.LayerNorm(d), nn.Linear(d, classes)
    def forward(self, x, return_attn=False):
        t = self.embed(x).flatten(2).transpose(1, 2)                    # (B, N, d)
        t = torch.cat([self.cls.expand(len(t), -1, -1), t], dim=1) + self.pos
        attn = []
        for b in self.blocks:
            t, A = b(t); attn.append(A)
        out = self.head(self.ln(t[:, 0]))                               # class token only
        return (out, attn) if return_attn else out

class SmallCNN(nn.Module):
    def __init__(self):
        super().__init__()
        self.c, self.l = nn.Conv2d(1, 8, 3), nn.Linear(72, 10)
    def forward(self, x):
        return self.l(F.max_pool2d(F.relu(self.c(x)), 2).flatten(1))

def train_eval(model, n, steps=600, lr=3e-3, seed=0):
    rng = np.random.default_rng(seed); idx = rng.choice(len(Xall), n, replace=False)
    X = torch.tensor(Xall[idx], dtype=torch.float32).view(-1, 1, 8, 8); y = torch.tensor(yall[idx])
    opt = torch.optim.AdamW(model.parameters(), lr=lr, weight_decay=0.01)
    g = torch.Generator().manual_seed(seed)
    for _ in range(steps):
        i = torch.randint(0, n, (min(128, n),), generator=g)
        opt.zero_grad(); F.cross_entropy(model(X[i]), y[i]).backward(); opt.step()
    model.eval()
    with torch.no_grad():
        return (model(Xv).argmax(1) == yv).float().mean().item()

torch.manual_seed(0)
vit = ViT()
print("ViT parameters:", sum(p.numel() for p in vit.parameters()),
      "  CNN parameters:", sum(p.numel() for p in SmallCNN().parameters()))
acc_full = train_eval(vit, len(Xall))
print(f"ViT test accuracy with all {len(Xall)} training images: {acc_full:.3f}")

Did it learn the geometry? The positional embeddings were initialised randomly and nothing told the model about neighbours. We check whether patches that are close in the image have similar learned embeddings. If so, similarity should fall with distance.

pos = vit.pos.detach()[0, 1:]                                  # (16, d)
posn = pos / pos.norm(dim=1, keepdim=True)
S = (posn @ posn.T).numpy()
coords = np.array([(r, c) for r in range(4) for c in range(4)])
dist = np.linalg.norm(coords[:, None] - coords[None], axis=-1)
iu = np.triu_indices(16, 1)
corr = np.corrcoef(S[iu], dist[iu])[0, 1]
fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(9.5, 3.6))
im = ax1.imshow(S, cmap="RdBu_r", vmin=-1, vmax=1); ax1.grid(False)
ax1.set_xlabel("patch"); ax1.set_ylabel("patch")
ax2.scatter(dist[iu], S[iu], s=14, color=PALETTE["model"], alpha=0.7)
ax2.set_xlabel("distance between patches (grid units)"); ax2.set_ylabel("cosine similarity")
plt.tight_layout(); plt.show()

36.8 Changing the resolution

A ViT trained at one resolution has a fixed number of positional embeddings. To run it on a larger image, the grid of embeddings is interpolated to the new grid size (bilinear or bicubic), treating it as a small image with \(d\) channels.

def resize_pos(pos, old_g, new_g):
    """pos: (1, 1 + old_g², d) -> (1, 1 + new_g², d); the class position is kept."""
    cls, grid = pos[:, :1], pos[:, 1:]
    d = grid.shape[-1]
    g = grid.reshape(1, old_g, old_g, d).permute(0, 3, 1, 2)            # (1, d, g, g)
    g = F.interpolate(g, size=(new_g, new_g), mode="bicubic", align_corners=False)
    return torch.cat([cls, g.permute(0, 2, 3, 1).reshape(1, new_g * new_g, d)], dim=1)

new_pos = resize_pos(vit.pos.detach(), 4, 8)
print("positional embeddings:", tuple(vit.pos.shape), "->", tuple(new_pos.shape))
print("neighbouring patches remain similar after interpolation:",
      F.cosine_similarity(new_pos[0, 1], new_pos[0, 2], dim=0).item() >
      F.cosine_similarity(new_pos[0, 1], new_pos[0, 40], dim=0).item())
positional embeddings: (1, 17, 48) -> (1, 65, 48)

36.10 Failure modes

Data hunger. Without locality and translation structure built in, a ViT trained on little data under-performs a CNN (Figure 36.3). Large-scale pre-training, strong augmentation, and regularisation close the gap.

Resolution change. Positional embeddings must be interpolated. A model run at another resolution without adaptation sees patches at scales and positions it did not learn.

Quadratic cost. Attention grows as \(N^2\). High resolution needs larger patches, windowed or hierarchical attention, or token pruning.

Patch size trade-off. Large patches lose fine detail within a patch. Small patches mean more tokens and cost.

Class token versus pooling. Some designs drop the class token and average the patch outputs. Both work. They differ in what is trained to hold the summary.

Position encoding shortcuts. A model with learned absolute positions can overfit to absolute locations. Augmentation by shifts and crops is important. In our small model the learned positions carried no visible grid structure (Figure 36.5); large models trained on large datasets do learn it, and fixed 2D sinusoidal embeddings provide it from the start.

36.12 System connection

NoteWhat the system gained in this chapter

Systems A and C are now joined: an image is a sequence of patch tokens, and the Transformer of Chapters 30–31 reads it. Everything specific to images lies in one reshape and one linear map. The model’s global reach comes at the price of data and quadratic cost.

Classification outputs one label for an image. Many tasks output a set of objects with locations. Chapter 37 shows how.

Chapter summary

  • A ViT: patchify → linear embed → add class token and positions → Transformer encoder → classifier on the class token.
  • Patch embedding equals a convolution with kernel = stride = \(P\).
  • \(N=HW/P^2\) tokens. Attention cost is \(O(N^2d)\).
  • Few built-in assumptions give flexibility and data hunger.
  • Positional embeddings are learned. They can be interpolated for a new resolution.
  • On small data, a CNN beats a ViT by a wide margin. With more data the gap narrows.
