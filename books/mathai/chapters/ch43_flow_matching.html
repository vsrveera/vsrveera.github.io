43  Flow Matching

NoteKey ideas
  • A flow moves points along a velocity field: \(\dot{\mathbf{x}}=\mathbf{v}(\mathbf{x},t)\). Integrating it from noise at \(t=0\) to data at \(t=1\) generates samples.
  • Flow matching trains \(\mathbf{v}_\theta\) by regression: draw a noise point \(\mathbf{x}_0\) and a data point \(\mathbf{x}_1\), move to \(\mathbf{x}_t=(1-t)\mathbf{x}_0+t\mathbf{x}_1\), and regress onto \(\mathbf{x}_1-\mathbf{x}_0\).
  • This simple conditional target has the same gradient as the loss for the true marginal velocity field.
  • Sampling is numerical integration of an ordinary differential equation (ODE). Euler is first order. Heun is second order. Straighter paths need fewer steps.
  • Diffusion’s DDIM sampler is a special case of such an ODE.

43.1 The system problem

Diffusion (Chapter 41) builds a path from data to noise from a noise schedule, derives a reverse process through Bayes’ rule, and trains on a weighted noise-prediction loss. DDIM shows that sampling can be deterministic: a trajectory from noise to data. That suggests asking for the trajectories directly.

Can we learn the path from noise to data as a velocity field, with a plain regression loss, and then simply integrate it?

43.2 Flows and ODEs

A velocity field \(\mathbf{v}(\mathbf{x},t)\) assigns to every position and time a direction and speed. Place a point at \(\mathbf{x}(0)=\mathbf{x}_0\) and let it drift:

\[ \frac{d\mathbf{x}}{dt}=\mathbf{v}\bigl(\mathbf{x}(t),t\bigr),\qquad t\in[0,1]. \tag{43.1}\]

The solution is a trajectory. Because \(\mathbf{v}\) is a function of position, two trajectories never cross, and each starting point has exactly one path. The map from \(\mathbf{x}(0)\) to \(\mathbf{x}(1)\) is the flow. If the starting points are noise, the end points are samples; the field is chosen so that they follow the data distribution.

43.2.1 Numerical integration

An ODE is solved by small steps. Euler’s method follows the tangent for a step \(\Delta=1/N\):

\[ \mathbf{x}_{t+\Delta}=\mathbf{x}_t+\Delta\,\mathbf{v}(\mathbf{x}_t,t). \tag{43.2}\]

Heun’s method (a second-order method) takes the tangent, looks at the tangent at the predicted end point, and uses the average:

\[ \tilde{\mathbf{x}}=\mathbf{x}_t+\Delta\,\mathbf{v}(\mathbf{x}_t,t),\qquad \mathbf{x}_{t+\Delta}=\mathbf{x}_t+\frac\Delta2\Bigl[\mathbf{v}(\mathbf{x}_t,t)+\mathbf{v}(\tilde{\mathbf{x}},t+\Delta)\Bigr]. \tag{43.3}\]

Euler’s error per unit time falls like \(\Delta\) (first order). Heun’s falls like \(\Delta^2\) at the cost of two field evaluations per step. We check on \(\dot{x}=-x\), whose exact solution from \(x(0)=1\) is \(x(t)=e^{-t}\).

def integrate(method, N):
    x, dt, f = 1.0, 1.0 / N, lambda x, t: -x
    for k in range(N):
        t = k * dt
        if method == "euler":
            x = x + dt * f(x, t)
        else:
            xp = x + dt * f(x, t)
            x = x + dt / 2 * (f(x, t) + f(xp, t + dt))
    return x
Ns = np.array([2, 4, 8, 16, 32, 64, 128])
err_e = [abs(integrate("euler", n) - math.exp(-1)) for n in Ns]
err_h = [abs(integrate("heun", n) - math.exp(-1)) for n in Ns]
fig, ax = plt.subplots(figsize=(5.8, 3.5))
ax.loglog(1 / Ns, err_e, "o-", color=PALETTE["loss"], label="Euler")
ax.loglog(1 / Ns, err_h, "o-", color=PALETTE["grad"], label="Heun")
ax.set_xlabel("step size Δ"); ax.set_ylabel("error at t = 1"); ax.legend()
plt.show()
slope = lambda e: np.polyfit(np.log(1 / Ns), np.log(e), 1)[0]
print(f"fitted orders: Euler {slope(err_e):.2f}, Heun {slope(err_h):.2f}")

43.3 Learning the field: flow matching

We want \(\mathbf{v}_\theta\) such that integrating it from \(\mathbf{x}_{0}\sim\mathcal{N}(\mathbf{0},\mathbf{I})\) gives \(\mathbf{x}_{1}\sim p_{\text{data}}\). There are many such fields. Choose the simplest path: for a noise point \(\mathbf{x}_0\) and a data point \(\mathbf{x}_1\), move on the straight line

\[ \mathbf{x}_t=(1-t)\,\mathbf{x}_0+t\,\mathbf{x}_1,\qquad \frac{d\mathbf{x}_t}{dt}=\mathbf{x}_1-\mathbf{x}_0. \tag{43.4}\]

The velocity along this particular path is the constant \(\mathbf{x}_1-\mathbf{x}_0\). The conditional flow matching loss regresses the network onto it:

\[ \mathcal{L}_{\text{CFM}}(\theta)=\mathbb{E}_{t,\ \mathbf{x}_0,\ \mathbf{x}_1}\Bigl[\bigl\lVert\mathbf{v}_\theta(\mathbf{x}_t,t)-(\mathbf{x}_1-\mathbf{x}_0)\bigr\rVert^{2}\Bigr]. \tag{43.5}\]

43.3.1 Why this works

A given point \(\mathbf{x}\) at time \(t\) can be reached from many \((\mathbf{x}_0,\mathbf{x}_1)\) pairs, with different velocities \(\mathbf{x}_1-\mathbf{x}_0\). A network sees only \((\mathbf{x},t)\). A squared-error regression has the conditional mean as its minimiser (Chapter 14):

\[ \mathbf{v}^*(\mathbf{x},t)=\mathbb{E}\bigl[\mathbf{x}_1-\mathbf{x}_0\ \big|\ \mathbf{x}_t=\mathbf{x}\bigr]. \tag{43.6}\]

This is exactly the marginal velocity field: the field whose flow carries the distribution of \(\mathbf{x}_t\) (noise at \(t=0\), data at \(t=1\)) correctly in time (by the continuity equation, whose derivation we omit). So regressing on the easy per-pair target recovers the field that transports \(p_0\) to \(p_1\). The loss Equation 43.5 and the loss of the marginal field differ only by a constant, and have the same gradient with respect to \(\theta\).

43.3.2 An exact check in one dimension

Take data concentrated at two points, \(x_{1}\in\{-2,+2\}\) with equal probability, and \(x_{0}\sim\mathcal{N}(0,1)\). Given \(x_t=x\), we have \(x_0=(x-tx_1)/(1-t)\), so the velocity is \((x_1-x)/(1-t)\). The only unknown is \(\mathbb{E}[x_{1}\mid x_t=x]\), which Bayes gives in closed form: the likelihood of \(x\) given \(x_1\) is \(\mathcal{N}(x;\,t\,x_1,(1-t)^2)\). Hence

\[ v^*(x,t)=\frac{\mathbb{E}[x_{1}\mid x]-x}{1-t},\qquad \mathbb{E}[x_{1}\mid x]=2\tanh\!\Bigl(\frac{2tx}{(1-t)^2}\Bigr). \tag{43.7}\]

We train a small network by Equation 43.5 and compare it with Equation 43.7.

import torch, torch.nn as nn, torch.nn.functional as F
torch.manual_seed(0)

class VNet(nn.Module):
    def __init__(self, d_in=1, h=128):
        super().__init__()
        self.net = nn.Sequential(nn.Linear(d_in + 1, h), nn.SiLU(), nn.Linear(h, h), nn.SiLU(),
                                 nn.Linear(h, h), nn.SiLU(), nn.Linear(h, d_in))
    def forward(self, x, t):
        return self.net(torch.cat([x, t[:, None]], dim=1))

43.4 Flow matching on a 2D distribution

We train the same kind of model on the two-moons data used in Chapter 41, with the same network size. Sampling now integrates the ODE from noise.

from sklearn.datasets import make_moons
def sample_data(n, seed=None):
    X, _ = make_moons(n, noise=0.06, random_state=seed)
    return torch.tensor((X - np.array([0.5, 0.25])) * 2.0, dtype=torch.float32)

torch.manual_seed(0)
net = VNet(2, h=128); opt = torch.optim.Adam(net.parameters(), lr=2e-3)
t0 = time.time(); hist = []
for step in range(20000):
    x1 = sample_data(256); x0 = torch.randn_like(x1); t = torch.rand(256)
    xt = (1 - t[:, None]) * x0 + t[:, None] * x1
    loss = F.mse_loss(net(xt, t), x1 - x0)
    opt.zero_grad(); loss.backward(); opt.step(); hist.append(loss.item())
print(f"trained in {time.time() - t0:.0f} s; loss {np.mean(hist[:50]):.3f} -> {np.mean(hist[-500:]):.3f}")

@torch.no_grad()
def integrate_net(n, steps, method="euler", seed=0, return_path=False):
    g = torch.Generator().manual_seed(seed)
    x = torch.randn(n, 2, generator=g); dt = 1.0 / steps; path = [x.clone()]; nfe = 0
    for k in range(steps):
        t = torch.full((n,), k * dt)
        v = net(x, t); nfe += 1
        if method == "euler":
            x = x + dt * v
        else:
            xp = x + dt * v
            v2 = net(xp, t + dt); nfe += 1
            x = x + dt / 2 * (v + v2)
        path.append(x.clone())
    return (x, path, nfe) if return_path else (x, nfe)

def sliced_wasserstein(a, b, n_proj=200, seed=0):
    g = np.random.default_rng(seed)
    dirs = g.normal(size=(n_proj, 2)); dirs /= np.linalg.norm(dirs, axis=1, keepdims=True)
    return np.abs(np.sort(a.numpy() @ dirs.T, axis=0) - np.sort(b.numpy() @ dirs.T, axis=0)).mean()

43.5 Relation to diffusion

Flow matching with the straight path is a special case of a general recipe: choose any path \(\mathbf{x}_t=a_{t}\mathbf{x}_1+b_{t}\mathbf{x}_0\), and regress on its velocity \(\dot a_{t}\mathbf{x}_1+\dot b_{t}\mathbf{x}_0\). A diffusion model uses a different path (\(a_t=\sqrt{\bar\alpha_t}\), \(b_t=\sqrt{1-\bar\alpha_t}\), with \(\mathbf{x}_0\) as noise) and a different parametrisation. The quantities are interchangeable. For the straight path, with \(\mathbf{x}_0=\boldsymbol\epsilon\):

\[ \mathbf{v}=\mathbf{x}_1-\boldsymbol\epsilon,\qquad \hat{\mathbf{x}}_1=\mathbf{x}_t+(1-t)\,\mathbf{v},\qquad \hat{\boldsymbol\epsilon}=\mathbf{x}_t-t\,\mathbf{v}. \tag{43.8}\]

x1 = torch.randn(5, 2); eps = torch.randn(5, 2); t = 0.37
xt = (1 - t) * eps + t * x1
v = x1 - eps
print("x1 recovered from v:", torch.allclose(xt + (1 - t) * v, x1, atol=1e-6))
print("ε  recovered from v:", torch.allclose(xt - t * v, eps, atol=1e-6))
x1 recovered from v: True
ε  recovered from v: True

The DDIM sampler of Chapter 41 is an Euler discretisation of an ODE of this family (the “probability-flow ODE” of the diffusion process). The difference between the methods is the path and the training weights, not a different kind of model.

An important contrast: DDPM sampling is a stochastic differential equation (noise is injected at each step). The flow is deterministic. Given the starting noise, the output is fixed. That allows exact likelihoods (by integrating the divergence of the field) and clean interpolation between samples.

43.6 Production

An adaptive solver can integrate the learned field accurately. We use SciPy’s RK45 as a reference, and check that our 100-step Euler is close.

from scipy.integrate import solve_ivp
n = 200
g = torch.Generator().manual_seed(11)
x_init = torch.randn(n, 2, generator=g)

def rhs(t, y):
    x = torch.tensor(y.reshape(n, 2), dtype=torch.float32)
    with torch.no_grad():
        return net(x, torch.full((n,), float(t))).numpy().ravel()

sol = solve_ivp(rhs, (0.0, 1.0), x_init.numpy().ravel().astype(np.float64), method="RK45", rtol=1e-4, atol=1e-6)
x_ref = sol.y[:, -1].reshape(n, 2)
print(f"RK45 used {sol.nfev} function evaluations (each on the whole batch)")
for steps in (4, 16, 100):
    x = x_init.clone(); dt = 1.0 / steps
    with torch.no_grad():
        for k in range(steps):
            x = x + dt * net(x, torch.full((n,), k * dt))
    print(f"Euler, {steps:3d} steps: mean distance to the RK45 solution {np.linalg.norm(x.numpy() - x_ref, axis=1).mean():.4f}")

43.8 Failure modes

Too few steps. With one Euler step, every noise point moves along the initial field, which points towards the mean of the data. The result is a blob at the centre. The error of Euler is first order (Figure 43.2). Heun and other higher-order solvers help.

Curved flows. The marginal field is generally not straight, even though each conditional path is. Where the data has several modes, the field must curve to split the noise between them. Re-training on the model’s own pairs (“reflow”) straightens the paths and allows fewer steps.

Time sampling. Sampling \(t\) uniformly in training may spend effort on times where the task is easy. Other time distributions or loss weights help.

Data scale. The straight path assumes data and noise have comparable scales. Standardise the data.

Stiffness. Where the field changes rapidly (near the end for sharp modes), a fixed step size is inaccurate. Adaptive solvers or non-uniform time grids are used.

Conditioning. As in Chapter 42, guidance is applied by combining conditional and unconditional velocities.

43.10 System connection

NoteWhat the system gained in this chapter

The generative systems now share a single view. Generation is transport: a velocity field carries simple noise to complex data. Training is a regression on a velocity (a squared error, Chapter 14). Sampling is numerical integration of an ODE (Euler, Heun). Diffusion models are the same idea with a particular path and parametrisation.

All the pieces of the book’s mathematics have now appeared in at least one modern system. The last chapter puts them together.

Chapter summary

  • A flow integrates \(d\mathbf{x}/dt=\mathbf{v}(\mathbf{x},t)\). Trajectories do not cross.
  • Euler has first-order error and Heun second-order.
  • Flow matching: \(\mathbf{x}_t=(1-t)\mathbf{x}_0+t\mathbf{x}_1\), target \(\mathbf{x}_1-\mathbf{x}_0\), squared-error loss.
  • The regression minimiser is the marginal velocity \(\mathbb{E}[\mathbf{x}_1-\mathbf{x}_{0}\mid\mathbf{x}_t]\).
  • Velocity, \(\hat{\mathbf{x}}_1\), and \(\hat{\boldsymbol\epsilon}\) are interchangeable parametrisations.
  • Fewer steps need straighter paths and better solvers.
