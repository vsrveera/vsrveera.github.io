15  Information as a Mathematical Quantity

NoteKey ideas
  • The information in an event of probability \(p\) is \(-\log p\). Rare events carry more.
  • Entropy \(H(p)\) is the average information: the uncertainty of a distribution.
  • Cross-entropy \(H(p,q)\) is the average cost of describing data from \(p\) with a code built for \(q\).
  • KL divergence \(D_{\text{KL}}(p\Vert q)=H(p,q)-H(p)\) is the extra cost. It is never negative, and not symmetric.
  • Mutual information measures how much knowing one variable tells about another.
  • Perplexity is \(e^{\text{cross-entropy}}\): the effective number of equally likely choices.

15.1 The system problem

Chapter 14 used cross-entropy as a loss without saying what it is. Chapter 13 compared points. We now need to compare distributions: the one the model predicts and the one the world follows.

How do we measure surprise, and how far one distribution is from another?

This chapter is also the bridge from measurement to probability. It contains a short primer on the probability that we need now. Part VI develops the full theory.

15.2 A short probability primer

This section gives only what is needed here and in Chapters 19 and 20. Chapter 21 gives the full treatment.

A distribution over a finite set assigns a probability \(p(x)\ge0\) to each outcome \(x\), with \(\sum_xp(x)=1\).

The expectation of a function \(f\) of the outcome is the probability-weighted average:

\[ \mathbb{E}[f(X)]=\sum_xp(x)\,f(x). \tag{15.1}\]

Two facts will be used often.

  1. Linearity. \(\mathbb{E}[aX+bY]=a\,\mathbb{E}[X]+b\,\mathbb{E}[Y]\), always.
  2. Variance. \(\text{Var}(X)=\mathbb{E}[(X-\mu)^2]=\mathbb{E}[X^2]-\mu^2\), where \(\mu=\mathbb{E}[X]\). For independent \(X,Y\): \(\text{Var}(X+Y)=\text{Var}(X)+\text{Var}(Y)\).
rng = np.random.default_rng(0)
vals = np.arange(1, 7); p = np.ones(6) / 6                  # one fair die
mean = np.sum(p * vals)
var = np.sum(p * vals ** 2) - mean ** 2
print(f"one die: E = {mean:.3f}, Var = {var:.3f}")

rolls = rng.integers(1, 7, size=(200_000, 2))               # two independent dice
total = rolls.sum(axis=1)
print(f"sum of two (simulated): E = {total.mean():.3f} (expect {2 * mean:.3f}), "
      f"Var = {total.var():.3f} (expect {2 * var:.3f})")
one die: E = 3.500, Var = 2.917
sum of two (simulated): E = 6.999 (expect 7.000), Var = 5.805 (expect 5.833)

15.3 Surprise: information content

How surprised are we by an event of probability \(p\)? A certain event (\(p=1\)) carries no surprise. A rare event carries a lot. Independent events should add: the surprise of “A and B” is the surprise of A plus the surprise of B. Since probabilities of independent events multiply, we need a function \(I\) with

\[ I(p\,q)=I(p)+I(q). \tag{15.2}\]

The logarithm has this property. Requiring also that \(I\) is continuous and decreasing in \(p\) leaves one family:

\[ I(p)=-\log p. \tag{15.3}\]

The base of the logarithm fixes the unit. Base 2 gives bits. Base \(e\) gives nats. One fair coin flip carries \(-\log_{2}\frac12=1\) bit. One roll of a fair die carries \(\log_26\approx2.58\) bits.

15.4 Entropy: average surprise

The entropy of a distribution is its expected information:

\[ H(p)=-\sum_xp(x)\log p(x). \tag{15.4}\]

It is the uncertainty of the distribution. It is also the average number of bits an ideal code needs per outcome. We use \(0\log0=0\).

def entropy(p, base=2):
    p = np.asarray(p, dtype=float)
    nz = p > 0                                         # convention 0 log 0 = 0
    return float(-np.sum(p[nz] * np.log(p[nz])) / np.log(base)) + 0.0

ps = np.linspace(0, 1, 201)
H = [entropy([q, 1 - q]) for q in ps]
fig, ax = plt.subplots(figsize=(5.5, 3.2))
ax.plot(ps, H, color=PALETTE["model"], lw=2)
ax.set_xlabel("probability of heads p"); ax.set_ylabel("entropy (bits)")
plt.show()
for dist in ([0.5, 0.5], [0.9, 0.1], [1/6] * 6, [1.0, 0, 0]):
    print(f"H({np.round(dist, 2)}) = {entropy(dist):.3f} bits")
H([0.5 0.5]) = 1.000 bits
H([0.9 0.1]) = 0.469 bits
H([0.17 0.17 0.17 0.17 0.17 0.17]) = 2.585 bits
H([1. 0. 0.]) = 0.000 bits

Among distributions on \(K\) outcomes, the uniform one has the largest entropy, \(\log K\). We prove this below.

15.5 Cross-entropy and KL divergence

Suppose the data follow \(p\), but our model says \(q\). We build a code from \(q\): it gives outcome \(x\) a codeword of length \(-\log q(x)\). The average length for data from \(p\) is the cross-entropy:

\[ H(p,q)=-\sum_xp(x)\log q(x). \tag{15.5}\]

The KL divergence (relative entropy) is the extra cost over the best possible code:

\[ D_{\text{KL}}(p\Vert q)=\sum_xp(x)\log\frac{p(x)}{q(x)}=H(p,q)-H(p). \tag{15.6}\]

TipDerivation: KL divergence is never negative (Gibbs’ inequality)

We use Jensen’s inequality for the concave function \(\log\): \(\mathbb{E}[\log X]\le\log\mathbb{E}[X]\). Take \(X=q(x)/p(x)\) with \(x\sim p\):

\[ -D_{\text{KL}}(p\Vert q)=\sum_xp(x)\log\frac{q(x)}{p(x)}\le\log\sum_xp(x)\frac{q(x)}{p(x)}=\log\sum_xq(x)\le\log1=0. \]

So \(D_{\text{KL}}(p\Vert q)\ge0\), with equality only if \(p=q\). \(\blacksquare\)

Consequence. Take \(q\) uniform: \(D_{\text{KL}}(p\Vert u)=\log K-H(p)\ge0\), so \(H(p)\le\log K\).

Three properties to remember:

  • Not symmetric. \(D_{\text{KL}}(p\Vert q)\ne D_{\text{KL}}(q\Vert p)\) in general. It is not a distance.
  • Infinite if \(q(x)=0\) where \(p(x)>0\). A model that rules out something that happens is infinitely wrong.
  • Minimising cross-entropy over \(q\) is the same as minimising KL, because \(H(p)\) does not depend on \(q\).
def kl(p, q, base=2):
    p, q = np.asarray(p, float), np.asarray(q, float)
    nz = p > 0
    if np.any(q[nz] == 0):
        return np.inf
    return np.sum(p[nz] * np.log(p[nz] / q[nz])) / np.log(base)

p = np.array([0.9, 0.1]); q = np.array([0.5, 0.5])
print(f"KL(p||q) = {kl(p, q):.3f} bits     KL(q||p) = {kl(q, p):.3f} bits   (asymmetric)")
print(f"H(p) + KL(p||q) = {entropy(p) + kl(p, q):.3f}   cross-entropy H(p,q) = "
      f"{-np.sum(p * np.log2(q)):.3f}")
print("support mismatch:", kl([0.5, 0.5], [1.0, 0.0]))
KL(p||q) = 0.531 bits     KL(q||p) = 0.737 bits   (asymmetric)
H(p) + KL(p||q) = 1.000   cross-entropy H(p,q) = 1.000
support mismatch: inf

15.5.1 Cross-entropy as the classification loss

For a labelled example the “true distribution” is a one-hot vector \(\mathbf{y}\) with \(1\) at the true class \(c\). Then \(H(\mathbf{y},\mathbf{q})=-\sum_ky_{k}\ln q_k=-\ln q_c\). This is exactly the cross-entropy loss of Chapter 14. The entropy of a one-hot distribution is \(0\), so the loss equals the KL divergence from the truth to the prediction.

We check it with a classifier on the digits.

from sklearn.datasets import load_digits
from sklearn.linear_model import LogisticRegression
from sklearn.metrics import log_loss
from sklearn.model_selection import train_test_split

D = load_digits()
Xtr, Xte, ytr, yte = train_test_split(D.data / 16.0, D.target, test_size=0.25,
                                      random_state=0, stratify=D.target)
clf = LogisticRegression(max_iter=2000).fit(Xtr, ytr)
P = clf.predict_proba(Xte)                                   # (N, 10) predicted q

ce = -np.mean(np.log(P[np.arange(len(yte)), yte]))           # mean of -ln q_c
print(f"cross-entropy (nats): {ce:.4f}   sklearn log_loss: {log_loss(yte, P):.4f}")
print(f"perplexity e^CE = {np.exp(ce):.3f}  (about this many classes 'in doubt')")

counts = np.bincount(ytr, minlength=10) / len(ytr)
print(f"entropy of the label distribution: {entropy(counts):.3f} bits "
      f"(maximum log2 10 = {np.log2(10):.3f})")
cross-entropy (nats): 0.1565   sklearn log_loss: 0.1565
perplexity e^CE = 1.169  (about this many classes 'in doubt')
entropy of the label distribution: 3.322 bits (maximum log2 10 = 3.322)

15.6 Mutual information

Two variables \(X,Y\) are independent if \(p(x,y)=p(x)p(y)\). Mutual information measures how far they are from independence:

\[ I(X;Y)=D_{\text{KL}}\bigl(p(x,y)\,\Vert\,p(x)p(y)\bigr)=H(X)+H(Y)-H(X,Y). \tag{15.7}\]

It is \(0\) for independent variables. It is at most \(\min(H(X),H(Y))\). It is symmetric.

We estimate how much each pixel of a digit tells about its class. Each pixel is binarised (on if brightness \(>8\)).

from sklearn.metrics import mutual_info_score
Xbin = (D.data > 8).astype(int)                              # (1797, 64)
mi = np.array([mutual_info_score(D.target, Xbin[:, j]) for j in range(64)]) / np.log(2)
fig, ax = plt.subplots(figsize=(4.4, 3.8))
im = ax.imshow(mi.reshape(8, 8), cmap="viridis")
plt.colorbar(im, ax=ax, label="bits"); ax.set_xticks([]); ax.set_yticks([]); ax.grid(False)
plt.show()
print(f"max pixel MI: {mi.max():.3f} bits;  H(class) = {np.log2(10):.2f} bits")
max pixel MI: 0.449 bits;  H(class) = 3.32 bits

One pixel gives well under one bit about a class that needs \(3.3\) bits. A classifier must combine many pixels.

15.7 Perplexity: a language model’s score

For a model that predicts a sequence of symbols, the average cross-entropy per symbol is the standard score. Its exponential is the perplexity:

\[ \text{PPL}=\exp\!\Bigl(-\frac1N\sum_{t=1}^{N}\ln q(x_{t}\mid\text{context})\Bigr). \tag{15.8}\]

Read it as the effective branching factor: a model with perplexity 8 is as uncertain as a fair 8-sided die at every step.

We build the smallest language models: character models for a short English text (the Zen of Python). We compare a uniform model, a unigram model, and bigram models with add-\(\alpha\) smoothing. Models are fitted on 70% of the text and scored on the remaining 30%.

import io, codecs, contextlib
with contextlib.redirect_stdout(io.StringIO()):          # silence the import
    import this
text = codecs.decode(this.s, "rot13").lower()
text = "".join(ch if ch.isalpha() else " " for ch in text)
text = " ".join(text.split())                             # letters and single spaces
alphabet = sorted(set(text)); V = len(alphabet)
idx = {c: i for i, c in enumerate(alphabet)}
ids = np.array([idx[c] for c in text])
cut = int(0.7 * len(ids)); train, test = ids[:cut], ids[cut:]
print(f"{len(ids)} characters, alphabet size {V}; train {len(train)}, test {len(test)}")

def unigram_ppl(alpha):
    c = np.bincount(train, minlength=V) + alpha
    q = c / c.sum()
    return np.exp(-np.mean(np.log(q[test])))

def bigram_ppl(alpha):
    C = np.full((V, V), alpha)
    np.add.at(C, (train[:-1], train[1:]), 1)             # count transitions
    Q = C / C.sum(axis=1, keepdims=True)                 # P(next | previous)
    return np.exp(-np.mean(np.log(Q[test[:-1], test[1:]])))

print(f"{'model':28s} {'test perplexity':>16s}")
print(f"{'uniform':28s} {V:16.2f}")
print(f"{'unigram (alpha = 1)':28s} {unigram_ppl(1):16.2f}")
for a in [0.05, 0.3, 1.0]:
    print(f"{f'bigram (alpha = {a})':28s} {bigram_ppl(a):16.2f}")
823 characters, alphabet size 25; train 576, test 247
model                         test perplexity
uniform                                 25.00
unigram (alpha = 1)                     16.47
bigram (alpha = 0.05)                   13.30
bigram (alpha = 0.3)                    12.10
bigram (alpha = 1.0)                    13.02

Two lessons stand out. Using context lowers the perplexity. And the smoothing constant \(\alpha\) matters: a bigram never seen in training gets probability \(0\) without smoothing, and the cross-entropy would be infinite.

15.8 Estimating entropy from data

We rarely know \(p\). We estimate it from counts, and then apply Equation 15.4. This plug-in estimate is biased: with few samples it underestimates the entropy, because rare outcomes are missed.

rng = np.random.default_rng(0)
ns = [8, 16, 32, 64, 128, 512, 2000]
est = []
for n in ns:
    vals = []
    for _ in range(300):
        c = np.bincount(rng.integers(0, 8, n), minlength=8) / n
        vals.append(entropy(c))
    est.append(np.mean(vals))
fig, ax = plt.subplots(figsize=(5.8, 3.3))
ax.semilogx(ns, est, "o-", color=PALETTE["loss"])
ax.axhline(3, ls="--", color=PALETTE["neutral"])
ax.set_xlabel("number of samples"); ax.set_ylabel("estimated entropy (bits)")
plt.show()
print("estimates:", [f"{v:.2f}" for v in est])
estimates: ['2.25', '2.65', '2.84', '2.92', '2.96', '2.99', '3.00']

15.9 Production

Libraries provide these quantities. We check that they match our code.

import torch
import torch.nn.functional as F
from scipy.stats import entropy as sp_entropy

p = np.array([0.7, 0.2, 0.1]); q = np.array([0.5, 0.3, 0.2])
print("scipy entropy (nats):", np.isclose(sp_entropy(p), entropy(p, base=np.e)))
print("scipy KL (nats)     :", np.isclose(sp_entropy(p, q), kl(p, q, base=np.e)))

# PyTorch kl_div expects log-probabilities of the model first, probabilities of the target second
kl_t = F.kl_div(torch.log(torch.tensor(q)), torch.tensor(p), reduction="sum")
print("torch kl_div        :", np.isclose(kl_t.item(), kl(p, q, base=np.e)))

logits = torch.randn(4, 5, dtype=torch.float64); target = torch.tensor([0, 2, 1, 4])
manual = -torch.log_softmax(logits, dim=1)[torch.arange(4), target].mean()
print("cross_entropy       :", np.isclose(F.cross_entropy(logits, target).item(), manual.item()))
scipy entropy (nats): True
scipy KL (nats)     : True
torch kl_div        : True
cross_entropy       : True

The argument order of KL functions differs between libraries. Always check which distribution is the target.

15.10 Failure modes

\(\log0\). A model that assigns zero probability to something that happens has infinite loss. Use smoothing, or compute with log_softmax (Chapter 24).

Few samples. The plug-in entropy and mutual information are biased (above). With many categories and little data, mutual information appears positive even for independent variables.

KL is not a distance. It is asymmetric and violates the triangle inequality. \(D_{\text{KL}}(p\Vert q)\) punishes a model \(q\) that misses mass where \(p\) has some. \(D_{\text{KL}}(q\Vert p)\) punishes a model that puts mass where \(p\) has none. The two give different fits (Chapters 38, 40).

Units. Bits (base 2) and nats (base \(e\)) differ by \(\ln2\). Reported perplexity and loss values must say which is used.

Perplexity is not comparable across vocabularies. A word-level model and a character-level model have different alphabets. Their perplexities cannot be compared directly.

15.12 System connection

NoteWhat the system gained in this chapter

The system can now measure how far a predicted distribution is from the truth, in units of bits or nats. It knows what cross-entropy is: the cost of coding the world with the model’s beliefs. The loss of Chapter 14 now has a meaning.

This closes Part IV. The system can measure similarity (Chapter 13), error (Chapter 14), and information (Chapter 15). It is time to use these measurements to change the model. Part V asks how: through derivatives.

Chapter summary

  • Information content is \(-\log p\). It is additive for independent events.
  • Entropy is average information. The uniform distribution has the highest entropy.
  • Cross-entropy is \(H(p,q)=H(p)+D_{\text{KL}}(p\Vert q)\).
  • \(D_{\text{KL}}\ge0\) by Jensen’s inequality. It is asymmetric and may be infinite.
  • The classification loss \(-\ln q_c\) is the cross-entropy to a one-hot target.
  • Mutual information is the KL divergence from independence.
  • Perplexity is the exponential of the cross-entropy.
  • Plug-in estimates are biased for small samples.
